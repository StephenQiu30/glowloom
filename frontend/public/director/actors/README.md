# 角色缩略图

12 张 192×192 PNG 来自项目实际交付的 `../models/quaternius-standard-male.glb` / `quaternius-standard-female.glb`，使用当前 `reshapeDirectorQuaterniusActor` 体型参数及 `DirectorModelMotion.sample(0, false)` 的站姿，经离线 Chromium / Three.js WebGL 渲染。

角色原资产为 Quaternius CC0，来源及许可见相邻 models 目录的两份 `.LICENSE.md`。体型/姿势适配逻辑的 BeefTV MIT 来源见仓库 `notices/BeefTV-MIT.txt`。没有使用即梦角色图片或模型。

`heights.json` 记录实际体型重塑后静止模型的包围盒高度（米），卡片展示保留两位小数；两个性别各有标准、少年、儿童、纤瘦、健壮、丰腴 6 类真实几何变化。
