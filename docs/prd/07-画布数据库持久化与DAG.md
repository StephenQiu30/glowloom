# 画布数据库持久化与DAG PRD

> 唯一来源设计：[14-画布数据与接口设计](../design/14-画布数据与接口设计.md)。实施状态见[BACKLOG](../../BACKLOG.md)。

## 1. 摘要

完整保存画布内容与协作状态，支持跨设备恢复、原子提交、结果查证及合法图与素材引用。

## 2. 背景

数据库承载项目画布的已确认内容、版本和回执。画布业务内容、草稿与待发操作不使用浏览器持久存储；本页内存和个人视图白名单沿唯一来源设计14区分，不能借离线缓存或错误恢复绕过约束。

## 3. 目标

关闭页面、清理浏览器数据或服务重启后可恢复全部已确认内容；重复提交保持一次业务效果，失败保持数据完整。

## 4. 目标用户

个人创作者和同项目获得授权的协作者。

## 5. 价值

用户可跨会话继续创作，核实保存结果并保留素材与生成来源。

## 6. 能力

| ID                         | 用户能力                                                 | 验收                   |
| -------------------------- | -------------------------------------------------------- | ---------------------- |
| CAP-DATA-01 可靠原子保存   | 完整保存或拒绝一次编辑，未知结果沿原身份查证             | AC-DATA-01、05、06、08 |
| CAP-DATA-02 合法图与引用   | 标注、分组及依赖各自合法，引用可授权读取                 | AC-DATA-03、05、06     |
| CAP-DATA-03 完整恢复与保护 | 节点、正文格式、引用、素材和关系完整读回，历史可查与恢复 | AC-DATA-02、04、07     |
| CAP-DATA-04 存储质量       | 二进制协作状态、投影与回执一致，可备份和恢复             | AC-DATA-01～08         |

覆盖全部正式节点、生成输入及结果来源；支持素材上传后接入、项目复制映射、存量画布转换及epoch切换。个人视图与临时在线状态分别管理。

## 7. 验收

验证全部字段读回、独立浏览器恢复、素材替换、上传后图提交失败、回执丢失、事务故障、非法依赖、越权、归档、项目复制和历史保护。核对Yjs二进制恢复结果与数据库投影；演练存量转换、备份恢复及服务重启。

证据见[计划17](../plan/17-画布数据库持久化与DAG实施计划.md)，通信和协作联合验收沿PRD08、09。

### 7.1 可靠保存与恢复的接受边界

- AC-DATA-01/07：正文、参数、布局、媒体引用、边和分组等正式字段完整读回；保存成功由数据库接受确定，未知类型不静默删除。
- AC-DATA-02/04：在线编辑和重开不依赖浏览器业务缓存；逐项检查设计14的存储清单，旧业务记录不读取、不自动上传，登录与个人偏好不被误清理。
- AC-DATA-08：留页时保留有界未确认内容，队列满不丢输入；刷新/关闭后读回服务器事实。已落库但丢回执的内容可能已恢复，未送达内容不承诺恢复；离页提示不代表已保存。
- AC-DATA-01/05/06：上传成功不等于图绑定成功；失败、撤权及迟到上传结果不产生错误绑定。重试只产生一次接受结果，不重复生成或计费。
- AC-DATA-03/05/06：并发后的图和引用也须合法；二进制、投影、回执及提交事件同事务。历史恢复保留旧接受记录，新版本不得被旧未确认输入自动覆盖。

自动提交时机沿[PRD08](08-画布WebSocket实时同步.md)，协作冲突与本人贡献沿[PRD09](09-画布协作编辑.md)；三项均通过才算多人画布保存闭环。完整离线持久草稿不在交付范围。

## 8. 依赖

素材服务提供稳定身份和授权读取；Go执行项目与图约束，协作服务处理Yjs状态。容量、恢复时延和备份目标通过部署验证确认。
