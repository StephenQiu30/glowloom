# 短剧工作室

唯一设计来源为 [设计38](../design/38-短剧工作室一致性设计.md)。原始观察及可验证范围见 [需求23](../requirement/23-短剧工作室对齐即梦需求.md)。

| 用户场景 | 验收 |
| --- | --- |
| 浏览工作室 | 侧栏显示「短剧工作室」。初次进入默认「剧本创作」，键盘可切换三个页签，「短剧画布」是独立入口 |
| 查看、创建及继续短剧 | 登录后只读取当前空间近期项目和模板。「全部」进入资产的「短剧工作室」分类。创建收到有效回执后才进入对应项目与主画布。未知结果用原请求重试 |
| 提交剧本、创意或转绘 | 各表单有明确文件、文本与配置校验。提交、恢复、结果归属和实际计费可核对。后端未开放的能力显示明确状态 |
| 制作资产与分镜 | 项目内可恢复资产、剧集及镜头选择。可验证引用、编辑保存、助手修改范围、生成及合成条件 |
| 查看示例及使用工具 | 公开预览只读，可按权限复制。导演台、预演与后期保持源输入及输出引用可追溯 |
| 多媒体创作参考（SRC-STUDIO-17） | 从设备或素材库添加图片、视频、小说文档，数量/格式/进度/失败/预览/移除明确；真正复制到新项目并随PromptDraft交接，账号切换不会泄露。视频展示采样理解边界，文档无静默截断，模型不支持时不发送。视频链接仅在解析入库成功后添加 |
| 风格库（SRC-STUDIO-18） | 搜索与官方/我的/真人/2D/3D筛选、无/选择、持久化创建编辑删除、4图首封面、20字名称/2000字描述。保存回读及CAS冲突、未知结果重试可验证。选中的真实描述/参考图参与本次创作。分析采用实际图片与正常Agent费用确认，回复需明确采用 |
