# 管理页面统一与五服务接入

唯一来源设计：[管理页面统一与五服务接入设计](../design/2026-10-31-管理页面统一与五服务接入设计.md)。来源需求04 SRC-AI-32 / CR-ADMIN-01。

1. 五类管理页共享全站外壳、留白、标题和导航，使用现有主题和组件；桌面、320/390px、明暗主题及键盘均可操作。
2. 新建服务集中一页，五类入口分别鉴权；跨分类模型选择和原请求恢复不丢失。保存、验证、启用分离，密钥不回显。
3. OpenAI 按当前官方模型目录提供文本与单张图片。Responses 不完整或拒绝不标成功，未知调用不自动重发；可完成验证、发布、报价、冻结提交和结果处理。
4. 历史连接、既有管理权限与危险操作确认保留。Figma 先行；受控协议测试、数据库测试、浏览器检查、真实供应商验收分别说明。
