# PRD 26｜模型号池接入与路由

唯一来源设计：[设计40 · 总体、接入与路由](../design/40-模型号池与销售计费设计.md)。执行计划：[Plan35](../plan/35-模型号池接入与路由执行计划.md)。

## 用户与范围

创作者在画布、工作室或对话中选定模型和规格。系统负责寻找有权限、有容量且能兑现报价的供应商和 Key。管理员可以从空目录开始发布、更新或撤销线路。值班人员可以用一个任务编号说明每次尝试的去向和受理情况。公开中转销售、订阅账号共享、自动更换模型和策略编排器属于范围外。

## 用户故事与接受条件

| 故事 | 用户操作与结果 | 追踪 |
| --- | --- | --- |
| US-POOL-02 管理接入 | 管理员在“渠道与 Key”新增连接，分别查看可达性、凭据授权和精确模式验证。手动或定期刷新时可审阅新增、失效及价格变化，再发布。列表给出可用性，详情说明阻断原因、时间、版本及在途影响。 | FR-POOL-01、FR-POOL-02、FR-POOL-03、FR-POOL-10 |
| US-POOL-01 一次确认 | 对同一付款空间和授权，从各创作入口提交相同规格，均遵守所选模型、参考素材、参数、地区、预算与确认价。用户不必选择 Key。Agent 固定端点时只能使用该端点。 | FR-POOL-04、FR-POOL-05、FR-POOL-06、FR-POOL-07 |
| US-POOL-03 查回原单 | 发生断流、超时、取消或重启后，用户看到原任务的真实状态与可执行动作。值班可沿原身份查询，账务可关联用量及费用。归档失败可重新取回同一产物。 | FR-POOL-08、FR-POOL-09、FR-POOL-10 |

## 产品验收

| ID | 前置、动作与可观察结果 |
| --- | --- |
| AC-POOL-01 | 空池显示不可用。管理员录入并验证首条线路，发布后才可选用。新增第二把独立 Key 并排空第一把，新单可使用新 Key，旧单仍可收尾。 |
| AC-POOL-02 | K1 在派发前到期，同渠道 K2 可用则使用 K2。随后主渠道维护，允许跨渠道的任务转到同规格乙方，固定甲方的任务给出不可用原因。 |
| AC-POOL-03 | 多个请求争用同一账号下两把 Key，共享额度只计算一份。有独立容量时走合格备线，否则停止派发。 |
| AC-POOL-04 | 候选缺少必需参数、参考素材访问权、数据地区、可核对计量或超采购上限时，排除该候选。无法约束聚合商下一跳时同样处理。全部排除后上游收到零次请求。 |
| AC-POOL-05 | 已明确拒收且无费用的可恢复供应故障允许在总时限内安全换路。输入错误、内容拒绝、取消均停止。只有 HTTP 错误码且受理不明时转核对。 |
| AC-POOL-06 | 在视频提交后丢失响应，或流已输出工具片段后中断，再重复确认并重启。仍返回原任务，未知单零补发，工具零重复执行。已取得的上游编号用于查原单。 |
| AC-POOL-07 | 已受理的视频可在 Key 排空期间按原身份查询或取回。紧急撤销完成后，旧 Key 停止使用，回滚配置也不能恢复其资格。 |
| AC-POOL-08 | 主路明确拒收、备路成功时只交付一个业务结果。采购尝试可追溯，用户资金效果按[PRD27](27-模型销售定价与结算.md)验收。成功产物缺用量时允许显示已交付、费用待核对。 |
| AC-POOL-09 | 空目录或刷新超时保留最后有效观测并显示陈旧。刷新期间更换身份则丢弃迟到结果。两个管理员从同一版本发布，后提交者可见冲突与最新差异。 |
| AC-POOL-10 | 冷却与恢复只影响对应 Key、账号组或渠道。值班可看脱敏尝试链，普通成员只见获授权的任务；详情、日志、导出均不泄露秘密或私有素材地址。 |

## 开放条件与待定项

产品验收按“模型 × 规格 × 渠道 × 凭据”记录实单结果。跨供应商能力另验两个合格组合及一次安全切换。比较同一时间窗的业务成功率、切换挽回率、端到端 P95，单列结果未知的单数。首批组合（DEC-POOL-01）、调度参数与时限（DEC-POOL-02）、采购价差及数据范围（DEC-POOL-03）待评审。主备优先、同级均分、渠道内轮询和总计最多两次收费尝试为设计建议。
