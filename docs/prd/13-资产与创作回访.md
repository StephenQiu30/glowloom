# 资产与创作回访

唯一来源设计：[设计26](../design/26-资产信息架构与即梦对齐设计.md)。原始要求见需求13，竞品事实见调研08。本人发起归属已由用户确认；历史画布旧工作流语义已由发行脚本补证，织光使用显式分类。

## 用户价值与范围

创作者从“资产”找回生成内容、继续画布/短剧，并从辅助入口管理上传参考。覆盖来源分类、四类生成媒体、搜索/筛选/时间/排序、详情入口、对象合法操作和真实状态。保留既有参考素材、文件夹、回收恢复和历史链接。

不因外观一致引入即梦品牌、会员报价、剪映集成或伪生成；不删除生成执行/计费事实，不猜测既有项目类别。

## 用户故事

- US-AST-01：作为创作者，我能区分生成结果、创作容器与上传参考，以找到正确内容。来源 FR-AST-01/02/07。
- US-AST-02：作为创作者，我能按当前媒体条件查询并清除条件，以找回需要的内容。来源 FR-AST-03/06。
- US-AST-03：作为创作者，我能对有权的对象执行单项/批量操作，看到真实结果，并在失败后恢复。来源 FR-AST-04/05。

| ID        | 前置与步骤                                   | 预期及例外                                                                                           |
| --------- | -------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| AC-AST-01 | 打开资产，切换来源和媒体                     | 默认生成历史/图片；主分类与媒体层级正确；上传参考单独保留                                            |
| AC-AST-02 | 有真实成功、处理中、失败任务                 | 都以真实状态出现；不将上传文件或空占位当任务；详情上下文与冻结内容一致                               |

| AC-AST-04 | 进入批量，选0/1/多项并操作                   | 分类动作正确，零项禁用；只操作合法选择；部分失败明确；取消不提交写入                                 |
| AC-AST-05 | 打开/重命名/复制/删除画布                    | 对象与主画布联动一致；修订、幂等和无权失败成立；模板标记明确，点击实际生成预填的新对象且保留模板本体 |
