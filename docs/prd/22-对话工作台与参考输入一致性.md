# PRD：对话工作台与参考输入一致性

唯一来源设计：[设计35](../design/35-对话工作台与参考输入一致性设计.md)。实施：[Plan31](../plan/31-对话工作台与参考输入一致性实施计划.md)。状态、优先级、阻塞及下一步仅见[BACKLOG](../../BACKLOG.md#conversation-workspace)。本文把设计35转为可接受的用户行为，不定义另一套Agent或编辑器合同。

## 1. 用户价值与目标

创作者从首页发送包含真实参考的需求，在对话中看见持久消息、执行进度及产物；可以明确停止、核对原任务或追加重新生成，并在重开后保留完整历史。首页、对话和富文本不再有三套添加参考样式或输入规则。

完成判据是整条链在真实页面和持久服务中成立；Figma模拟完成、mock产物或仅接口接线不构成产品接受。本轮工程验证不产生新的积分或真实生成费用。

## 2. 角色与使用边界

会话为当前创作者本人私有，受当前空间、项目权限约束。项目成员和画布分享者不能因此查看其他人的对话。模型和素材能力来自真实服务；没有可用项目、模型或权限时允许保留草稿并修复，不能假装已经执行。

## 5. 产品验收

| 验收ID     | 可观察的接受条件                                                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-CONV-01 | 首页Agent发送进入可刷新详情；已有会话可直达，新建进入空草稿。缺项目要求选择、不偷偷新建；未登录先登录，不读取私有列表                                                     |
| AC-CONV-02 | 侧栏显示当前项目本人会话、当前选中、最近输入排序及分页；空/加载/失败可区分。跨账号/空间/项目不得闪现前一上下文内容                                                        |
| AC-CONV-03 | 首页Agent、首页图片模式、对话和共享富文本的参考空/单/多/展开/移除外观一致：48×64视觉、64×84固定槽、12间距、正文起点76、外壳16内边距及24圆角；展开不推挤或遮挡输入         |
| AC-CONV-04 | 文件选择取消保留文字和绑定；删除任一图保留正确另一图、编号和行内引用；删除卡片及其提及可整体撤销。移除后迟到上传不复活绑定；失权缩略图被撤去                              |
| AC-CONV-05 | 空输入与纯历史引用不能发送；可用图片only在规划模型支持时可发送；有新文字时移除末图仍按能力检查。上传中/失败/失权/模型不支持有阻塞原因，不静默忽略参考                     |
| AC-CONV-06 | 发送消息准确展示当次文字、引用及参考，没有凭空文字/媒体；受理前不清空。明确拒绝保留输入；回执未知先找回原request，双击和重传仅受理一次。受理后读取失败不会产生第二次发送  |
| AC-CONV-07 | 重开显示全部已受理轮次和尝试，较旧历史可加载；SSE重连/重放不重复文本、不丢终态尾消息。用户向上阅读时新回复不抢滚动，可回到底部                                            |
| AC-CONV-08 | 文本安全展示；进度、工具和专业任务仅显示可公开信息；审批显示实际候选及费用依据。子Agent内部回复和私有推理不能混进主回复，raw HTML/危险链接不执行                          |
| AC-CONV-09 | 点击停止先显示请求中，Agent应用回执后显示已停止，原用户输入及已有输出保留。断线/离页/换会话不停止；迟到批准/继续不能覆盖Stop                                              |
| AC-CONV-10 | 失败/停止/完成后用户明确重新生成会追加新尝试并保留旧记录；再次停止仍保留所有尝试。使用原输入，不覆盖正在编辑的新草稿；设置失效要求用户修复，不偷换模型。暂停继续属于原run |
| AC-CONV-11 | 刷新/断线后按原快照/cursor恢复；cursor过期可重读；无权限/不存在统一处理。迟到响应不能写入新会话，恢复失败有可操作提示，不自动新建run                                      |
| AC-CONV-12 | 原收费结果未知时只能核对原任务，服务端也拒绝重新生成；run停止、媒体取消、交付成功和结算各有真实状态。取消请求与最终取消分开，不声称必退款或0费用                          |
| AC-CONV-13 | 桌面及320/390/768宽度无横向溢出；软键盘不挡发送/停止；移动操作至少44命中，键盘可添加/展开/移除/关闭/发送；IME组合Enter不发送                                              |
| AC-CONV-14 | 结果卡来自真实媒体身份和归档状态，预览/下载受当前授权，过期链接可刷新；无产物/不可读/失败有明确状态，不能用示例图或run完成伪造已生成图片                                  |
| AC-CONV-15 | 新建/切换类型/会话/项目后草稿按身份隔离；引用和正文使用同一编辑历史；仅显示有真实能力的Skill/模型/动作；Figma新增恢复和停止请求态与实现一起核对                           |

## 7. 依赖与交付边界

沿来源设计35依赖当前Agent合同、Go预算与控制、PromptDraft与素材/主体授权、共享壳。同步更新生成API及全部仓内调用方，不保留旧goal双轨接口。既有纯文本记录可只读回看，不伪造多模态快照。

知识库链完整、工程检查通过、隔离数据库通过、浏览器接受、实际供应商/费用接受和发布分别记录。无新增消费约束下，真实模型、媒体队列取消及实际结算接受须明确留待单独授权；缺此证据不能宣称“完整真实创作已验收”。当前调度统一在BACKLOG，本文不复制进度表。


## 即梦对话改版验收

- AC-CONV-16（FR-CONV-10、13）用户从首页、对话页及模型选择器看到一致命名。技能搜索按名称和描述匹配，已选技能在过滤和关闭面板后保留；无匹配与无已启用技能分别说明。
- AC-CONV-17（FR-CONV-11）本人置顶、取消置顶、行内重命名与确认删除，刷新可观察到服务端结果。重命名可按 Esc 取消。其他用户与只读项目不能修改；在途或待核对会话拒绝删除，失败保留原列表和结果。
- AC-CONV-18（FR-CONV-12）已完成、等待确认和停止分别呈现；公开活动可展开。Agent 与直接生成按接受顺序重开，参数复用只回填，显式重试创建新尝试。
- AC-CONV-19（FR-CONV-13、14）创作类型菜单按即梦实页七项顺序展示；切换保留原类型草稿，且不会提交生成。对话模型独立于图片、视频设置。只展示当前权限和项目能力支持的配置。检索覆盖持久记录，日期和类型过滤可恢复，回到底部不干扰旧消息阅读。


- AC-CONV-20（FR-CONV-10、13）新建对话有独立空态。已有历史时仍可从侧栏切回旧对话。推荐卡始终可见。「试一试」聚焦输入，有可用同名技能时选用确切版本，其余填入可编辑提示词。保留原草稿，空白输入不能提交。
