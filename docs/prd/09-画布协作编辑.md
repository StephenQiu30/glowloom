# 画布协作编辑 PRD

> 唯一来源设计：[17-画布Yjs协作编辑设计](../design/17-画布Yjs协作编辑设计.md)。实施状态见[BACKLOG](../../BACKLOG.md)。

## 1. 摘要

使用Yjs实现节点、关系及Tiptap富文本的多人协作编辑，保持引用完整、持久结果可查和个人贡献可撤销。

## 2. 背景

交付覆盖同一画布的连续多人编辑、断线恢复、在线状态和版本恢复。

## 3. 目标

兼容编辑完整保留，客户端与数据库最终一致；关闭重开后正文格式、引用身份和素材绑定保持完整。

## 4. 目标用户

同项目编辑者、同账号多设备使用者及只读访问者。

## 5. 价值

多人共同创作时能够连续编辑、了解协作状态并恢复自己的工作。

## 6. 能力

| ID                        | 用户能力                                       | 验收                  |
| ------------------------- | ---------------------------------------------- | --------------------- |
| CAP-COL-01 共享模型与合并 | 不同节点、属性及同段正文的兼容修改共同保留     | AC-COL-01、02、05     |
| CAP-COL-02 完整编辑覆盖   | 节点、分组、连线、格式及引用参与协作           | AC-COL-01、02、04、05 |
| CAP-COL-03 连续编辑与恢复 | 持续输入并接收远端更新，断线后查证与恢复原提交 | AC-COL-05、06         |
| CAP-COL-04 个人撤销       | 撤销及重做本人贡献，保留他人修改               | AC-COL-03             |
| CAP-COL-05 业务一致性     | 保存、历史恢复及生成结果遵守权限、图和引用约束 | AC-COL-01～06         |

在线成员、光标、选择和拖动预览按权限展示并过期；个人视图独立保存。历史版本可查看，恢复后形成新的持久版本。

## 7. 验收

至少三个客户端、两个授权账号验证同段富文本与引用并发、中文与IME、个人撤销、拒绝恢复、断线重放、撤权及服务重启。用数据库回读核对内容、引用和持久回执。旧画布转换后逐项核对并关闭重开。

实施见[计划19](../plan/19-画布Yjs协作编辑实施计划.md)。

### 7.1 可见接受边界

- AC-COL-01/02：不同属性及正文的兼容修改保留；同字段互斥赋值按确定性规则合并，不承诺服务器最后收到者获胜。区分“已接受但字段被并发更新”“确定拒绝”“未知结果”；非法依赖整笔拒绝，未处理的恢复输入不得被已保存提示掩盖。
- AC-COL-03：本人撤销不整图回滚，正常可独立撤销的贡献能够撤回；他人已改同字段或使用本人所建对象时，不能强行覆盖或删除，受阻时说明原因。删除恢复保持业务与引用身份，旧实例的迟到编辑不能污染恢复后的对象；重做与重建后撤销也遵守当前约束。
- AC-COL-04：旧任务结果不覆盖新输入，系统回写不绕过同一保存确认合同。
- AC-COL-05/06：保存期间和临时断线可在有界本页内存继续编辑；旧回执不能清掉新输入的未保存状态；页面关闭后不承诺恢复未送达内容；服务器实际已接受但丢回执的内容仍可重开读回。
- AC-COL-06：数据库提交后ACK或广播丢失、服务重启与owner切换可查证并补齐；禁用浏览器业务持久缓存后仍完成在线多人编辑与重开。

- AC-COL-02/06：拒绝后的依赖链重建期间他人可继续提交，恢复以最新权威内容为准；安全兼容意图可重建，同字段/删除/引用冲突须展示差异并让用户处理，不能无提示覆盖。旧已接受动作不重复执行，旧未知动作须先查证。

以上细化沿唯一来源设计17与原AC，不新增完整离线产品、跨重开撤销栈或生产性能承诺。具体协议、数据结构和故障注入方法回设计/计划，不由PRD复制。

## 8. 依赖

Go提供项目、权限、素材、任务和持久接受；数据与实时传输按PRD07、08接受。应用服务通过Docker启动，复用现有基础依赖。

### 7.2 本轮优先能力的可见接受

- 并发添加参考时，提示词引用及正式画布的参考节点列表都不重号；移除、恢复和重开不重排既有编号。
- 撤销本人删除后恢复原节点及合法关系，其他人的旧实例输入不能进入恢复后的内容；不可独立恢复时明确提示。
- 版本预览可核对节点正文、关系和完整数据。恢复创建新版本，保留当前画布名称及后来已分配的引用编号；核对期间远端有新接受时要求重新核对。
- 恢复结果未确认期间不能再次发起另一份恢复；断线后的原恢复查证不重复产生版本。其他页面的新输入按原断线/epoch恢复规则处理。
- 在线光标与保存状态独立，同账号多个页面可区分；断线、关闭和撤权后的在线状态消失或过期。跨实例转发、远端选区和拖动预览不以单实例光标测试代替验收。

全应用存储接受补充：项目创建/复制、独立提示词与试运行不得从旧本地业务记录恢复或发起请求；断网留页使用原命令重试，重开只读服务器。旧实验Yjs升级须保留图、富文本、引用身份并创建新epoch，未确认旧输入不自动重放。中文输入法须区分候选组合、提交、取消及远端删除时的草稿保护，普通中文字符串输入不等同物理IME验收。

中文输入节点被他人删除时，未确认内容保留在本页。恢复界面须明确区分“恢复为新节点”与本人撤销删除的原身份恢复，要求用户勾选后提交；失败保留输入，不静默复活节点或关系。
