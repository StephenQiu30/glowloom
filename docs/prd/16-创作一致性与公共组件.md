# 创作一致性与公共组件 PRD

唯一来源设计：[设计29](../design/29-创作一致性与公共组件设计.md)。执行：[Plan25](../plan/25-创作一致性与公共组件实施计划.md)。实施状态仅见[BACKLOG](../../BACKLOG.md)。

## 用户故事与范围

作为创作者，我希望在所有普通页面看到相同的账号区，在创作时按类型选择模型和输入，并在切换后找回自己的草稿。完整范围为设计29承接的70项要求；七种菜单不等于七类服务已实现。

## 接受边界

测试夹具只验证客户端合同；真实生成、任务队列、计费、非空结果、后端草稿保存必须分别接受。分批落地不删除尚未满足的范围。

补充 CR-AC-06：七类+画布各自有独立输入；六类文字入口与画布首次切换为空、往返恢复正文/引用/设置，动作模仿使用独立槽位且不提供正文；项目新草稿以目标类型内容初始化。页面内恢复按类型提示候选文字，旧草稿只归图片，恢复不静默覆盖新输入。账号/空间变更立即隔离；保存失败拒绝离开；过期异步读取不串写。

### CR-AC-07 七类输入验收

音频选择项目请求audio.generate目录，标题显示音频生成，文本朗读不显示普通素材引用；图片/视频保持原引用链路。数字人角色图片、驱动音频与可选动作说明分开，音乐模式单独保留，动作模仿没有可编辑正文。视频时长以秒编辑并保留毫秒协议；模型范围决定滑块与输入框上下限。未接通服务不能创建通用替代任务，模型未配置、加载失败与未知结果仍可恢复。完整真实服务验收按设计29及供应商协议单列。

恢复边界补充：当前 branchJournal 为页面内存日志；CR-016 的刷新/跨设备恢复尚未实现。hook 的模拟重挂载测试只证明候选处理与权限隔离，不证明刷新持久化。

### Seed-Audio 全能配音合同（2026-10-29）

来源：`../research/evidence/2026-10-29-creation/volcengine-omni-audio-protocol.md`。Figma 可编辑节点 `3211:63326`、`3211:63408`、`3211:63490`、`3211:63572`，桌面/移动共享现有组件；实例属性与文字均回读。

音频保留文本朗读，新增独立 `omni_audio` 模式，模型 `seed-audio-1.0`，POST `/api/v3/tts/create`。自然语言最多3000字符描述角色台词、环境音和时间段；最长120秒，不提供虚假的硬时长控制。引用最多3条音频（每条≤30秒、≤10MB）或1张图片（≤10MB），禁止混用，素材事实由服务端校验。引用通过稳定ID编译成当前物理顺序的 `@音频N`，不沿用删除后的旧编号。固定MP3/24000，开放语速、音量、音调、字幕开关。字幕保存句/字毫秒时间，允许查看与导出；缺失字幕不得伪造。

报价按最大120秒预留，实际使用 `original_duration` 计费，保留原始小数秒收据；不得按后处理时长或每次整分钟计费。超时结果未确认时保留原请求，不自动重发。模型必须经过真实模式验证才能启用，不能靠预设导入自动激活。官方收费与平台积分规则分开。音色注册、收藏、公共音色目录独立验收，素材上传不能冒充音色训练。


### 项目 Agent 单图执行合同（2026-10-29）

Figma 节点 `3217:60567`、`3217:60772`、`3217:60925`、`3217:61078`、`3217:61231`：会话、规划报价、图片方案确认、执行恢复、完成。首个可执行范围为图片创作，会话按项目和当前账号私有保存，刷新可恢复。规划器使用受限 JSON 方案（reply 或 generate_image），服务端严格解析和白名单执行，不能把普通文本聊天冒充任意工具 Agent。无需供应商原生 function-call；运行策略版本写入冻结提示与会话，不接受浏览器上传可信历史、工具结果或任意工具名。

每轮最多一次规划、单张图片和一次总结。规划、图片、总结分别复用正式 operation 报价/确认/余额/归档链路；模型输出不能授权付费。每个阶段持久化同一个请求 UUID，断线重放不得重复生成。只有 completed 且审核通过的图片结果才可反馈总结；unknown/manual/reconciling 保留原任务并暂停。用户可停止后续阶段，已开始的供应商任务仍按真实状态处理。会话读取只读，显式 advance 恢复执行。选择的模型和参数冻结至当前轮，工具不能改项目、供应商、URL、价格或参数。

该边界不承诺视频工具、浏览器、代码执行、多工具并行或自动花费总预算；这些能力需要另行扩展已验证工具合同。直接回答无需图片阶段。会话历史使用已落库事实，每次模型调用保持可审计和计费；总结不声称看过未经视觉模型读取的图片内容。

### 音色库与数字人文本驱动补充（2026-10-29）

来源：需求16；设计29；PRD16；实施计划25。Figma `3252:64030` 已先于代码建立并回读：音色库、创建、异常、数字人两阶段和390px。系统音色来自火山官方2.0列表；用户参考音色按项目与创建者隔离保存名称、素材ID及修订、授权确认和收藏，无需可用模型。参考音频必须就绪、审核通过、≤30秒且≤10MB；不把保存素材称为训练。创建使用稳定请求ID，重放相同请求返回原记录，不同输入冲突；变更带修订，删除不删除源素材。系统音色不虚构试听文件。数字人文本驱动复用独立音频草稿、报价、确认与任务结果，用户试听后显式采用音频，再单独确认数字人报价；台词不得直接提交OmniHuman。验收包括真实数据库权限、幂等、并发修订，以及浏览器保存/收藏/刷新/引用与类型往返。

验收补充：四类属性筛选与搜索共同生效；保存请求未知时重开仍恢复原请求；不同账号/项目不可读写他人音色。普通音频、数字人视频、数字人台词在保存与刷新恢复时互不覆盖。没有可用模型时允许保存台词、选择音色及管理音色，生成按钮按真实目录禁用。

手机音色管理验收：390px页面无横向溢出；音色库、创建及筛选项点击高度至少44px；Escape关闭返回原触发按钮。数字人台词必须经真实整页刷新与重新选择所属项目后恢复，普通音频保留自己的引用。

### CR-071 导航外壳验收

唯一来源：[设计29 §7.12](../design/29-创作一致性与公共组件设计.md)。普通创作、探索、资产、主体页面共用账号区与侧栏；图标形状和对应设计资源一致。导航、最近画布、账号按钮按设计尺寸展示，折叠不截断图标，320/390px不出现横向溢出，手机触达至少44px。工具链接可达真实页面；原搜索、积分弹层和账号菜单行为保留；不得展示虚构余额或促销。

CR-071补充：首页无顶栏搜索，⌘/Ctrl+K不会打开隐藏搜索；共享顶栏无企业服务入口。探索和资产的实际搜索仍按其页面合同验收。
