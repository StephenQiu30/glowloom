# 画布编辑与素材 PRD

> 唯一来源设计：[10-画布交互设计](../design/10-画布交互设计.md)。实施状态见[BACKLOG](../../BACKLOG.md)。

## 1. 摘要

完整迁入画布能力，统一Tiptap与全能参考，接入Yjs协作及现有项目、素材、权限和任务服务。

## 2. 背景

创作工作区覆盖节点编辑、素材处理、生成与工作流、协作与恢复、个人视图、侧栏和项目交互。

## 3. 目标

| ID                 | 接受条件                                                     |
| ------------------ | ------------------------------------------------------------ |
| KR-CAN-01 一致编辑 | 节点、正文格式、参考与参数可完整编辑，焦点和取消行为明确     |
| KR-CAN-02 可控交互 | 平移、缩放、选择、拖动、尺寸、分组、连线和浮层在目标屏幕可达 |
| KR-CAN-03 可信内容 | 素材与生成来源可追溯，已确认内容可从数据库完整恢复           |

## 4. 目标用户

创作者、项目协作者及只读访问者。

## 5. 价值

文字、媒体、参考和生成任务在同一画布内组织、编辑、协作与恢复。

## 6. 能力

- 文本、图片、视频、音频、分组、生成及工作流节点的创建、编辑、复制、删除和定位。
- Tiptap正文、全能参考卡、@提及、预览、替换、移除及单会话展开编辑。
- 素材上传、拖入、粘贴、授权预览、下载，以及图片裁剪、拆分和像素缩放。
- 模型与参数配置、任务提交、进度、失败恢复、结果来源和历史展示。
- 框选、多选、拖动、缩放、分组、端口连线、小地图、搜索、侧栏及项目交互。
- Yjs连续协作、在线成员与光标、个人撤销、版本浏览与恢复。
- 用户与画布隔离的个人视图；加载、空态、失败、只读、键盘、IME和窄屏体验。
- 历史结构完整只读展示，保留正文、引用、素材和关系。

ST-CAN-01～03、ST-CAN-UI-01～07与AC-CAN既有编号沿[原始需求](../requirement/06-画布组件迁入与定制需求.md)保留。

参与者展示复用官方头像组及悬停/点击弹层，按已认证用户去重，姓名与头像来自授权业务资料；同一账号多页面不增加人数。顶栏移除版本历史入口，保留生成历史；断线明确在线状态未知，保存状态独立显示。具体尺寸、触屏和键盘交互见[画布设计7.7.1](../design/10-画布交互设计.md)。

## 7. 验收

AC-CAN-LINK-01：有权限的团队成员打开分享链接或刷新画布，无需手动选择团队；旧链接同样有效，保存后重开保留内容和格式。链接归属以服务端验证为准，伪造空间参数不改变权限；退出成员和失效会话不能读取归属或正文。加载及错误状态保持简洁，接口异常或不完整响应不导致页面崩溃。

SRC-CAN-13：从正式 `/canvas` 进入统一编辑器，使用当前账号与项目；界面只呈现本产品命名。创建、编辑、保存、关闭重开与撤销/重做在同一正式入口验证；后端未接受的内容不能显示已保存。

按设计10核对各类节点、工具栏、菜单、编辑位置与全部能力；在真实身份和数据库下完成上传、编辑、持久确认及关闭重开，逐项比对内容、格式、引用身份、布局和关系。

验证个人视图隔离、异常浏览器存储、异尺寸恢复，以及只读浏览、手势取消、键盘与IME。协作、数据和通道分别沿PRD07～09验收。实施证据见[计划13](../plan/13-画布编辑与素材实施计划.md)。

SRC-CAN-14验收：已加载图片/视频在平移、拖动和保存回执后不闪回占位，同文件更新保留媒体DOM和预览地址；替换、移除及版本变更正确失效。横图、竖图、方图和视频导入/替换后节点比例与素材一致，中心稳定；保存后刷新、断线恢复与远端更新保留正确尺寸。未知尺寸延后到解码完成且手势结束再提交，校正比例时不二次居中；并发替换/缩放保留合并后位置，迟到旧素材测量不得修改新素材。

## 8. 依赖

Go提供项目、用户权限、素材与生成合同；Yjs提供协作编辑模型。应用服务统一Docker启动，基础依赖复用现状。功能迁入后按最终Figma稿优化页面展示。
