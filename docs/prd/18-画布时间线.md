# 画布时间线

唯一来源设计：[31-时间线即梦一致性设计](../design/31-时间线即梦一致性设计.md)。需求ID沿用TL-R001～008。

## 用户能力

1. 从本地或资产库导入素材，区分已导入资产与画布资产，筛选及拖入轨道。
2. 在一个主视觉轨连续剪辑图片和视频，在独立音轨编排声音；分割、左右剪裁、删除、换序、边缘裁剪、撤销重做。
3. 从画布节点进入全屏编辑，播放、定位、调音量、切换比例，调整资产与轨道视图。
4. 设置名称、位置、分辨率后导出，接收真实文件或画布资产；可取消和重试。

## 验收

命名、层级、尺寸与状态遵循唯一来源设计7.1；时间与素材遵循7.2～7.4；输出遵循7.5。逐项执行TLA-01～52，确认实际媒体可解码、引用正确、刷新恢复、权限有效、失败不丢编辑。不把按钮存在或测试夹具通过记为真实产品接受。
