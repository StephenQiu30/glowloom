# 织光产品范围

状态：当前能力目录；除用户已确认的邮箱认证、平台/团队双层管理及创作者称谓外，细节和交付批次仍需评审。更新：2026-10-14。

织光服务于围绕图片、视频、声音和画布开展创作的个人与内容制作者。主要旅程为：浏览灵感 → 登录或注册 → 创建对话/项目/画布 → 引用素材与主体 → 提交生成 → 比较并采用结果 → 保存、导出或分享。

产品功能与主要交互参考即梦，视觉与组件遵循 [DESIGN](../../DESIGN.md)。以下是织光的完整候选范围，不是竞品当前能力的核验报告，也不表示全部已实现或已排期。先保留完整能力覆盖，再决定各批次范围。首页推荐与活动内容可使用明确的设计占位；私有资产、账号、生成结果和收费状态必须来自真实服务。

## 能力目录

| ----- | ----------------------------------------------------------------- | ------------------------------------------------------- |
| JM-01 | 首页双入口、近期项目、对话/画布历史、搜索与继续创作               | 返回首页后能准确继续原对象；切模式不静默丢草稿          |
| JM-02 | 首页活动与推荐内容、灵感分类、搜索、作品详情、创作过程、同款/模板 | 从案例进入编辑时说明哪些素材/参数可复用；原作品不被修改 |
| JM-03 | Agent 对话、技能发现、引用和多步创作                              | 展示计划、当前步骤、引用与产物；不可用技能给原因        |
| JM-04 | 文生图、参考生图、主体引用、多图输入                              | 生成记录可追溯到实际输入与模型；输入失效先提示          |
| JM-05 | 模型能力驱动的比例/尺寸/清晰度/数量参数                           | 切换模型时标明失效参数，不静默改变成本或丢参考          |
| JM-06 | 图像局部重绘、扩图、消除、抠图、增强与多图融合                    | 保留原图，可比较编辑结果；失败保留蒙版和输入            |
| JM-07 | 图层/画面编辑：移动、裁切、变换、排列、蒙版与组合                 | 画面编辑与工作流连线明确区分；撤销不破坏原素材          |
| JM-08 | 文生视频、图生视频、首尾帧与多帧参考                              | 显示参考角色与顺序；错误输入不进入收费提交              |
| JM-09 | 多模态视频参考、运镜/动作控制、视频编辑与延展                     | 每份参考用途明确；局部修改保留原视频和新版本            |
| JM-10 | 视频质量/时长/比例/数量、结果播放和帧参考复用                     | 预览失败与生成失败区分；导出可核对真实尺寸/时长         |
| JM-11 | 音乐生成、描述/风格/时长及后续复用                                | 可试听、停止、比较、保存并用于项目；歌词能力单独核实    |

| JM-13 | 数字人、角色/声音/台词/动作输入、口型成片                         | 缺少角色或音频时提示；输出和授权来源可追踪              |

| JM-16 | 引用与连线：创建/断开/查看来源、合法输入验证                      | 能解释每条边的用途；布局连线不被误当成已经执行          |

| JM-18 | 画布 AI 助手：上下文引用、技能、执行反馈                          | 引用范围明确；中止后展示已完成内容与未执行步骤          |
| JM-19 | 时间线/片段编排、音画组合、预览、成片导出                         | 顺序、时长与声音可核对；导出失败不丢工程                |
| JM-20 | 导演台、剧本到分镜/镜头、叙事主体连续性                           | 计划、素材与产物相互可定位；单镜头可返工                |
| JM-21 | 资产库：上传、来源、预览、搜索/筛选/排序、批量、引用              | 同一素材跨生成/画布复用；失效或无权限不伪装为空         |
| JM-22 | 主体库：建立、命名、描述、引用、更新                              | 主体是可复用对象；更新不静默篡改历史生成证据            |
| JM-23 | 对话/画布/项目管理：创建、命名、搜索、复制、删除恢复              | 原项目与副本隔离；删除前解释影响；恢复能力明示          |
| JM-24 | 生成任务：队列、进度、取消、重试、部分成功、恢复                  | 重复点击不重复建同一任务；刷新后找回真实状态            |

| JM-26 | 下载/导出：单个媒体、批量、成片、交接剪辑工具                     | 规格、文件名、错误与重试清楚；可继续编辑原工程          |
| JM-27 | 分享与协作：私密链接、权限、撤销、评论/共同编辑                   | 先区分仅查看、复制与编辑；多用户冲突不能静默覆盖        |

| JM-29 | 个人与团队创作者、登录恢复、偏好、成员管理、消息/任务通知         | 会话失效保留输入；通知定位真实任务；主题跨页一致        |
| JM-30 | 会员/积分/额度、生成前费用、明细、失败与取消结算                  | 用户在提交前知道预计消耗；状态未知时不诱导重复付款      |

| JM-32 | 通用质量：自动保存、断线恢复、跨设备、性能、可访问性              | 保存状态真实；核心动作可键盘完成；失败可恢复            |

## 当前深化范围

账号与用户体系以 [用户系统 PRD](../prd/01-用户系统.md)、[用户系统需求](01-用户系统需求.md) 为准。邮箱用于登录、注册和恢复；显示名用于展示，稳定用户 ID 用于内容归属。用户管理、个人设置和账号生命周期与认证一并设计。个人创作者与团队创作者共用账号，平台管理员负责全站治理，团队管理员负责本团队成员；团队称谓不扩展为企业组织层级。

全能参考及相关模式的多参考引用已深化为[多参考提示词编辑器需求](02-多参考提示词编辑器需求.md)，选型依据见[编辑器调研与设计](../design/05-多参考提示词编辑器调研与设计.md)。用户已确认采用 Tiptap 开源底座；交互设计细化了统一引用事务、模式切换和草稿保存，执行顺序见[编辑器实施计划](../plan/07-多参考提示词编辑器实施计划.md)。尚未实现或完成运行验收。

AI 平台接入与预设管理已确认首轮由平台管理员统一配置 Key，接入火山引擎和 OpenRouter；[需求03](03-AI平台接入与预设管理需求.md) → [设计06](../design/06-AI平台接入市场调研与架构设计.md) → [PRD03](../prd/03-AI平台接入与预设管理.md) → [计划08](../plan/08-AI平台接入与预设管理实施计划.md)已补齐。细化预设版本、连接、模型发布组合与恢复流程；BytePlus仅保留调研参考，个人/团队BYOK不在首轮。当前仅文档，尚未实现或验收。

除以上已深化范围外，其余能力保留目录级范围，不沿用未重新评审的详细表结构、接口、Demo 优先级或排期。进入某个模块实施时，再围绕当次完整用户结果补需求与设计；不能据此删除已有业务数据或认定现有代码不可用。

## 跨模块要求

- 私有项目、画布、资产、主体、任务及下载逐项验证用户身份和对象权限；同属团队不等于个人资料可共享。
- 生成前展示实际模型、输入、费用或无法报价原因；未知回执先查询，不诱导重复收费。
- 候选、人工采用和发布分开；迟到结果不覆盖人工修改；私有内容不会因模板复用而公开。
- 刷新、断网、失败、取消及权限变化均有可理解状态；保存成功必须能从服务端读回。
- 明暗主题、手机和短屏、键盘与焦点管理属于共享交互要求；测试环境成功与真实业务接受分别记录。
- 发布、协作、会员积分及通知不因出现在目录中而自动获得外部写入或收费授权。
