# 画布协作编辑需求

## 1. 原始需求与确认

用户要求完整迁入Lucky画布能力，并明确：“切换我们当前的协作方案为Yjs 协作编辑”。应用服务统一通过Docker启动，保留现有基础依赖。协作能力支持免费生产使用和自托管。

原始多人编辑、个人贡献撤销、生成来源保护及跨端恢复需求保留，稳定身份沿用COL编号。数据与引用依赖[需求08](08-画布数据库持久化与DAG需求.md)，实时传输依赖[需求09](09-画布WebSocket实时同步需求.md)。

## 2. 用户与范围

同账号多端使用者、同项目获得授权的编辑者及只读访问者。覆盖节点、关系、Tiptap正文、引用、在线状态、个人撤销和版本恢复。

## 3. 功能需求

| ID        | 能力                                                           |
| --------- | -------------------------------------------------------------- |
| FR-COL-01 | 使用Yjs合并多客户端兼容编辑，同步节点、关系、富文本与引用      |
| FR-COL-02 | 撤销与重做本人的编辑，保留其他人的有效贡献                     |
| FR-COL-03 | 生成结果绑定发起时的输入和引用版本，保留后续用户输入及任务身份 |

在线成员、光标、选择与拖动预览实时可见并在离线后过期。历史版本可浏览，授权恢复生成新的持久版本。个人视图独立保存。

## 4. 业务规则

| ID        | 规则                                                             |
| --------- | ---------------------------------------------------------------- |
| BR-COL-01 | 每份画布具有唯一协作epoch和可核实的持久接受修订；各端最终收敛    |
| BR-COL-02 | 更新接受前校验权限、图、schema和引用，拒绝保持已接受数据完整     |
| BR-COL-03 | 创建、删除、属性、位置、尺寸、连线、分组和富文本均有明确并发语义 |
| BR-COL-04 | 乐观状态与持久状态区分，拒绝后可恢复已接受基线与本页输入         |
| BR-COL-05 | 撤销只作用于本人的贡献，并遵守当前权限、对象和素材约束           |
| BR-COL-06 | 编辑及系统回写使用统一接受合同，持久化与回执分别沿DATA和SYNC专项 |

## 5. 质量要求

| ID         | 要求                                                       |
| ---------- | ---------------------------------------------------------- |
| NFR-COL-01 | 排空未确认更新后，各端共享内容与数据库投影一致             |
| NFR-COL-02 | 兼容编辑完整保留，接受后的图合法，重复处理保持一次业务效果 |

未确认更新与恢复处理有资源上限；浏览器业务内容保留在本页内存，个人视图偏好按白名单持久化。生产容量以真实测量验收。

## 6. 验收

| ID        | 场景与结果                                                                                        |
| --------- | ------------------------------------------------------------------------------------------------- |
| AC-COL-01 | 两账号修改不同节点及同节点不同属性，兼容修改全部保留                                              |
| AC-COL-02 | 同字段、富文本、删除与编辑、依赖建立交错，结果符合设计规则且图合法                                |
| AC-COL-03 | A编辑后B编辑，A撤销与重做，保留B有效修改                                                          |
| AC-COL-04 | 生成期间产生新输入，结果保留原来源，新输入完整，任务与费用不重复                                  |
| AC-COL-05 | 三客户端并发和连续编辑，覆盖中文、emoji、IME、格式与引用，内容和引用身份一致                      |
| AC-COL-06 | 真实WebSocket提交后回执前断线，他端继续编辑；重连、服务重启与重开后数据库和各端一致，保存状态准确 |

补充检查在线状态过期、撤权、版本恢复、旧画布转换及同一画布写入通道隔离。
