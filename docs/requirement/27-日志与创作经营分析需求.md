## 4. 功能与边界（建议）

| ID        | 所需能力                                                            | 可观察边界                                                                                          |
| --------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| FR-LOG-01 | 统一记录系统生命周期、后台任务异常、请求完成与未处理错误            | 结构化、按环境/服务/角色/版本区分；请求有耗时与稳定错误码，预期业务拒绝不混为系统故障               |
| FR-LOG-02 | 按时间、服务、等级、错误码及请求/业务 ID 查询，查看脱敏上下文       | 默认有界时间窗和分页；记录缺失、过期、采集失败分别提示，不能把缺记录解释为未执行                    |
| FR-LOG-03 | 关联请求、Agent run/call、业务任务、供应商尝试、资产/交付及费用引用 | 原业务身份不因重试或重连改变；普通用户只见获授权的任务状态，不读取内部堆栈与秘密                    |
| FR-LOG-04 | 展示运行质量趋势、错误分布、延迟、积压、资源占用与恢复健康          | HTTP、业务任务与上游尝试各用自己的分母；展示采集完整性、时间范围和更新时间                          |
| FR-LOG-05 | 保留本人安全活动、团队与平台审计入口，并支持与诊断记录关联          | 不以短期运行日志代替审计；审计写入及失败处理遵守原业务事务合同，查询无编辑/删除动作                 |
| FR-LOG-06 | 分析访问/注册、首次创作、生成、采用、交付、再次创作与留存           | 漏斗与同期群明确对象、先后、观察窗；人工创作路径允许绕过生成，不强制虚构统一漏斗                    |
| FR-LOG-07 | 分析各创作入口、模态、模型、Agent/工作室阶段、资产复用和交付效果    | 业务单、尝试、产物、采用和交付分别计数；取消、部分完成、未知、等待不合并为失败                      |
| FR-LOG-08 | 分析用户与团队活跃、账号构成、付费转化、复购和权益使用              | 去重用户与付款空间分开，账号状态沿 FR-USER-24；平台汇总不自动开放私有内容                           |
| FR-LOG-09 | 分析充值实收/退款、积分来源与消费、采购成本、补贴、贡献利润         | 现金与积分面值分开；已知与待核对分开；收入分摊、手续费或采购缺失时不宣称真实利润                    |
| FR-LOG-10 | 用统一筛选查看概览、趋势和明细，按受控范围导出                      | 图表到明细保持同一范围/口径/快照；导出重查权限并审计，处理公式注入和数量限制                        |
| FR-LOG-11 | 保障分析事实去重、迟到更正、历史回补和版本可追踪                    | 不依赖可丢弃运行日志计收入；数据未接入显示未接入，分母为零显示不适用，未知不补零                    |
| FR-LOG-12 | 对所有采集、查询、关联与保留执行脱敏、授权和容量边界                | 禁记令牌、密码、完整私有提示词/正文、素材签名地址；不能靠日志页面跨组织读取；运行日志故障不阻塞创作 |

## 5. 完整范围与非目标

完整交付包括运行诊断、既有审计衔接、创作全流程分析、用户/团队分析、资金与成本分析、可视化明细及受控导出。分批建设不等于删除经营分析；尚未开放的支付、会员或制作能力须在页面标明未接入，不能通过补建报表暗中扩大其业务实现范围。

本专题不建公共日志 SaaS、查询语言、自助拖拽 BI、数据湖、第二套账本、全量会话回放、私有内容检索、用户画像评分或自动经营决策。营销归因只接受明确提供且获准的来源分类，不加入跨站追踪；告警规则平台与自动修复不在本次范围。
