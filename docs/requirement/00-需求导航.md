## 专项来源链

画布新增需求按三个独立目标拆分：08保证内容可靠保存及图合法，09保证变化实时传递与恢复，10保证并发编辑语义和收敛。08提供权威数据和持久回执；09消费这些能力；10消费版本与同步能力并调用08的图校验。数据库结构、消息协议和转换算法分别由各专项维护，避免重复规则。三项分别进入requirement → design → prd → plan，当前仅需求草稿；分开评审、分开验收不等于已承诺分批发布。

画布组件：[需求06](06-画布组件迁入与定制需求.md) → [设计10](../design/10-画布组件实现调研与迁入设计.md) → [PRD05](../prd/05-画布组件迁入与定制.md) → [计划13](../plan/13-画布组件迁入验证与定制实施计划.md)。核心实现与工程检查已完成，功能/非功能需求及目录见来源正文；真实业务接受与性能边界见计划13。
