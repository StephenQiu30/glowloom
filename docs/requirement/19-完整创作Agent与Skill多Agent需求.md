## 3. 核心场景

创作者导入一份剧本，解析 Agent 给出带来源定位的人物/场景/台词提案。用户修订后，制作协调 Agent 将已采用版本交给美术与分镜 Agent；相互独立的任务可并行，镜头生成必须等待相应参考确认。声音 Agent 与剪辑 Agent 只消费明确采用的素材与时间信息，形成可播放且可编辑的结果。

创作者安装并选择一份分镜 Skill，系统展示所需模型、工具与脚本权限。运行固定 Skill 版本；Skill 更新或停用后，新任务按新状态判断，旧任务继续持有历史版本引用或被明确撤销。用户把其中一个镜头改为夜景，只重做受该变更影响的步骤，已成功的其他镜头保留。

用户离开页面、运行时崩溃或某个子 Agent 失败后，可以回到原运行查看实际状态。父任务不在子 Agent 仅提交任务时宣称完成；停止必须说明哪些调度已停止、哪些供应商任务尚未确认取消。

## 4. 非目标与待评审细节

“完整”描述目标能力的闭环，不代表首个实现切片即可标记全部完成。不包含模型训练、自动发布成片到外部平台或开放任意宿主机 shell。对外 MCP/CLI 是扩展接入面，不能替代站内完整创作能力。

SDK 的具体版本、运行配额、脚本镜像、共享 Skill 的发布治理和部署容量由设计给出可评审默认值；不是另行向用户索取需求后才开始写文档。单主机故障恢复与跨主机高可用分别验收；本轮不能用“采用耐久 SDK”推断二者均已满足。
