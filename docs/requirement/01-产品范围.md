织光服务于围绕图片、视频、声音和画布开展创作的个人与内容制作者。主要旅程为：浏览灵感 → 登录或注册 → 开始对话，或新建画布并同时建立项目 → 引用素材与主体 → 提交生成 → 比较并采用结果 → 保存、导出或分享。项目与主画布的创建不是两个连续必经步骤。

产品功能与主要交互参考即梦，视觉与组件遵循 [DESIGN](../../DESIGN.md)。以下是织光的完整候选范围，不是竞品当前能力的核验报告，也不表示全部已实现或已排期。先保留完整能力覆盖，再决定各批次范围。首页推荐与活动内容可使用明确的设计占位；私有资产、账号、生成结果和收费状态必须来自真实服务。

## 3. 跨模块要求

- 私有项目、画布、资产、主体、任务及下载逐项验证用户身份和对象权限；同属团队不等于个人资料可共享。
- 生成前展示实际模型、输入、费用或无法报价原因；未知回执先查询，不诱导重复收费。
- 候选、人工采用和发布分开；迟到结果不覆盖人工修改；私有内容不会因模板复用而公开。
- 刷新、断网、失败、取消及权限变化均有可理解状态；保存成功必须能从服务端读回。
- 明暗主题、手机和短屏、键盘与焦点管理属于共享交互要求；测试环境成功与真实业务接受分别记录。
- 发布、协作、会员积分及通知不因出现在目录中而自动获得外部写入或收费授权。
