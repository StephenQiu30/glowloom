# 画布组件迁入与定制需求

## 1. 原始需求与确认

用户已明确：“先将画布的完整的能力迁移过来，后续再对页面进行优化和展示”；“切换我们当前的协作方案为Yjs 协作编辑”；“当前只需要对我们的画布完整的迁移过来，不要做任何的其他的动作”。

SRC-CAN-13：完整组件直接用于正式 `/canvas`，适配现有Go业务服务。界面和工程运行标识统一为织光/Glowloom，法定来源与许可保留。应用服务使用Docker，复用现有基础依赖。

## 2. 使用者与范围

面向创作者、项目协作者和只读访问者。完整能力包括节点编辑、媒体工具、生成与工作流、协作与恢复、个人视图、侧栏和项目交互。正文及全能参考统一使用Tiptap，协作使用Yjs，Go承接项目、权限、素材、任务及持久接受。

页面展示依据最终Figma稿，详见[设计10](../design/10-画布交互设计.md#77-页面展示)。功能迁入与页面优化分别验收；源码存在不等于功能已接受。

## 3. 功能需求

| 编号      | 需求                                                                                                                               | 范围与约束                                                                                                   |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| FR-CAN-01 | 平移、指针锚点缩放、适合屏幕、小地图定位与取消手势保持一致                                                                         | 覆盖鼠标、触控板、触摸；缩放区间按现有前端规则                                                               |
| FR-CAN-02 | 单选、框选、多选、批量移动与尺寸调整可预览、取消、一次提交                                                                         | 操作仅作用于可编辑节点；输入框、Tiptap、菜单与弹窗有独立事件作用域                                           |
| FR-CAN-03 | 节点与连线按可见范围渲染；媒体按需加载                                                                                             | 全部合法节点仍可被查找、定位和选择；不能因 DOM 预算静默丢失                                                  |
| FR-CAN-04 | 支持有明确事务边界的撤销、重做与复制                                                                                               | 本人撤销、版本历史和生成结果分开；不得绕过服务端删除限制                                                     |
| FR-CAN-05 | 接入文本、图片、视频、音频、分组、连线的成套编辑交互；支持素材导入、替换、预览、保存到素材库及下载，图片可裁剪、拆图和本地像素缩放 | 保留原件；媒体播放不误触拖动，处理取消或失败不清空输入；普通线不触发生成                                     |
| FR-CAN-06 | 节点、正文、素材引用、布局与关系由服务端保存和读回；个人视图独立保存                                                               | 保存与恢复遵守DATA/SYNC/COL合同                                                                              |
| FR-CAN-07 | 迁入Lucky完整画布能力，复用宿主组件与业务服务                                                                                      | 来源许可保留，功能优先于页面优化                                                                             |
| FR-CAN-08 | 旧画布可安全往返；保留画布导入导出及多选素材导出的使用体验                                                                         | 不支持的数据保留并明确限制，不过滤后另存为“成功”；画布包须包含可导出媒体，导入不覆盖原画布或沿用外部资产身份 |
| FR-CAN-09 | 按最终Figma稿统一画布布局及状态                                                                                                    | 覆盖空态、各类节点、菜单、参数、异常和窄屏                                                                   |
| FR-CAN-10 | 鼠标、触控板、触摸与键盘操作一致                                                                                                   | 选择、平移、缩放、编辑、取消和输入作用域明确                                                                 |
| FR-CAN-11 | 可见功能接入真实业务合同                                                                                                           | 包含生成、工作流、参考、历史、素材及迁入能力；不可用项如实呈现                                               |
| FR-CAN-12 | 真实浏览器逐项验收                                                                                                                 | 工程、夹具、数据库、真实媒体与供应商证据分别记录                                                             |
| FR-CAN-13 | 节点两侧创建同时新增定向布局线                                                                                                     | 左侧新节点→当前节点，右侧当前节点→新节点，一次可撤销编辑                                                     |
| FR-CAN-14 | 授权媒体可加入生成草稿                                                                                                             | 稳定素材身份与版本、同源防重、引用编号稳定，空节点不伪造来源                                                 |
| FR-CAN-15 | 全能参考模式与参考选择分开                                                                                                         | 模式遵循模型能力；Popover/Command区分画布、素材库、上传和主体                                                |
| FR-CAN-16 | 参考架提供预览、编号、状态、提及与移除                                                                                             | 移除引用不删除原素材；普通线不等于执行依赖                                                                   |
| FR-CAN-17 | 正式画布按账号、空间和项目打开主画布                                                                                               | 读取失败可重试，不用空图覆盖                                                                                 |
| FR-CAN-18 | 视口支持平移、锚点缩放、框选、小地图与适合屏幕                                                                                     | 个人视图不改变共享图修订                                                                                     |
| FR-CAN-19 | 节点支持创建、选择、移动、缩放及参数面板                                                                                           | 保持稳定身份和手势事务边界                                                                                   |
| FR-CAN-20 | 支持分组、拖入拖出、解组、撤销重做与复制                                                                                           | 遵守分组、引用和删除约束                                                                                     |
| FR-CAN-21 | 工具栏、菜单、多选操作跟随选择                                                                                                     | 控件通过统一编辑会话提交                                                                                     |
| FR-CAN-22 | 图像处理与创作面板复用素材、提示词和生成服务                                                                                       | 上传、授权、引用及任务身份不另建规则                                                                         |
| FR-CAN-23 | 正式产品移除Mock预览页面和调试入口                                                                                                 | 测试夹具隔离，不写真实项目                                                                                   |

## 4. 数据与业务规则

| 编号      | 规则                                                                                        |
| --------- | ------------------------------------------------------------------------------------------- |
| BR-CAN-01 | 服务端图与回执是保存事实；浏览器本地缓存不成为第二套业务持久化                              |
| BR-CAN-02 | 节点、媒体、归属与输入版本使用稳定身份；临时URL、Blob和播放器状态不作为媒体身份             |
| BR-CAN-03 | 原请求体与提交身份固定；未知结果先查证，必要时原样重试；本页未确认内容按身份隔离            |
| BR-CAN-04 | 删除与撤销遵守当前权限、对象保护和引用约束，不留下悬挂关系或隐式删除媒体                    |
| BR-CAN-05 | 布局边、生成引用与业务投影分别定义；框选、定位、复制、拖动和视口操作不得触发付费生成        |
| BR-CAN-06 | 当前图容量为 2000 节点、4000 边；它是协议上限，不是已实测流畅容量                           |
| BR-CAN-07 | 完整迁入节点、媒体工具、生成/工作流、协作与恢复、个人视图、侧栏和项目交互；未接通项如实记录 |

画布内容遵守[数据需求08](08-画布数据库持久化与DAG需求.md)，长连接遵守[同步需求09](09-画布WebSocket实时同步需求.md)，并发合并、本人撤销和版本恢复遵守[协作需求10](10-画布协作编辑需求.md)。个人视图按用户、空间、项目和画布隔离，只包含视口与偏好，不含正文、引用、素材地址或权限。

## 5. 非功能性需求

| 编号                      | 要求                                                                                                  | 验证方式                                                           |
| ------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| NFR-CAN-01 容量与可达性   | 保持2000节点/4000边协议上限；可见元素不因渲染数量预算截断，离屏元素仍可搜索、框选和定位               | 50/200/2000节点、稀疏/密集图及跨屏连线；查询结果与全量几何结果对照 |
| NFR-CAN-02 高频交互       | 原始指针事件不逐条触发整图状态更新或保存；rAF合并预览，连续平移期间刷新可见窗口，结束时提交相机       | 假时钟行为测试和浏览器连续手势；记录样本与耗时，不编造固定FPS      |
| NFR-CAN-03 持久可靠性     | 请求载荷/幂等键冻结，回执校验共享内容及版本，个人视图独立保存；后续编辑不被旧回执覆盖；恢复按身份隔离 | 超时重试、冲突、迟到回执、重开及恢复隔离测试                       |
| NFR-CAN-04 输入与可访问性 | V/Space、保存、撤销重做不抢中文输入和Tiptap历史；节点方向键移动；焦点/播放节点保留；窄屏控件可达      | 键盘、输入、弹层、320/390/768/1440px、深浅主题验证                 |
| NFR-CAN-05 媒体与生命周期 | 离屏非交互节点不挂载媒体预览，视频/音频仅选中时激活；切图、卸载、撤权释放监听、帧和请求               | 授权API请求、挂载数量及取消测试；浏览器生命周期检查                |
| NFR-CAN-06 工程与维护     | 画布复用宿主权限、素材与保存，不新增通用框架；保留来源与许可声明                                      | ESLint、类型、测试、构建、目录及依赖diff核验                       |

## 6. 验收场景

| 编号      | 动作与预期                                                                                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-CAN-01 | 画布文件、依赖和许可可核对；每项行为有消费者与验证                                                                                                                    |
| AC-CAN-02 | 鼠标/触控板连续平移缩放，触摸单指与双指操作；锚点正确，取消和失焦不遗留抓手状态                                                                                       |
| AC-CAN-03 | 多选移动、四角缩放、取消手势；预览不写服务端，结束形成一次编辑，锁定节点保持原限制                                                                                    |
| AC-CAN-04 | 编辑中文、选择素材、滚动面板及打开嵌套弹层；快捷键不抢输入，Escape逐层关闭并恢复焦点                                                                                  |
| AC-CAN-05 | 测试 50、200、2000 节点，稀疏/密集布局与四类媒体；定位所有节点，记录交互、挂载、解码和内存数据                                                                        |
| AC-CAN-06 | 未保存编辑撤销/重做/复制，保存后再撤销；受限操作明确不可用，复制不携带旧任务或执行身份                                                                                |
| AC-CAN-07 | 分组、组移动、解组与普通连线保存重开；世界坐标及父子关系一致，未支持的生成连接不显示可执行                                                                            |
| AC-CAN-08 | 编辑、断网、原请求查证、并发、切账号与切画布；持久回执准确，未确认内容不串身份                                                                                        |
| AC-CAN-09 | 图片/视频/音频素材导入、替换、预览、处理、素材库保存和下载可完成；取消、失败、失效及撤权不丢原件；派生图真实保存重开，媒体关闭释放资源；历史3D对象安全可读            |
| AC-CAN-10 | 生成按真实报价、确认、任务身份和结果采用合同验证；重试不重复生成或计费                                                                                                |
| AC-CAN-11 | 320/390/768/1440px、深浅主题、短屏、键盘；核心操作可达，浮层不随画布缩放成不可用尺寸                                                                                  |
| AC-CAN-12 | 读取旧画布及未知/只读对象后编辑保存，字段与边不丢失；图文、音视频、组和线导出后导入可继续编辑，身份独立；缺媒体或不支持版本明确反馈，不静默丢弃；多选素材导出核对原件 |
| AC-CAN-13 | 从节点左右创建，撤销重做并保存重开；方向正确，节点和布局线一次事务，不触发生成                                                                                        |
| AC-CAN-14 | 添加、提及、替换、移除授权参考并重开；编号稳定、同源防重、越权拒绝，原素材不被删除                                                                                    |
| AC-CAN-15 | 分组拖入拖出、取消、解组和复制，图片裁剪、拆图和缩放后保存重开；关系合法，失败保留输入，下载核对授权                                                                  |
| AC-CAN-16 | 正式画布组件按职责组织，产品标识统一为织光/Glowloom，法定来源声明保留                                                                                                 |
| AC-CAN-17 | 正式入口中的平移、选择、分组、撤销、图像处理与保存读回满足对应场景                                                                                                    |
| AC-CAN-18 | 正式与开发产品入口均不展示 Mock 预览页面、菜单和调试工具；测试夹具不得写入真实项目                                                                                    |
| AC-CAN-19 | 按来源功能清单验证编辑与素材旅程，覆盖正常、靠边、输入、加载和失败状态；差异有依据                                                                                    |
| AC-CAN-20 | 图片、视频、音频使用对应节点；上传不强加生成面板，正文、选择和撤销记录保持完整                                                                                        |
| AC-CAN-21 | 端口创建与拖线有目标反馈；完成、Escape、失焦及取消清理临时状态，空白松手不新增孤立节点                                                                                |
| AC-CAN-22 | 不同缩放、边缘及短屏下浮层不遮挡正文和确认/关闭入口，空间不足可滚动                                                                                                   |
| AC-CAN-23 | 编辑器输入、中文组合输入、文字选择、菜单滚动与画布拖动互不抢事件；多选移动保持相对位置，一次手势一次历史，取消不产生额外保存。                                        |
| AC-CAN-24 | 正式产品无 Mock 预览、节点数量测试、重置示例、退出预览或原始错误码。真实草稿读取失败保留现有正文和重试入口，正常加载不展示空白故障页。                                |

容量与性能阈值须由目标设备实测确认。工程、夹具、浏览器、数据库、真实媒体与供应商证据分别记录；未执行不标为通过。
