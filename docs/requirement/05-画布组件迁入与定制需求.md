## 2. 使用者与目标

创作者需要在同一画布组织素材和生成草稿，保留引用关系并继续创作；维护者需要可以追溯、升级和个性化修改的成熟实现。首先验证现有 BeefTV 适配能否扩展，避免已有保存与生成合同在替换组件时退化。产品确认人与实施责任人不补造姓名。

## 3. 功能需求建议

| 编号    | 需求                                                       | 范围与前提                                                                     |
| ------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------ |
| CAN-F01 | 平移、指针锚点缩放、适合屏幕、小地图定位与取消手势保持一致 | 覆盖鼠标、触控板、触摸；缩放区间先按现有前端规则，不直接采用上游上限           |
| CAN-F02 | 单选、框选、多选、批量移动与尺寸调整可预览、取消、一次提交 | 操作仅作用于可编辑节点；输入框、Tiptap、菜单与弹窗有独立事件作用域             |
| CAN-F03 | 节点与连线按可见范围渲染；媒体按需加载                     | 全部合法节点仍可被查找、定位和选择；不能因 DOM 预算静默丢失                    |
| CAN-F04 | 支持有明确事务边界的撤销、重做与复制                       | 文档历史、Tiptap 历史、恢复分支和生成结果分开；不得绕过服务端删除限制          |
| CAN-F05 | 接入文字、媒体、分组、连线所需的成套交互                   | 分组和视觉连接先核对现有命令；生成引用必须经正式业务合同，不把普通线当执行依赖 |
| CAN-F06 | 素材、草稿、参数与采用结果通过现有服务保存和读回           | 继续使用原命令幂等、revision、输入版本、冲突及未知回执恢复                     |
| CAN-F07 | 迁入代码可按项目视觉、组件和目录规则定制                   | 主来源固定到 commit；算法、Hook、样式、资源和必要测试按功能追踪                |
| CAN-F08 | 旧画布与新增能力之间可验证往返兼容                         | 不支持的数据保留并明确限制编辑，不过滤后另存为“成功”                           |

## 4. 数据与业务规则

| 编号    | 规则                                                                                                 |
| ------- | ---------------------------------------------------------------------------------------------------- |
| CAN-B01 | 服务端图与回执是保存事实；上游 Zustand/localForage/SQLite 不成为第二套业务持久化                     |
| CAN-B02 | 节点 UUID、媒体 `ref_id`、归属、权限与输入版本沿用现有合同；预览 URL、Blob、播放器状态不作为媒体身份 |
| CAN-B03 | 保存中的请求体与幂等键固定；结果未知重试原请求，冲突保留本地草稿，撤权后停止私有访问                 |
| CAN-B04 | 本轮不放开已保存生成草稿删除，也不以撤销新增为由绕过删除限制；已保存资源删除需先完成引用与回执设计   |
| CAN-B05 | 布局边、生成引用与业务投影分别定义；框选、定位、复制、拖动和视口操作不得触发付费生成                 |
| CAN-B06 | 当前图容量为 2000 节点、4000 边；它是协议上限，不是已实测流畅容量，不沿上游扩大                      |
| CAN-B07 | 不迁入上游模型凭据、供应商执行器、桌面后端和远程插件运行时；需要这些能力时另按所属领域设计           |

## 5. 验收场景建议

| 编号    | 前置、动作与预期                                                                               | 对应需求      |
| ------- | ---------------------------------------------------------------------------------------------- | ------------- |
| CAN-A01 | 固定上游 SHA，逐项追踪源文件、必要依赖、改写和许可；每个迁入动作有消费者与验证                 | F07           |
| CAN-A02 | 鼠标/触控板连续平移缩放，触摸单指与双指操作；锚点正确，取消和失焦不遗留抓手状态                | F01、F02      |
| CAN-A03 | 多选移动、四角缩放、取消手势；预览不写服务端，结束形成一次编辑，锁定节点保持原限制             | F02           |
| CAN-A04 | 编辑中文、选择参考、滚动参数及打开嵌套弹层；快捷键不抢输入，Escape 逐层关闭并恢复焦点          | F02、F04      |
| CAN-A05 | 测试 50、200、2000 节点，稀疏/密集布局与四类媒体；定位所有节点，记录交互、挂载、解码和内存数据 | F03           |
| CAN-A06 | 未保存编辑撤销/重做/复制，保存后再撤销；受限操作明确不可用，复制不携带旧任务或执行身份         | F04、F06      |
| CAN-A07 | 分组、组移动、解组与普通连线保存重开；世界坐标及父子关系一致，未支持的生成连接不显示可执行     | F05、F08      |
| CAN-A08 | 编辑保存、断网、原请求重试、并发冲突、切账号/切画布；真实回执正确，本地分支不串入其他身份      | F06、F08      |
| CAN-A09 | 图片/视频/音频/3D 素材失效、无权限或加载失败；可见反馈、可恢复，关闭后释放监听与临时资源       | F03、F06      |
| CAN-A10 | 使用现有真实报价、确认和结果采用流程；来源版本冻结，重复点击和未知回执不重复生成               | F06           |
| CAN-A11 | 320/390/768/1440px、深浅主题、短屏、键盘；核心操作可达，浮层不随画布缩放成不可用尺寸           | F01、F02、F07 |
| CAN-A12 | 读取旧画布及含未知/只读业务节点的画布后编辑保存；受保护字段与边不丢失，错误不伪装成功          | F08           |

CAN-A05 的通过值需先在目标设备建立基线再确认，当前不承诺固定 FPS 或内存值。Mock、单元、浏览器、数据库、真实媒体和供应商接受分别记录。
