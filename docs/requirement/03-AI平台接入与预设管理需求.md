## 1. 目标与边界

管理员选择内置平台预设、填写 API Key 后，即可配置可用的 AI 服务，并能管理预设、连接和模型。创作者在编辑器中使用已启用的能力，无须填写平台协议和请求 JSON。对应产品范围 JM-05、JM-08～10、JM-24～25、JM-30～31。

Seedance 是模型系列；火山方舟是火山引擎的模型服务平台；OpenRouter 是聚合平台。模型与平台分别建模。平台连接预设不等于提示词模板或风格预设。BytePlus 保留为调研对象，不进入首轮接入与验收范围。

“填 Key 即可使用”的前提是：平台账号已开通目标模型、有额度、区域匹配，且织光已部署对应适配器并发布模型能力与价格。正常路径只要求填 Key，缺失条件应给出具体修复入口，不能用“连接成功”代表可生成。

首轮所有连接归平台所有，由平台管理员维护 Key、预设、模型及默认配置；上游费用由平台账号承担，创作者的额度预留与平台结算沿用 billing 合同。个人/团队 BYOK 不在首轮范围。团队管理员没有平台配置权限；授权接入用户系统的平台管理员合同，不复用旧 org admin 身份作为替代。

本次实施基线为火山 Seedance 视频，以及 OpenRouter 的文本、图像、视频三类协议；每条链路至少选择一个实际开通模型完成验证后再开放。不是承诺两平台的全部模型、全部模式均可用。多参考、首尾帧等按已发布能力逐模式验收；音频独立生成、火山其他模型系列及第三平台在后续范围。

## 2. 对象与职责

| 对象         | 用户理解                                  | 关键边界                                                 |
| ------------ | ----------------------------------------- | -------------------------------------------------------- |
| 平台预设     | 火山方舟、OpenRouter 等可复用配置模板     | 不含 Key；包含协议、地址、区域、凭据字段和模型模板引用   |
| 平台连接     | 如“火山方舟生产账号”“OpenRouter 测试账号” | 一个预设可建立多个连接；有独立凭据、额度、健康和启用状态 |
| 模型配置     | 某连接上的某个模型及其版本                | 包含输入/输出、模式、限制、参数、价格与验证状态          |
| 生成参数预设 | 如“竖屏短片”                              | 只引用模型及合法参数；本轮不扩展为提示词市场             |

## 3. 功能与业务规则

| 编号     | 需求与规则                                                                                         | 验收     |
| -------- | -------------------------------------------------------------------------------------------------- | -------- |
| AI-FR-01 | 预设列表按平台名称/别名搜索，按图像/视频/文本/音频、区域筛选；显示维护来源、版本和适配状态         | AI-AC-01 |
| AI-FR-02 | 选择预设自动填写地址、协议、区域和推荐模型；基础表单仅暴露必填凭据；高级配置可展开                 | AI-AC-02 |
| AI-FR-03 | 同平台创建多个命名连接，分别测试、启用、停用、更新 Key、查看使用情况                               | AI-AC-03 |
| AI-FR-04 | 支持自定义预设的新建、复制、编辑、发布、停用、归档、导入与导出；内置预设通过派生副本修改           | AI-AC-04 |
| AI-FR-05 | 已发布预设版本不可原地修改；升级前展示差异和影响，逐连接应用；可回退兼容版本                       | AI-AC-05 |
| AI-FR-06 | 凭据测试分别报告配置合法性、鉴权、模型发现；免费检查不支持时如实提示；收费试运行单独发起并展示预算 | AI-AC-06 |
| AI-FR-07 | 模型发现仅生成候选目录；管理员确认能力、价格和验证状态后发布，支持手动补充模型 ID                  | AI-AC-07 |
| AI-FR-08 | 创作参数由已发布模型能力驱动；切换时显示失效引用/参数及新报价，禁止静默丢引用或降级                | AI-AC-08 |
| AI-FR-09 | 支持按能力指定默认连接/模型；多连接共存；明确提交目标。首轮固定选择，自动路由为后续建议            | AI-AC-09 |
| AI-FR-10 | 任务保存提交时配置与计费版本；连接停用或预设紧急停用阻止新提交，已派发任务保留查询、转存及结算路径 | AI-AC-10 |
| AI-FR-11 | 超时或回执不明展示“状态待核实”；先恢复查询，无法查证时保留待核实，不自动再次提交或换供应商         | AI-AC-11 |
| AI-FR-12 | 管理员查看测试时间、失败分类、任务成功率、延迟、用量和成本来源；不暴露原始 Key 或完整敏感请求      | AI-AC-12 |

AI-BR-01：启用开关、鉴权健康、模型可用性、适配器运行状态独立，不能压缩成一个绿色状态点。

AI-BR-02：预设发布和连接写入须服务端授权、版本冲突检查及审计；团队成员不得读取或修改平台共用凭据。BYOK 若进入后续范围，每次操作必须检查连接归属和当前成员权限。

AI-BR-03：Key 只写入不回显；复制连接时不复制 Key；导出不含 Key、密文、凭据引用、签名 URL、私有素材或账号账单。导入后默认未启用，预览差异后保存。

AI-BR-04：自定义预设只能选择已部署的受支持协议，不能执行脚本或通过 JSON 发明新协议。改变地址、区域、协议或关键模型配置后必须重新验证。

AI-BR-05：默认连接按能力设置。不存在一个同时适合聊天、图片和视频的全局“当前平台”；设置默认项不修改正在运行的任务。

AI-BR-06：价格未知、货币不明或无法形成预算上限时，不能展示虚构报价或自动放行收费任务。上游成本、平台收费、额度预留和最终结算分别记账。

## 4. 数据与质量要求

- AI-DR-01：保存预设来源、版本、更新时间、连接快照及覆盖字段；模型配置保存上游 ID、能力版本、价格版本与最近核验时间。
- AI-DR-02：任务绑定连接、模型版本、价格版本、凭据版本引用及请求标识；密钥明文只存在于必要的短时服务端调用内，不进入浏览器返回、日志或工作流历史。
- AI-DR-03：有关联任务/连接的对象归档而不硬删除；未发布且未被引用的草稿可删除。回退不恢复已撤销凭据或已下架模型。
- AI-NFR-01：同一操作幂等重放不产生额外连接、模型发布或收费提交；并发修改冲突必须显式返回。
- AI-NFR-02：模型发现和测试有超时、并发和频率限制；上游故障不阻塞其他连接管理。
- AI-NFR-03：自定义地址和媒体下载校验协议、域名、解析地址及重定向，阻断内网探测；鉴权头不跨域转发。
- AI-NFR-04：管理页具备空状态、加载、无权限、冲突、过期、部分失败与未保存状态；支持键盘及明暗主题，手机可完成添加 Key。

## 5. 接受条件

| 编号     | 可观察证据                                                                          |
| -------- | ----------------------------------------------------------------------------------- |
| AI-AC-01 | 搜索火山/方舟/Volcengine/OpenRouter 可定位预设，未部署适配器的预设明确显示不可启用  |
| AI-AC-02 | 已具备开通和额度的测试账号按预设只填 Key，完成验证与启用；无须编辑 URL/JSON         |
| AI-AC-03 | 同平台两个连接可独立停用、轮换 Key；查询历史任务仍定位原账号                        |
| AI-AC-04 | 自定义预设 CRUD、复制和导入导出可读回；内置原件不被覆盖；导出无秘密                 |
| AI-AC-05 | 预设 v2 发布后旧连接与运行任务保持 v1；显式升级和回退有差异、冲突与审计证据         |
| AI-AC-06 | 错 Key、超时、不支持免费检查分别展示；点击普通测试未产生生成调用或收费              |
| AI-AC-07 | 模型列表发现成功不自动全量上架；无权限模型不能冒充可生成；手工配置仍须验证          |
| AI-AC-08 | 多参考编辑器切模型时准确指出不支持的引用角色/数量；确认前不提交新请求               |
| AI-AC-09 | 文本与视频分别使用各自默认连接；用户选择固定模型后不会后台更换                      |
| AI-AC-10 | 运行中修改/停用连接、轮换密钥、停用预设均不改写已提交任务参数；不可恢复时有明确原因 |
| AI-AC-11 | 模拟“上游已接收、响应丢失”后，无第二次收费提交；迟到回调和查询仅结算一次            |
| AI-AC-12 | 普通成员越权被拒；日志、接口与导出未泄密；管理指标区分供应商成功与结果已转存        |

真实供应商接受覆盖火山 Seedance 视频、OpenRouter 文本/图像/视频四条执行链路。每条链路的模型、模式、账号、样本及预算由实施任务 A0 固定；未通过的链路保持未开放，不能称首轮全部完成。检查证据分为文档核验、契约 fixture、隔离库、浏览器、真实付费任务及产品接受，互不替代。此次设计与计划编写不授权真实收费调用。

## 6. 已确认范围与剩余运行参数

已确认：平台管理员统一配置 Key；火山引擎和 OpenRouter 首轮接入；继续预设与适配器方案；本轮只交付文档。无需再次确认这些方向。

运行前需固定：实际账号可用模型 ID、地区、上游价单/平台售价、预算上限、真实测试素材和活动执行端部署信息。它们是计划 A0 的输入，不阻止本轮文档完成；不编造默认生产模型或试运行预算。平台管理员权限依赖用户系统实现，缺失时不得开放管理入口。

| AI-AC-16 | 只有明确确认的试运行产生一次任务；未上线候选可以由管理员测试但不能被普通用户调用；预算超限不派发                     |
| AI-AC-17 | 轮换后新任务用新 Key，旧任务只凭既有任务绑定使用旧 Key；紧急撤销后恢复调用也被拒绝，不能通过回退配置复活             |
| AI-AC-18 | 归档预设不会关闭已有模型；紧急停用阻止尚未派发的调用，但保留已派发任务恢复；两操作的提示与审计不同                   |
| AI-AC-19 | 默认版本替换/停用后，旧报价确认与停用并发具有确定结果；过期报价要求重新核对成本，不静默换模型；运行任务不改写        |
| AI-AC-20 | 团队管理员访问预设/连接/测试/发现/模型发布接口全部被拒；普通创作者仅拿到公开安全投影，跨项目引用仍被拒               |

AI-BR-07：保存连接的默认状态为 disabled；模型发布组合未验证时仅允许管理员受预算控制的试运行。启用条件为目标配置合法、执行器可用、凭据未撤销、价格有效、该组合的验证覆盖目标模式；免费探测 unsupported 不伪装鉴权成功，但成功的受控试运行可补足该组合的验证证据。

AI-BR-08：新任务的提交资格检查与派发许可记录须具有确定事务顺序。停用先完成则未派发任务停止并释放未消耗预留；派发许可先取得则按可能已提交处理并继续恢复。不能承诺停用瞬间撤回已经在网络中的请求。

AI-BR-09：候选版本验证成功后仍须管理员启用。修改上游模型 ID、端点、参数约束或转换协议使旧验证证据不适用于新组合；仅改显示名称不要求重新付费验证。Key 轮换需要新凭据鉴权/权限验证，不要求无条件重新跑所有收费样本。

AI-DR-04：验证证据绑定连接配置版本、模型版本、模式/样本摘要、执行器版本和测试凭据 ID；上线组合绑定模型/价格/配置版本。价格变更重新报价，不自动复用旧报价授权。

AI-NFR-05：管理写入成功须可从服务端读回；重放响应不含 Key；审计记录操作者、动作、对象和版本差异的安全摘要，不复制完整请求体。

## 8. 管理动作权限与生命周期

| 动作                                    | 平台管理员                                                   | 团队管理员/个人与团队创作者      |
| --------------------------------------- | ------------------------------------------------------------ | -------------------------------- |
| 维护预设、连接、Key、价格、模型、默认项 | 允许，服务端复核当前权限                                     | 禁止，包括只读管理接口           |
| 测试连接、发现模型、运行收费验证        | 允许；收费验证另行明确确认并受预算约束                       | 禁止                             |
| 查看已启用模型/参数与创作报价           | 允许；创作仍按项目权限                                       | 允许读取安全投影并按项目权限创作 |
| 查看任务、结果和费用                    | 按既有任务/治理权限，不因管理 Key 自动获得全部私有素材访问权 | 仅获授权对象                     |

预设：草稿可编辑/删除，发布版本不可变，归档保留引用，紧急停用单独记录。连接：停用、启用和归档独立于探测健康；引用历史的连接不能硬删。模型：候选、已验证、已启用、下架分开；验证是证据状态，启用是产品决策。创建、复制和导入均默认不对创作者开放。
