# 统一顶栏与阶段入口设计

更新：2026-10-21（结构整理）；文档确认状态沿原来源，未重新认定方案接受。

## 1. 摘要

通过统一布局、顶栏、搜索、创作入口及共享组件完成工作台操作。

本文按设计、用户故事与测试场景结构整理。原需求、确认结论和历史验证沿来源记录保留；当前实施进度、剩余工作及阻塞项统一见 [BACKLOG](../../BACKLOG.md)。

### 1.1 产品定义：摘要

来源：原PRD《11-统一工作台与创作入口》第1节。

让创作者从统一工作台浏览内容、输入想法、选择项目并继续创作，在页面和创作类型之间切换时保留输入，清楚知道哪些能力可以使用。把现有共享布局、首页富文本、内容浏览和计费入口连成可验收的用户流程。

## 2. 参与者

使用者与参与职责：工作台创作者及共享布局、页面消费者。维护职责及确认人沿下方原来源记录；未给出姓名的，不补造人员或排期。

### 2.1 产品定义：目标用户

来源：原PRD《11-统一工作台与创作入口》第4节。

首轮聚焦准备开始创作的访客，以及已有项目、需要找回输入和素材的登录创作者。管理员仍使用既有授权入口，不在本专项重做后台治理。无访谈或量化使用基线，不推定所有用户偏好。

### 2.2 需求原文与规则：用户、场景与范围

来源：原需求《11-统一工作台与创作入口需求》第2节。

创作者需要在浏览灵感、输入、选择项目、引用资产和继续画布之间切换，保留自己的输入并理解可用能力。未登录访客可以浏览公开内容、编辑允许保留的本地文字；私有数据、引用和生成仍走现有身份及项目权限。管理员沿既有授权进入管理页面。

本批覆盖共享布局与这些能力的页面入口。完整社区发布、主体生命周期、批量导出、消息系统、钱包支付及音乐/音频等生成产品不在本批承诺内。

## 5. 使用场景

参与者为工作台创作者及共享布局、页面消费者；在下方定义的输入、对象状态、权限和环境条件具备时执行相应操作。各故事按其独立前置条件核对，不能把测试夹具当成真实业务条件。

### 5.1 状态与交互

来源：原设计《09-统一顶栏与阶段入口设计》第5节。

默认主题为 dark，与深色页面设计一致。首次访问、无浏览器偏好、新注册账号，以及账号偏好暂不可读时均以深色展示；已有 light、dark、system 选择继续按真实偏好恢复。改变默认值不批量更新已有账号，也不将用户明确选择的 system 解释为 dark。新库快照及增量迁移同步默认值，历史迁移保持原样。

| 状态       | 左侧                         | 搜索              | 右侧                  |
| ---------- | ---------------------------- | ----------------- | --------------------- |
| 桌面已登录 | 当前页面                     | Command 入口、Kbd | 通知、主题切换、头像  |
| 桌面未登录 | 当前页面                     | Command 入口、Kbd | 主题切换、登录 / 注册 |
| 手机已登录 | 导航按钮、品牌图标、当前页面 | 搜索图标          | 通知、主题切换、头像  |
| 手机未登录 | 导航按钮、品牌图标、当前页面 | 搜索图标          | 主题切换、登录 / 注册 |

未登录时，公共布局唯一的登录 / 注册入口位于顶栏右上角，复用原认证弹窗。侧栏展开、图标收起和手机抽屉均只展示导航，移除底部登录按钮及登录引导。手机从顶栏打开认证，关闭后恢复到原登录按钮。

不标注游客模式，不展示示例积分或未读数。未接入能力沿用原可用性弹窗，不虚构功能状态。头像菜单复用账号摘要、资产、我的画布、密码、主题及退出；管理员入口继续依赖真实角色。

主题切换在登录前后均可使用，复用 shadcn Button + DropdownMenuRadioGroup/RadioItem 与现有 next-themes Provider。可选择浅色、深色、跟随系统，选中项具有可见标记；复用已有偏好存储与水合保护。游客选择保留在当前浏览器；已登录选择读取现有偏好及 revision，保留提示词后缀，通过既有偏好更新接口保存后读回，再应用主题。保存期间阻止重复操作；失败使用 Sonner 提示，不假装保存成功。会话恢复仅在账号变化时执行，不随主题 setter 引用变化反复覆盖用户选择。手机主题选项至少 44px。菜单支持方向键、Enter、Escape 和触发按钮焦点恢复；通知、主题和头像各自保留可访问名称。退出沿用原确认与撤销会话流程。移除公共顶栏下方 SpaceSwitcher，不改动服务端接口或授权校验；已有创作归属保持真实读取，不静默改写私有草稿或项目归属。

## 7. 方案

### 7.1 结构与视觉

来源：原设计《09-统一顶栏与阶段入口设计》第3节。

顶栏高 64px，固定在内容区域顶部，左侧显示当前页面名称，右侧集中放置账号相关操作。与展开 240px、收起 64px 的侧栏共同适配剩余宽度。背景、文字和交互状态使用现有语义 token，顶栏底部不显示分隔线；不增加宣传文案、营销色或第二层工具条。

桌面内边距 24px，操作间距 8px：通知与主题切换使用 ghost 图标 Button，头像使用现有 AccountMenu。积分、会员及对应的更多操作入口不属于当前阶段，不在顶栏或菜单展示。图标使用 Lucide，品牌复用 BrandMark。页面名称来自现有路由配置，不维护第二份标题列表。搜索统一放在 Header，页面筛选和创建操作保留在正文。

### 7.2 BasicLayout 与搜索

来源：原设计《09-统一顶栏与阶段入口设计》第4节。

普通页面统一使用 BasicLayout，组合官方 SidebarProvider、Sidebar、SidebarInset、共享 ProductHeader，以及当前页面内容。统一侧栏宽度、收起偏好、移动抽屉、跳转主内容和认证弹窗；不为每个页面复制布局。Header 不出现边框或阴影，搜索控件保留必要的焦点反馈。沉浸式画布编辑器保留原项目工具栏与保存逻辑。

按用户补充要求，桌面和手机均使用官方 shadcn CommandDialog + CommandInput + CommandList/CommandGroup/CommandItem。桌面顶栏为不超过 360px 的 Button 搜索入口，配合 Kbd 显示平台快捷键；手机保留 44px 图标入口。⌘K / Ctrl+K 快速唤起或关闭；密码输入和其他已打开弹窗不抢焦点。弹窗按当前页面明确搜索范围，Enter 执行搜索，方向键选择页面跳转，Escape 关闭并恢复原焦点。输入法组合输入期间不提交，清除同时恢复完整列表。请求错误沿用 Sonner；不在顶栏增加错误横幅。

首页和探索筛选现有灵感示例；资产通过原 search 参数、我的画布通过原 q 参数查询服务端；主体仍只搜索当前项目中已加载的主体，提示词明确范围。其他普通页面的搜索跳转到探索，并携带关键词。保留资产类型、目录、收藏、排序和回收站，搜索不触发任何写操作；资产命令结果未确认时继续禁止更改搜索。正文不重复展示同一个搜索框。页面独立使用图库或主体选择器时，保留其原局部搜索。

验收覆盖搜索提交与清除、原接口参数、中文输入法、手机弹窗焦点恢复，以及 320/390/768px 和桌面侧栏展开/收起。设计组件：HeaderSearch、BasicLayout 展开/收起，复用原 Header 组件与页面实例。

### 7.3 响应式与可访问性

来源：原设计《09-统一顶栏与阶段入口设计》第6节。

768px 以下使用紧凑布局：两侧 16px，图标触发区域至少 44px，品牌图标 24px，标题允许省略；360px 以下将页面名称保留为读屏文本，避免出现半个汉字。320px 仍保留导航、搜索、主题与登录或账号入口。长标题提供完整 title，不挤压操作。菜单与搜索弹窗限制视口宽度和高度，短屏内部滚动。内容滚动时顶栏可用；移动导航抽屉关闭后恢复到导航按钮，认证弹窗沿用现有焦点管理。

### 7.4 布局职责、状态与一致性补充（2026-10-20整理）

来源：原设计《09-统一顶栏与阶段入口设计》第8节。

本专项解决普通换页的布局连续性和统一入口，不创建新的业务归属或账户权限。选用根级ApplicationLayout与复用BasicLayout，是为了让侧栏偏好、滚动和全局弹窗在普通换页时保持一致；沉浸画布仍有自己的项目工具栏，避免把工作台顶栏和编辑器工具叠加。视觉参数及最新版布局以文首2026-10-19记录为准；Figma节点/页面的接受范围由设计09对应设计记录定位，本文未重新读取设计稿。

| 模块                           | 职责与状态事实                                                   | 依赖与输出                                                    |
| ------------------------------ | ---------------------------------------------------------------- | ------------------------------------------------------------- |
| ApplicationLayout/BasicLayout  | 路由布局、稳定侧栏、正文滚动及认证流程；不拥有项目或账户业务数据 | 依赖现有路由、SidebarProvider、认证及权限Provider             |
| ProductHeader/CommandDialog    | 当前页名称、单图标搜索触发、主题/账号入口；搜索范围显式说明      | 页面注册搜索回调，切换即清旧回调；导航和查询不写业务对象      |
| PageLayout及页面消费者         | 声明正文/全宽和本页搜索，拥有结果加载/空/错误及恢复入口          | 资产search、项目q等沿原合同；迟到结果须仍属于当前页面/查询    |
| SessionGate/SpaceGate/偏好接口 | 服务端会话、真实归属和主题revision仍是权威事实                   | 菜单可见性不授予API权限；保存后读回偏好再应用                 |
| DataPagination                 | 本页大小/页号和选择状态                                          | 12/24/48及0/0沿原记录；写入结果未知时禁止翻页，不能放弃原回执 |

布局临时状态为展开、抽屉、焦点、滚动和搜索输入；不写入项目、画布或成员关系。侧栏偏好从原cookie初始化，主题沿现有游客存储/账号偏好接口；不新增主题表或全局第二份标题表。搜索请求、页面和账号变化都须使旧回调/结果失效，不能让上一页查询或上一账号私有结果进入新页面。

| 失败/状态            | 用户反馈与恢复                                                                  | 验证入口                                           |
| -------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------- |
| 首次恢复/偏好不可读  | 按原水合保护和默认主题展示；私有区域等待身份，不短暂展示旧账号                  | 登录/退出、深浅主题及重载                          |
| 搜索空/网络失败      | 空结果限于已声明范围；失败保留重试，不显示成空库或成功                          | 原search/q参数、取消与迟到响应                     |
| 主题保存中/冲突/失败 | 阻止重复；失败保留已确认偏好，409重读revision后让用户再选，不自动覆盖另一端偏好 | 已登录偏好接口、断网/409；接口状态须按实际合同核对 |
| 菜单、导航或认证关闭 | 恢复原触发器焦点；短屏局部滚动，中文组合不提交                                  | 键盘、IME、320/390/768及短屏                       |
| 退出或权限改变       | 沿既有会话撤销/缓存清理，管理员条目消失不代替服务端拒绝                         | 身份切换、直接URL及真实权限反例                    |

### 8.1 2026-10-19 布局落地更新

来源：原设计《09-统一顶栏与阶段入口设计》第1节。

最新 Figma 及用户本轮指令优先于下面的历史阶段限制。全站沿用 shadcn Radix Nova、Vercel Geist、Lucide 和中性色 token；搜索入口保持单个图标 Button。完整页面落地次序见[实施设计09](#1-摘要)。

根级 Providers 内的 ApplicationLayout 依据路由选择普通工作台、独立安全页面或沉浸式画布；普通换页保留同一个 BasicLayout。BasicLayout 只组合 SidebarProvider、ProductSider、SidebarInset、ProductHeader、独立正文滚动区域、认证及退出流程。页面使用 PageLayout 声明正文、全宽模式及当前页面搜索，不再重复挂载壳组件。管理员与访客策略继续由 SessionGate 校验，SpaceGate 继续控制创作归属；不因视觉重构放开私有接口。

Header 为 64px 固定高度，展开/收起侧栏为 240/64px。工作台高度为 100dvh，只有正文滚动；滚动槽只在正文预留，避免根元素和正文重复占位。页面切换清理旧搜索回调并重置正文滚动；侧栏初始偏好由服务端读取已有 cookie，客户端订阅后继续保持同一状态，避免先展开再收起。手机仅保留 Sheet 导航，不重复渲染横向主导航。品牌默认使用设计稿的单色版本。

ProductFooter 在账号恢复/重设密码页面提供既有服务条款与隐私政策链接，不在工作台追加设计稿不存在的底部操作栏。会员积分后续按最新设计接入真实服务数据，原型余额和未定价套餐不作为运行数据。

数据集合统一使用公共 DataPagination：默认每页 12 项，可选 12/24/48，右侧排列；空集合为 0/0，前后翻页不可用。批量选择只涵盖当前页，切页清空选择，写入结果未确认时禁止改变分页。素材库与探索已接入，其他数据页按实施计划迁移。示例图保持原色并标注 AI 生成，私人素材仍来自原服务接口；空状态在正文剩余区域居中。
