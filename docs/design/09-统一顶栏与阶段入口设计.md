# 统一顶栏与阶段入口设计

## 1. 摘要

通过统一布局、顶栏、搜索、创作入口及共享组件完成工作台操作。

## 2. 参与者

使用者与参与职责：工作台创作者及共享布局、页面消费者。维护职责及确认人沿下方原来源记录；未给出姓名的，不补造人员或排期。

原始需求：[11-统一工作台与创作入口需求](../requirement/11-统一工作台与创作入口需求.md)。关联需求与验收：[11-统一工作台与创作入口](../prd/11-统一工作台与创作入口.md)。本文维护技术合同；相关实施步骤与证据见 Plan，状态与调度见 [BACKLOG](../../BACKLOG.md)。

## 4. 目标

通过统一布局、顶栏、搜索、创作入口及共享组件完成工作台操作。目标的规则、量化条件与非目标沿需求原文及下方已确认设计，不增加未经确认的指标。

### 4.1 范围

首页、探索、资产、主体、我的画布及账号/管理页面共用一个 ProductHeader。个人空间按已确认范围提供入口；团队空间、团队和邀请的入口范围保持待决，保留现有服务接口、权限和创作归属逻辑，不删除后台能力。沉浸式画布保留项目名称、保存与冲突反馈工具栏，不叠加全局账号顶栏。

## 5. 使用场景

参与者为工作台创作者及共享布局、页面消费者；在下方定义的输入、对象状态、权限和环境条件具备时执行相应操作。各故事按其独立前置条件核对，不能把测试夹具当成真实业务条件。

### 5.1 状态与交互

素材库的收藏是列表筛选，不是独立页面。启用后入口使用共享 secondary 选中样式、实心收藏图标和关闭符号，可再次点击解除；列表上方始终保留“返回素材”，加载、空结果和读取失败时也不能隐藏。退出仅解除收藏，保留类型、时间、排序、搜索与所在文件夹；不取消素材本身的收藏。回收站沿用相同返回方式，与收藏互斥。窄屏即使收起次要操作，返回入口仍可见且点击区域至少 44px。参考 2026-10-25 即梦资产页实测：收藏位于筛选菜单，勾选后触发器改为“收藏”，取消勾选后恢复“筛选”。

默认主题为 dark，与深色页面设计一致。首次访问、无浏览器偏好、新注册账号，以及账号偏好暂不可读时均以深色展示；已有 light、dark、system 选择继续按真实偏好恢复。改变默认值不批量更新已有账号，也不将用户明确选择的 system 解释为 dark。新库快照及增量迁移同步默认值，历史迁移保持原样。

| 状态       | 左侧                         | 搜索              | 右侧                  |
| ---------- | ---------------------------- | ----------------- | --------------------- |
| 桌面已登录 | 当前页面                     | Command 入口、Kbd | 通知、主题切换、头像  |
| 桌面未登录 | 当前页面                     | Command 入口、Kbd | 主题切换、登录 / 注册 |
| 手机已登录 | 导航按钮、品牌图标、当前页面 | 搜索图标          | 通知、主题切换、头像  |
| 手机未登录 | 导航按钮、品牌图标、当前页面 | 搜索图标          | 主题切换、登录 / 注册 |

未登录时，公共布局唯一的登录 / 注册入口位于顶栏右上角，复用原认证弹窗。侧栏展开、图标收起和手机抽屉均只展示导航，移除底部登录按钮及登录引导。手机从顶栏打开认证，关闭后恢复到原登录按钮。

不标注游客模式，不展示示例积分或未读数。未接入能力沿用原可用性弹窗，不虚构功能状态。头像菜单复用账号摘要、资产、我的画布、密码、主题及退出；管理员入口继续依赖真实角色。

主题切换在登录前后均可使用，复用 shadcn Button + DropdownMenuRadioGroup/RadioItem 与现有 next-themes Provider。可选择浅色、深色、跟随系统，选中项具有可见标记；复用已有偏好存储与水合保护。游客选择保留在当前浏览器；已登录选择读取现有偏好及 revision，保留提示词后缀，通过既有偏好更新接口保存后读回，再应用主题。保存期间阻止重复操作；失败使用 Sonner 提示，不假装保存成功。会话恢复仅在账号变化时执行，不随主题 setter 引用变化反复覆盖用户选择。手机主题选项至少 44px。菜单支持方向键、Enter、Escape 和触发按钮焦点恢复；通知、主题和头像各自保留可访问名称。退出沿用原确认与撤销会话流程。移除公共顶栏下方 SpaceSwitcher，不改动服务端接口或授权校验；已有创作归属保持真实读取，不静默改写私有草稿或项目归属。

## 6. 价值

相同交互在各页面保持一致，失败时保留输入和可恢复上下文。

## 7. 方案

### 7.1 结构与视觉

普通工作台由 Header、Sidebar 与正文滚动区组成。Header 不重复显示页面名称，标题与页面动作归 PageHeading；搜索、主题、通知与账户顺序固定。尺寸与组件规则见第7.10节，背景、文字和交互状态使用既有语义 token，无额外装饰边框或营销色。

搜索放在 Header，页面筛选和创建操作保留在正文。会员状态复用固定账户插槽，余额与能力由服务端事实决定；不以原型内容开放付费能力。

### 7.1.1 深色层级与工具栏（2026-10-25）

参考即梦资产页实测的计算样式：主内容 #121212、侧栏 #171717、弹出菜单 #262626，侧栏选中采用白色8%叠加。织光沿用中性灰层级：background #121212、sidebar #171717、card #1C1C1C、popover #262626、muted #222222、accent/selected #2A2A2A、border #333333。foreground #EDEDED、muted-foreground #A1A1A1保持原定义；正文与次要文案不使用降低整体透明度的方式实现层级。浅色值保持原合同。

直接更新现有语义变量及别名，沉浸画布沿共享background，工具面板沿surface；不将所有表面统一抬亮，不增加包围整页的边框。弹窗、下拉与内容卡片有明确底色区分。

页面标题与创建/上传操作位于同一行；下一行按“媒体类型 / 筛选条件 / 已选条件”分组，组间24px、组内8px。下拉按钮文字在左、16px箭头在右；桌面高度36px、左右内边距12px。类型组与筛选组之间仅使用短分隔线。收藏返回保持独立可见；标题行右侧的主操作与内容右边缘对齐。主体库复用相同筛选组。窄屏沿既有44px触控规范，必要时横向滚动类型组，不压缩文字和命中区域。

### 7.2 BasicLayout 与搜索

普通页面统一使用 BasicLayout，组合官方 SidebarProvider、Sidebar、SidebarInset、共享 ProductHeader，以及当前页面内容。统一侧栏宽度、收起偏好、移动抽屉、跳转主内容和认证弹窗；不为每个页面复制布局。Header 不出现边框或阴影，搜索控件保留必要的焦点反馈。沉浸式画布编辑器保留原项目工具栏与保存逻辑。

按用户补充要求，桌面和手机均使用官方 shadcn CommandDialog + CommandInput + CommandList/CommandGroup/CommandItem。桌面顶栏为不超过 360px 的 Button 搜索入口，配合 Kbd 显示平台快捷键；手机保留 44px 图标入口。⌘K / Ctrl+K 快速唤起或关闭；密码输入和其他已打开弹窗不抢焦点。弹窗按当前页面明确搜索范围，Enter 执行搜索，方向键选择页面跳转，Escape 关闭并恢复原焦点。输入法组合输入期间不提交，清除同时恢复完整列表。请求错误沿用 Sonner；不在顶栏增加错误横幅。

首页和探索筛选现有灵感示例；资产通过原 search 参数、我的画布通过原 q 参数查询服务端；主体仍只搜索当前项目中已加载的主体，提示词明确范围。其他普通页面的搜索跳转到探索，并携带关键词。保留资产类型、目录、收藏、排序和回收站，搜索不触发任何写操作；资产命令结果未确认时继续禁止更改搜索。正文不重复展示同一个搜索框。页面独立使用图库或主体选择器时，保留其原局部搜索。

验收覆盖搜索提交与清除、原接口参数、中文输入法、手机弹窗焦点恢复，以及 320/390/768px 和桌面侧栏展开/收起。设计组件：HeaderSearch、BasicLayout 展开/收起，复用原 Header 组件与页面实例。

### 7.3 响应式与可访问性

768px 以下使用紧凑布局：两侧 16px，图标触发区域至少 44px，品牌图标 24px，标题允许省略；360px 以下将页面名称保留为读屏文本，避免出现半个汉字。320px 仍保留导航、搜索、主题与登录或账号入口。长标题提供完整 title，不挤压操作。菜单与搜索弹窗限制视口宽度和高度，短屏内部滚动。内容滚动时顶栏可用；移动导航抽屉关闭后恢复到导航按钮，认证弹窗沿用现有焦点管理。

### 7.4 布局职责、状态与一致性补充（2026-10-20整理）

本专项解决普通换页的布局连续性和统一入口，不创建新的业务归属或账户权限。选用根级ApplicationLayout与复用BasicLayout，是为了让侧栏偏好、滚动和全局弹窗在普通换页时保持一致；沉浸画布仍有自己的项目工具栏，避免把工作台顶栏和编辑器工具叠加。视觉参数与稿件来源见第7.10节，实际验收归 Plan16。

| 模块                           | 职责与状态事实                                                   | 依赖与输出                                                    |
| ------------------------------ | ---------------------------------------------------------------- | ------------------------------------------------------------- |
| ApplicationLayout/BasicLayout  | 路由布局、稳定侧栏、正文滚动及认证流程；不拥有项目或账户业务数据 | 依赖现有路由、SidebarProvider、认证及权限Provider             |
| ProductHeader/CommandDialog    | 单图标搜索触发、主题/账号入口；搜索范围显式说明                  | 页面注册搜索回调，切换即清旧回调；导航和查询不写业务对象      |
| PageLayout及页面消费者         | 声明正文/全宽和本页搜索，拥有结果加载/空/错误及恢复入口          | 资产search、项目q等沿原合同；迟到结果须仍属于当前页面/查询    |
| SessionGate/SpaceGate/偏好接口 | 服务端会话、真实归属和主题revision仍是权威事实                   | 菜单可见性不授予API权限；保存后读回偏好再应用                 |
| DataPagination                 | 本页大小/页号和选择状态                                          | 12/24/48及0/0沿原记录；写入结果未知时禁止翻页，不能放弃原回执 |

布局临时状态为展开、抽屉、焦点、滚动和搜索输入；不写入项目、画布或成员关系。侧栏偏好从原cookie初始化，主题沿现有游客存储/账号偏好接口；不新增主题表或全局第二份标题表。搜索请求、页面和账号变化都须使旧回调/结果失效，不能让上一页查询或上一账号私有结果进入新页面。

| 失败/状态            | 用户反馈与恢复                                                                  | 验证入口                                           |
| -------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------- |
| 首次恢复/偏好不可读  | 按原水合保护和默认主题展示；私有区域等待身份，不短暂展示旧账号                  | 登录/退出、深浅主题及重载                          |
| 搜索空/网络失败      | 空结果限于已声明范围；失败保留重试，不显示成空库或成功                          | 原search/q参数、取消与迟到响应                     |
| 主题保存中/冲突/失败 | 阻止重复；失败保留已确认偏好，409重读revision后让用户再选，不自动覆盖另一端偏好 | 已登录偏好接口、断网/409；接口状态须按实际合同核对 |
| 菜单、导航或认证关闭 | 恢复原触发器焦点；短屏局部滚动，中文组合不提交                                  | 键盘、IME、320/390/768及短屏                       |
| 退出或权限改变       | 沿既有会话撤销/缓存清理，管理员条目消失不代替服务端拒绝                         | 身份切换、直接URL及真实权限反例                    |

### 7.5 全局布局与组件统一（2026-10-21）

普通页面统一使用一套BasicLayout、Header与PageLayout规则，沉浸画布保留项目工具栏。本文参数为织光设计决定；shadcn提供组件与语义样式，Vercel提供界面可用性准则，不把项目尺寸称为官方强制值。先同步文档与Figma，本轮不改应用代码。

| 层级       | 统一规则                                                                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 页面外壳   | Header高64px；桌面侧栏展开240px、收起64px；手机采用Sheet。正文从Header下方开始，禁止负偏移把内容送到顶栏后面                                                     |
| 内容边界   | 桌面/平板正文及Header左右24px，手机16px；正文顶部24px、手机16px。外壳只提供一次边距，子页面不再叠加40/48px                                                       |
| 内容类型   | 列表/图库/管理页使用剩余宽度；首页创作区最大1012px并居中；表单详情按现有业务宽度居中。画布全铺，不套普通页面边距；相同类型共用容器，而非把所有页面强制同宽       |
| 间距       | 使用现有space/1、2、3、4、6、8（4/8/12/16/24/32px）；内容区块24px、控件组8px、编辑器内边距16px。网格按可用宽度重排，不拉伸媒体比例                               |
| 控件       | 使用shadcn当前Radix Nova内建变体：默认按钮32px、紧凑28px、较大按钮36px、桌面图标按钮沿对应变体；移动交互命中区至少44px。分页选择器与翻页按钮同组同高，不单独缩放 |
| 字体与表面 | Geist与现有文字样式、Lucide；background/card/popover/muted/foreground/border/input/ring语义token。全局token驱动替换，不逐页附加颜色、字号和边框                  |

全局富文本组件以同一组件集维护首页、画布、展开和移动变体；正文、引用标签、附件、参数、反馈和动作槽共享组件。文本正文与生成提示词保留各自职责及保存会话，不因外壳复用而混用数据。新建生成输入默认显示“全能参考”，无“选择模式”的待选状态；已有草稿保留已保存的选择。模型不支持时显示能力限制并引导改选，不静默降级、不伪造可提交能力；音乐、朗读等无此模式合同的工具不因共用组件而新增供应商参数。

| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 8. 实施与验收

以下定义验收条件；执行步骤与版本化结果见[对应实施计划](../plan/16-Figma设计落地实施计划.md)。未执行或未覆盖的场景不能视为通过。

### 8.1 布局组合与状态保护

根级 Providers 内的 ApplicationLayout 依据路由选择普通工作台、独立安全页面或沉浸式画布；普通换页保留同一个 BasicLayout。BasicLayout 只组合 SidebarProvider、ProductSider、SidebarInset、ProductHeader、独立正文滚动区域、认证及退出流程。页面使用 PageLayout 声明正文、全宽模式及当前页面搜索，不再重复挂载壳组件。管理员与访客策略继续由 SessionGate 校验，SpaceGate 继续控制创作归属；不因视觉重构放开私有接口。

Header 为 64px 固定高度，展开/收起侧栏为 240/64px。工作台高度为 100dvh，只有正文滚动；滚动槽只在正文预留，避免根元素和正文重复占位。页面切换清理旧搜索回调并重置正文滚动；侧栏初始偏好由服务端读取已有 cookie，客户端订阅后继续保持同一状态，避免先展开再收起。手机仅保留 Sheet 导航，不重复渲染横向主导航。品牌默认使用设计稿的单色版本。

ProductFooter 在账号恢复/重设密码页面提供既有服务条款与隐私政策链接，不在工作台追加设计稿不存在的底部操作栏。会员积分后续按最新设计接入真实服务数据，原型余额和未定价套餐不作为运行数据。

数据集合统一使用公共 DataPagination：默认每页 12 项，可选 12/24/48，右侧排列；空集合为 0/0，前后翻页不可用。批量选择只涵盖当前页，切页清空选择，写入结果未确认时禁止改变分页。素材库与探索已接入，其他数据页按实施计划迁移。示例图保持原色并标注 AI 生成，私人素材仍来自原服务接口；空状态在正文剩余区域居中。

### 8.2 验收

Figma 使用可编辑的 Header、HeaderSearch、BasicLayout 展开/收起组件，保留桌面/手机、已登录/未登录、Command 展开与深色样例；五个普通页面和手机首页同步移除重复搜索入口。实现复用 shadcn Sidebar/SidebarInset、Command、Kbd、Button、DropdownMenu、Tooltip、Avatar；不新增空间产品能力。验证桌面侧栏两种宽度、320/390/768px、快捷键、中文输入法、弹窗焦点恢复、短屏滚动，以及原搜索参数和账号操作。

### 8.3 发布、回退与待决边界

按共享壳、页面布局与搜索注册、分页消费者的顺序核对，保留业务 API、身份和归属合同。回退仍须保留唯一登录入口、菜单、搜索、焦点及页面正文，不得重复挂载新旧布局、回滚用户偏好或重写项目归属。

团队和邀请入口的范围按需求11保留待决，不能由后台已有能力推导导航开放。会员积分、通知和公开资料缺真实合同或数据时明确不可用。主题冲突、搜索取消、键盘、触摸及可访问性按真实界面与接口验收。

### 加载与状态展示标准（2026-10-25）

初始数据尚未返回时使用共享 Skeleton，不再使用 ContentState/Empty 表示加载。导航、顶栏、页面标题和已知操作保持最终位置；仅未知内容使用匹配最终布局的头像、文本、卡片、列表或表单骨架。骨架不显示伪造条数、已保存、分页结果或可提交的生成按钮。

| 场景 | 统一展示 |
| --- | --- |
| 素材、主体、画布列表、推荐内容 | 对齐最终网格的封面、标题和元信息骨架 |
| 个人空间 | 头像、姓名、简介和内容分别占位；已知 Tab 保持原位 |
| 搜索、通知、资产选择、设置弹窗 | 容器内紧凑骨架，不遮盖整页，不用分页充当加载反馈 |
| 空间切换、画布进入等阻断读取 | 共享 Loading / Global；简短状态文字，无假百分比和空态操作；保留已知外壳 |
| 已有内容刷新或写入 | 保留内容及输入，局部显示忙碌反馈；提交按钮固定尺寸并防止重复提交 |
| 无数据、无权限、读取失败、协议不兼容 | ContentState/Empty；有内容时采用紧凑 Alert，不覆盖编辑器 |

加载 Token：`loading/surface` 引用现有 `selected` 语义色；`loading/opacity-low=55`、`loading/opacity-high=100`（Figma 百分制；代码端为 0.55 / 1）、`loading/pulse-ms=1600`。使用低对比度呼吸变化，每半周期 800ms、ease-in-out；减少动态效果时使用 Skeleton 的 Static 状态。禁止白色闪烁、装饰边框和任意独立色值。页面左右间距仍为桌面 32px / 移动端 16px，区域间距 24px；按钮 36px、动作间距 8px。

Figma 组件库沿用 Skeleton `737:26434`，升级为 Default/Dim/Static；加载组合统一收口到 `2228:30677`。最终页加载状态位于 `2228:30987`，已有素材库加载页 `1446:5695` 原位更新。原型用 1.6s 延迟演示 pending→ready；真实实现必须由请求生命周期驱动，不人为等待 1.6s，也不把超时自动视为成功。

### 嵌套区域与弹窗状态约束（2026-10-25）

区域初读使用上述骨架或全局加载；读取失败使用 ContentState：整页最小高度 288px，弹窗/设置内部按内容使用 160px 紧凑高度。失败时不得展示成功零计数；重试进入对应加载态；错误持续显示于正文，不只存在 Toast。搜索无结果继续使用 CommandEmpty；字段校验保留 FieldError。

普通状态动作复用 36px Button、8px 间距；确认表单尾部右对齐，取消在前、主操作在后。包含输入框的标签容器占满表单宽度。页脚由共享外壳提供。未开放能力只显示说明与必要返回入口，不重复放置无效动作。协议不兼容不宣称已恢复，重连不新建业务提交。
