# 统一顶栏与阶段入口

日期：2026-10-17。依据本轮用户要求，先更新 Figma，再实现页面。

## 范围

首页、探索、资产、主体、我的画布及账号/管理页面共用一个 ProductHeader。个人空间、团队空间、团队和邀请入口暂不进入当前产品导航；保留现有服务接口、权限和创作归属逻辑，不删除后台能力。沉浸式画布保留项目名称、保存与冲突反馈工具栏，不叠加全局账号顶栏。

## 结构与视觉

顶栏高 64px，固定在内容区域顶部，左侧显示当前页面名称，右侧集中放置账号相关操作。与展开 240px、收起 64px 的侧栏共同适配剩余宽度。背景、底部分隔、文字和交互状态使用现有语义 token；不增加宣传文案、营销色或第二层工具条。

桌面内边距 24px，操作间距 8px：积分商城使用 outline Button，通知使用 ghost 图标 Button，开通会员使用 ghost Button，头像使用现有 AccountMenu。图标使用 Lucide，品牌复用 BrandMark。页面名称来自现有路由配置，不维护第二份标题列表。页面内容原有筛选、搜索和创建操作留在正文。

## 状态与交互

| 状态 | 左侧 | 右侧 |
| --- | --- | --- |
| 桌面已登录 | 当前页面 | 积分商城、通知、开通会员、头像 |
| 桌面未登录 | 当前页面 | 登录 / 注册 |
| 手机已登录 | 导航按钮、品牌图标、当前页面 | 通知、更多、头像 |
| 手机未登录 | 导航按钮、品牌图标、当前页面 | 登录 / 注册 |

不标注游客模式，不展示示例积分或未读数。未接入能力沿用原可用性弹窗，不虚构功能状态。头像菜单复用账号摘要、资产、我的画布、密码、主题及退出；管理员入口继续依赖真实角色。

手机“更多操作”使用官方 DropdownMenu，包含积分商城与开通会员。菜单支持方向键、Enter、Escape 和触发按钮焦点恢复；通知和头像各自保留可访问名称。退出沿用原确认与撤销会话流程。移除公共顶栏下方 SpaceSwitcher，不改动服务端接口或授权校验；已有创作归属保持真实读取，不静默改写私有草稿或项目归属。

## 响应式与可访问性

768px 以下使用紧凑布局：两侧 16px，图标触发区域至少 44px，品牌图标 24px，标题允许省略；320px 仍保留导航、通知、更多和头像。长标题提供完整 title，不挤压操作。菜单限制视口宽度和高度，短屏内部滚动。内容滚动时顶栏可用；移动导航抽屉关闭后恢复到导航按钮，认证弹窗沿用现有焦点管理。

## 验收

先在 Figma 建立可编辑的 Header 组件及桌面/手机、已登录/未登录、菜单展开与深色样例，再更新五个普通页面和手机首页。实现只使用既有 shadcn Button、DropdownMenu、Tooltip、Avatar 与语义布局；不新增空间产品能力。验证桌面侧栏两种宽度、320/390/768px、菜单键盘操作、长标题、浅深色与原账号操作。
