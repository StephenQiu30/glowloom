# 短剧工作室一致性设计

依据 [需求23](../requirement/23-短剧工作室对齐即梦需求.md)。交互目标已明确，依赖真实生成的行为以运行验收确定。

## 1. 摘要

将短剧制作集中到工作室首页、制作资产库和分镜三个层次。首页处理创作输入、近期项目和样例入口；项目内组织资产、剧集和镜头。

## 2. 参与者

编剧导入或创作剧本；项目成员制作资产、编辑分镜与生成；浏览者从精选作品查看获授权的只读画布；组织管理员控制供应商及模型可用性。

## 3. 背景

短剧和普通画布共享项目及主画布服务。资产页已有 `short_drama` 分类、模板、权限和写入回执。独立的 `/storyboard` 只有占位状态。剧本模块有来源、文件导入、剧集结构、版本和确认接口，项目主体接口可提供资产引用。导演台和时间线已有画布实现，需要核对短剧内上下文及回填。

## 4. 目标

使用「短剧工作室」「短剧画布」「制作资产库」「分集视频」「故事板助手」等已观察名称。短剧项目的创建、打开、分集切换和返回共享项目身份。设计、接口、真实数据与运行状态能逐项追溯到需求。

## 5. 使用场景

- 创作者有剧本、只有创意、已有成片或直接进入画布时，分别走上传剧本、剧本创作、转绘或短剧画布。
- 项目成员在资产库准备角色和场景，进入分集视频选择一集，在编辑器查看片段、引用素材、预演和生成。
- 访问者查看公开示例。进入本人工作区编辑须显式复制，并核对权限和副本结果。

## 6. 价值

统一创作入口与项目归属，可通过「我的短剧」找回进行中的项目。制作资产可在画布、剧集和分镜复用，减少重复上传和选错项目的情况。

## 7. 方案

| 需求 | 当前实现对照 | 目标合同 |
| --- | --- | --- |
| 01、07 | 原一级侧栏无短剧入口，资产已能按 `short_drama` 列出和新建项目；可重命名、收藏和删除。模板使用既有创建合同。卡片未提供直接复制 | 工作室用 `/short-drama`，全部跳转 `/assets?view=short_drama`。入口只向当前空间提交创建，请求和未知回执沿用幂等逻辑。最近列表与全部列表复用同一授权和卡片合同 |
| 02 | `script` 已有正式文档导入任务、文本来源写入、分集和版本接口。工作室尚需串联创建、导入和审阅 | 提交冻结内容、版权和项目归属。已创建项目和已受理导入分别显示，失败可继续在原项目重试 |
| 03–05 | 通用创作、引用、Agent 和模型目录可复用，未发现完整短剧生成入口和专用输出合同 | 使用真实模型、技能和报价，明确输出草稿及版本，分集与资产抽取结果可审阅 |
| 06、15、16 | 画布有通用媒体及时间线能力，未核实能满足短剧转绘、智能预演、局部重拍、超分或拉片完整业务合同 | 按任务分别确认输入、结果模型、权限、计价与重试，保留源片及派生结果关联 |
| 08 | 资产与探索有各自权限和媒资能力，未发现精选短剧完整画布预览和复制闭环 | 只读渲染单独校验公开范围与资产权限，复制后返回新的授权项目 |
| 09–10 | 短剧创建后打开普通主画布，项目主体服务独立。未发现制作资产库视图 | 短剧画布复用现有编辑器，列表和画布共享项目资产引用；继续沿用 [Yjs](17-画布Yjs协作编辑设计.md) |
| 11–13 | `/storyboard` 是占位，剧本接口可读取剧集与结构。通用对话尚需绑定分镜上下文 | 项目内分集及单集编辑使用明确的项目/集/片段身份和版本。故事板助手写入遵守业务权限、版本校验及范围确认 |
| 14 | 画布已有 3D 导演台、镜头与输出能力 | 复用 [导演台](30-导演台一致性与实现整理设计.md) 和 [时间线](31-时间线即梦一致性设计.md)，核对导演台输出能回到指定画布或分镜引用 |

Figma 在现有 Glowloom 文件中复用 ProductSider、Header、TabsTrigger、Button 和语义变量。共享侧栏与原资产桌面稿原位更新。画板包含 [工作室总区](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/Glowloom?node-id=3541-96353)、[手机首页](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/Glowloom?node-id=3541-97047)、[单集编辑](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/Glowloom?node-id=3541-97310)。主题沿用 Geist 与现有语义变量。原型使用示例内容。

## 8. 实施与验收

首个可用闭环从全局入口进入，读取当前用户的最近短剧和模板，创建或打开短剧画布，并到资产页管理全部。匿名只浏览公开页面，写操作走登录及当前空间授权。后续验收覆盖导入、生成、转绘、分镜助手和派生媒体。以 [PRD24](../prd/24-短剧工作室.md) 和 [Plan33](../plan/33-短剧工作室实施计划.md) 组织验收。
