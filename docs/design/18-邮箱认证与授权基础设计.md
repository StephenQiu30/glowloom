### 7.3 Global Constraints

来源：原任务文档《02-邮箱认证与授权基础》第2节。

- 前置 T-USER-16 完成只读迁移预检；用户已授权在 main 实现。只复用现有连接和已运行服务，不创建隔离环境；发信及切换取决于真实配置和已核验映射。
- ASCII 邮箱≤254字节；密码8～128 Unicode字符；验证码6位/10分钟/5次；注册grant10分钟；恢复30分钟。
- 失败5次/15分钟锁15分钟，锁内不续期；邮件60秒间隔、5次/小时、10次/天。
- 会话空闲12小时/绝对7天；复验5分钟；个人、团队、平台权限独立，任何授权源错误都拒绝受保护访问。
- 下列 Create 为未来实现文件，Modify 为现有文件；只创建当前任务需要的文件。按文件职责注入时钟，禁止全局工具包。所有任务遵守[执行总览](01-用户系统总体设计.md)共同检查点。
