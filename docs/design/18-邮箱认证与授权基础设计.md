# 邮箱认证与授权基础设计

技术设计；确认等级沿原来源。需求、PRD、Plan 独立维护，实施状态只见 [BACKLOG](../../BACKLOG.md)。

## 1. 摘要

沿统一邮箱证明和授权合同完成注册、登录、找回与范围校验。

本文采用设计、用户故事与测试场景结构。原始需求、PRD 和 Plan 独立维护；当前实施进度、剩余工作及阻塞项统一见 [BACKLOG](../../BACKLOG.md)。

## 2. 参与者

使用者与参与职责：注册或登录的用户及身份、范围授权消费者。维护职责及确认人沿下方原来源记录；未给出姓名的，不补造人员或排期。

## 3. 背景

原始需求：[02-用户系统需求](../requirement/02-用户系统需求.md)。关联需求与验收：[01-用户系统](../prd/01-用户系统.md)。本文维护技术合同；相关实施步骤与证据见 Plan，状态与调度见 [BACKLOG](../../BACKLOG.md)。

## 4. 目标

沿统一邮箱证明和授权合同完成注册、登录、找回与范围校验。目标的规则、量化条件与非目标沿需求原文及下方已确认设计，不增加未经确认的指标。

## 5. 使用场景

参与者为注册或登录的用户及身份、范围授权消费者；在下方定义的输入、对象状态、权限和环境条件具备时执行相应操作。各故事按其独立前置条件核对，不能把测试夹具当成真实业务条件。

## 6. 价值

失败可更正，个人与团队业务入口按当前资格授权。

## 7. 方案

### 7.1 Global Constraints

- 前置 T-USER-16 完成只读迁移预检；用户已授权在 main 实现。只复用现有连接和已运行服务，不创建隔离环境；发信及切换取决于真实配置和已核验映射。
- ASCII 邮箱≤254字节；密码8～128 Unicode字符；验证码6位/10分钟/5次；注册grant10分钟；恢复30分钟。
- 失败5次/15分钟锁15分钟，锁内不续期；邮件60秒间隔、5次/小时、10次/天。
- 会话空闲12小时/绝对7天；复验5分钟；个人、团队、平台权限独立，任何授权源错误都拒绝受保护访问。
- 下列 Create 为未来实现文件，Modify 为现有文件；只创建当前任务需要的文件。按文件职责注入时钟，禁止全局工具包。所有任务遵守[执行总览](01-用户系统总体设计.md)共同检查点。
