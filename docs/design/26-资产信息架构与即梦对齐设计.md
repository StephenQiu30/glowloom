# 资产信息架构与即梦对齐设计

依据：[需求13](../requirement/13-资产对齐即梦需求.md) FR-AST-01～08；竞品证据：[调研08](../research/08-即梦资产完整需求分析.md)。本设计替代设计09中资产总入口“素材库优先”的旧分类顺序；共享布局、认证、组件、主题继续由设计09持有。

## 1. 摘要

资产从上传文件管理扩展为创作回访入口。主分类为生成历史、画布、短剧；原个人素材独立称“参考素材”，通过辅助入口保留上传、文件夹、收藏、回收和恢复。不得只替换页签文字而沿用不相符的数据源。

## 2. 参与者

使用者为当前登录的创作者；游客可访问外壳并登录。用户已确认生成历史只显示本人发起的任务，不能列出其他成员的任务。主体专项仍由对应需求和设计维护，不纳入资产分类推断。

## 3. 背景与实现差异

| 领域     | 当前拥有者与事实                                                                                                | 对齐处理                                                   |
| -------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 入口     | `frontend/src/app/assets/_components/assets-page.tsx` 默认 library；`library-toolbar.tsx` 为素材/生成历史两页签 | 资产总入口重构，默认生成历史；参考素材单独保留             |
| 导航命名 | `components/layout/product-sider.tsx`、`routes.ts` 称素材库                                                     | 面向用户统一资产；保持 `/assets` 链接可用                  |
| 参考素材 | `/api/media/library` 有真实个人上传、文件夹、收藏、回收、下载；schema 限制 personal 不属于生成任务              | 复用全部真实能力，不能改写为生成历史                       |
| 生成记录 | `components/media/generation-history.tsx` 经项目选择读取 `/api/projects/:pid/operations`                        | 新增经授权的全局历史读模型，保留单项目接口供画布使用       |
| 详情     | operation 详情有冻结提示词、参数、输入、输出和事件                                                              | 复用真实详情，禁止逐卡瀑布请求来拼列表                     |
| 画布     | `/api/projects` 是主画布容器入口；同项目可另有画布                                                              | 不把项目列表冒称全部画布；新资产查询按实际 canvas 对象授权 |
| 收藏     | 当前个人素材有收藏，任务/项目/画布没有个人收藏字段                                                              | 个人收藏元数据与任务执行事实分离，先定义迁移合同           |
| 短剧     | 有剧本结构与分镜提示模板，没有容器类别字段                                                                      | 增加显式分类，既有项目不凭内容自动改类                     |

以上为2026-10-28源码静态核查，未执行数据库或供应商验收；进入任务前这些文件部分已存在并行未提交修改，不能据此归为本轮实现。

## 4. 目标

完成信息架构、术语、状态与操作语义的一致性；保留真实数据、现有会话与授权。用户可在统一入口找回生成结果、继续画布或短剧、管理参考素材。模型、收费、会员和剪映商业集成不因竞品存在而自动采用。

## 5. 使用场景

- 回看创作：选择生成历史与媒体类型，组合查询，打开任务详情和对应结果。
- 继续编辑：选择画布/短剧，按名称和时间定位对象，打开实际画布。
- 管理参考：进入参考素材，上传、整理文件夹、收藏、回收与恢复。
- 批量管理：进入选择模式，选定当前可操作对象，提交动作并逐项理解结果。
- 异常恢复：查询失败提供重试，筛选无结果能清除条件；会话失效清理私有数据并回到登录入口。

## 6. 价值

将“生成了什么”“在哪里继续编辑”“上传了什么参考”各自对应真实对象，减少名称相同而数据不同造成的误导。分类型查询避免无效选项，回收与生成执行账本分离，避免整理历史误删业务事实。

## 7. 方案

### 7.1 结构与命名

资产来源与筛选采用统一 workspace 组件变体：13px、22px 行高、500 字重，桌面控件高36px；手机与粗指针设备保留至少44px点击区域。主导航14px、22px行高、500字重，桌面行距40px。普通空态为14px、20px行高、400字重、正常字距；错误和加载提示不降级。文字使用 workspace-foreground、workspace-muted-foreground、workspace-subtle-foreground 语义令牌，深色分别为白色、70%白色、35%白色，浅色沿用可读的现有前景令牌。宽屏来源与筛选中心距44px；中等宽度优先保留来源与账号同行，工具换至次行。保留现有字体栈，本次不替换字体文件。

资产右侧采用 shadcn ButtonGroup 的语义描边分组：搜索／批量操作为工具组，织光不提供企业服务入口，通知／积分入口／会员中心／头像为账号组。来源操作通过 actions 插槽进入工具组，保留来源自身的批量锁定和命令状态；批量模式按可用宽度换行，来源标签预留完整宽度，操作组不足时换行。进入批量模式将键盘焦点移至“取消选择”，退出后返回“批量操作”，切换来源时不抢夺来源标签焦点。画布删除或重命名对话框关闭后返回原操作入口；日期错误使用FieldError行内提示，输入关联错误信息且不再重复弹出Toast。图标按钮使用 Tooltip 和可访问名称，主题设置由现有账号 DropdownMenu 的外观菜单提供。积分服务未开放时明确反馈不可用，不写入示例余额、消息数或促销文案。页面筛选、空态、卡片、反馈和确认复用现有 shadcn 组件；资产工作台不显示通用营销页脚，空态占据可用内容区域。

`/assets` 保留稳定地址，默认生成历史/图片；主导航“资产”，主分类“生成历史／画布／短剧”。参考素材保留现有直达路由和创作选材能力，资产顶栏不再提供额外入口，不成为生成历史中的第五个媒体类型。素材内部的3D内容保留在参考素材，不伪装成即梦已观察的第四类或短剧。

共享顶栏仍按已接受的搜索图标/CommandDialog合同，资产页不另造第二个全局搜索框。搜索可访问名称随当前来源变化。资产页采用两层结构：桌面第一行左侧为生成历史／画布／短剧，右侧为当前来源操作、搜索和账户区，中心线对齐；第二行是媒体类型或画布／历史画布，以及筛选、时间和排序。一级来源使用Tabs的pill变体，选中项为圆角胶囊；二级类型使用ToggleGroup的text变体，以文字高亮选择，类型与筛选之间使用Separator。来源标签通过共享PageToolbar插槽渲染进ProductHeader，React Tabs上下文、查询状态和动作锁定仍归资产页持有，不复制头像或搜索组件，不使用绝对定位拼接。正文不再显示额外的资产标题行，仅保留读屏h1；顶栏与正文使用同一水平留白。窄屏保留导航与账户首行，来源／操作换到下一行，筛选按内容换行，保证不横向溢出。卡片无装饰描边，控件保留组件边界与1px焦点环。

### 7.1.1 2026-10-29 实测精简合同

用户确认：“即梦没有的东西我们就不做”，企业服务继续排除。Chrome 实测当前画布、历史画布、短剧、文档历史和批量状态；证据记录在 [调研补证](../research/09-资产展示精简复核.md)。此节覆盖此前多余入口的描述。

- 默认工具区只保留搜索和批量；删除参考素材、更多画布操作、添加到已有项目和顶部新建按钮。未接入剪映不放占位按钮。
- 新建为网格第一张16:9加号卡片，下方“新建项目”或“新建短剧画布”；历史画布里的新建也创建当前类型画布，不新增旧版文档。筛选命中时不混入新建或系统目录。
- 即梦当前画布与短剧确有模板卡片，不能把“没有独立系统模板区”误写成“没有模板”。织光已有真实模板以同一网格卡片、封面角标及名称展示，删除单独区标题、说明、节点数量和使用按钮；不假造即梦的示例内容和封面。不可变系统模板不冒充可删除的用户资产，批量状态暂不提供其选择。
- 批量区为数量、删除、下载/发布（仅支持的生成媒体）、收藏、取消选择；移除额外全选和取消全选。搜索与账号组在选择模式隐藏，退出恢复。保留原幂等、部分失败和权限保护。
- 文档默认顶栏不展示下载格式控制；下载格式归入批量“下载”菜单和详情操作。
- 画布卡片标题/元信息使用统一组件样式，名称单行省略，修改时间显示相对时间，较旧内容为月日；收藏位于封面右上，更多位于名称行右侧。保留可访问名称、键盘焦点和触摸命中区。

### 7.2 目标查询合同

这是织光设计合同，不是对即梦私有 API 的推断。

- 本人任务列表在有效项目访问权限之上按可靠发起人事实限制，返回任务 ID、项目/画布上下文、媒体类型、模型、创建时间、状态、必要候选预览摘要和个人收藏状态；按身份与空间授权后筛选分页。
- 查询包括类型、搜索、收藏、处理类型、分辨率、比例、生成模式、开始/结束日期与顺序。只接受与类型相容的选项，切换类型清除非法条件；后端为所有可见数据完成筛选后分页。
- 日期按用户选定时区的日历日转成明确的半开区间 `[start,end)`；结束日展示包含当天，但传输为下一日边界。服务端校验合法范围；同时间以 ID 稳定排序。
- 游标绑定身份/空间/全部条件与顺序，不能跨条件重用；只选当前已加载页，不宣称跨所有结果全选。
- 收藏按用户及具体结果ID隔离，不能以单个任务布尔值代替一条多结果任务内的收藏状态，依据调研08第8.1节。“删除生成历史”的即梦语义仍未确认；整理动作必须保护执行、计费、引用与其他成员记录，不能先接不可逆删除。具体数据表、迁移、幂等和逐项批量回执在编码前细化。
- 失败/生成中任务不要求已经有媒体文件；列表不能复用只返回 ready+passed 的素材目录。
- 不能从像素尺寸推断超清/补帧；需要明确的任务处理类型事实。历史元数据缺失时保留未知，不补造。

生成历史与公共任务详情的`outputs[].kind`是展示投影：底层`operation_output.kind`仍为`media/json`，媒体候选必须从同项目正式`media_asset.kind`读出image/video/audio/document/model，不能按任务能力猜测；JSON候选保留json。软删除、审核变化和保存中的本项目候选仍保留真实ID、顺序及原审核元数据，字节访问由媒体入口重新授权；损坏或越界引用不得泄露其他项目事实。JSON没有公开正文是合法元数据，不因正文缺省使整个任务读取失败；只有最终完成、审核通过的text/document能力正文可展示和导出，客户端也按UTF-8字节核对64KiB上限。

### 7.3 筛选与操作

具体媒体选项采用调研08第3节矩阵及第8.3节补证。图片/文档选择与下载最多200、删除/收藏最多50，图片发布最多7；音频/视频/普通与历史画布选择最多50；现代短剧最多100。技术API封装上限不冒充竞品UI上限。目标生成历史批量包含删除、下载、发布、收藏，按对象状态及真实能力启用；无结果、未成功或无权项不能假成功。画布批量仅对应删除/收藏，单项增加重命名/复制。短剧工具栏随真实数据与收藏状态表达，不照抄模板空态中的“取消收藏”。

发行脚本已确认图片、音频使用具体结果级选择，文档不发布，视频按实际历史对象处理。任务状态卡与已生成候选分开表达；多结果任务不能共用单一收藏布尔值。发布按7.8的具体结果合同执行。

### 7.4 画布与短剧

资产查询对象是实际`canvas.document`，返回项目上下文、文档修订、项目修订、创建/修改时间、真实封面及个人收藏；主画布名称取项目当前显示名，不能用项目列表代替同项目的全部画布。

即梦的“画布／历史画布”分别由新`InfiniteCanvasProjectDataService`与旧`OldCanvasListManager.getUserDraft(Canvas)`提供，是产品来源的区分，不是归档、回收站或版本恢复。织光`operation_version=0/1`只表示历史布局命令与版本化编辑协议；`canvas_protocol_incremental.sql`保留版本0历史，新文档默认1；Yjs是否初始化另由`collab_document`记录，因此这些字段均不得猜测映射为即梦新旧产品代际。

织光用显式`asset_collection=current|legacy`保存经过确认的来源。现有产品均由当前画布入口服务，增量默认`current`，不按协议号、时间或节点内容自动重分；没有确证来源的旧编辑器资产时，历史画布真实返回空列表。常规新建只能创建current，不开放任意改类入口。列表`collection=current|legacy`选择两类；短剧是独立`kind=short_drama`，不挪用scope、不按视频或剧本节点猜测。

个人收藏保存到独立`canvas.asset_preference(actor_id,scope_id,document_id)`，有自己的修订，缺记录为false/修订0，不改变共享图文档修订或其他成员的收藏。`GET /api/canvases`新增`collection`与`favorite_only`，游标绑定这些条件。封面只返回当前项目内ready+passed、未删除图像的真实媒体ID：主画布优先项目封面，其他画布取真实图像节点；缺失或不可用保持空/不可用，不生成占位URL。

新画布单项操作为重命名、收藏、复制项目、删除；历史画布没有复制项目。复制沿既有整个项目冻结/复制合同，legacy文档在后端复制准入中明确拒绝。普通文档重命名和删除复用canvas生命周期；已初始化Yjs的重命名由私有runtime生成只改标题的合法delta，再经现有CommitYjs接受，保持epoch与历史，不直接改数据库修订来伪造协同同步；主画布必须通过workspace生命周期，保留名称联动、项目修订校验、正在执行任务保护及软回收，不能直接删除主文档。归档项目的主画布删除仍由workspace允许的项目回收合同处理，不以内容写入前置校验阻断；归档内容重命名/附加画布删除及只读空间写入保持拒绝。

`POST /api/canvas-assets/commands`提供`favorite|rename|delete`，受UUID幂等键保护；rename只允许单项，收藏/删除最多100项。每项带文档修订，收藏另带个人收藏修订，主画布写入另带项目修订。先授权当前会话与空间，再逐项保留成功/失败回执；同一请求重放返回原回执，改请求必须新键。删除主画布等于回收其项目，产品确认需明确影响范围；同项目先处理其他所选文档，再处理主画布。已知业务拒绝只失败该项，数据库/依赖未知故障回滚整个请求并保留原幂等重试方式。

资产个人入口默认直接新建，不要求先有项目。`POST /api/canvas-assets`接收`kind`、可选`name`及`template_key`，使用UUID幂等键；canvas模块持有外层事务与完整请求指纹，通过事务内注入的workspace创建者复用既有项目、主画布、零预算、审计与创建回执，再初始化显式kind和模板图。返回新项目ID与主画布ID供打开编辑器；资产页移除“添加到已有项目”辅助入口，不改变其他模块的项目创建器默认行为。失败必须回滚项目、预算和图，未知结果同键重试不能留下重复项目。canvas创建使用独立持久化回执，公共24小时幂等缓存到期后仍保留完整kind、名称和模板指纹；已回收或移出空间的对象不通过旧创建回执泄露。

`GET /api/canvas-assets/templates`提供明确`is_template=true`的系统模板目录，可按`kind`筛选。首批不可变版本键为`text-to-image-v1`（文生图工作流）与`storyboard-three-shots-v1`（三镜头分镜），每项有名称、说明、节点数与需选模型提示。模板真正预填可编辑说明文本、GENERATE图片节点及PROMPT连线；短剧含开场、冲突、转折三组分镜。点击模板始终创建新的所属项目和主画布，结果`is_template=false`，节点身份基于新文档重新生成；模板内容本身不能被覆盖，修改模板须新增版本键。模板不嵌入用户媒体、模型凭据、任务或结果，不自动报价、选择模型或执行生成。未知模板或kind不匹配在写入前拒绝；同键改kind、名称或模板冲突。

### 7.5 状态与权限

有真实正文的文档提供PDF、Markdown：通过现有详情接口重新授权取得最终完成且审核通过的具体输出正文，再生成真实PDF或Markdown附件；只有正式文件的结果提供原件下载，禁用不能完成的格式转换；PDF按需加载渲染库，使用已有OFL字体子集嵌入，保留中文、分页及可选择正文，不使用浏览器打印窗口或改扩展名冒充格式。

普通空态“暂无相关资产”；筛选空态“当前已开启筛选，部分内容可能被隐藏”，提供清除条件；读取失败明确重试；加载只显示共享 Skeleton/Spinner；未登录显示登录入口。无权对象不可预览、下载或操作；账号/空间切换中止旧请求、关闭详情、清理选择和私有缓存。

查询切换清除批量选择和失效游标；详情返回保持有效查询。写入时锁定会改变操作上下文的控件，未知提交结果使用原幂等键重试。部分失败返回逐项结果，保留失败项供用户重试，不把全部选择显示为成功。

### 7.7 全量界面细则

本节是资产全量实现的界面合同，沿用7.1～7.6的真实数据、身份隔离与设计系统要求；即梦发行脚本的已验证分支以本轮`full-alignment/verified-contracts.md`及调研08的证据为准，不把静态分支描述成运行验收。

#### 来源、列表与结果粒度

- 主分类“生成历史／画布／短剧”保持单一正文；生成历史默认图片，其他类型为视频、音频、文档。参考素材仍为辅助管理入口，保留现有上传目录和回收行为。
- 生成历史保留任务分组及真实状态。图片、音频、文档的每个真实结果以独立`operation_id + output_id`标识卡片、收藏和选择；没有结果的处理中/失败任务显示任务卡片，不虚构候选。视频按生成记录选择与计数，记录内真实结果均可在详情查看，不能将其余结果从数据或操作目标中丢弃。收藏、分辨率等条件先用EXISTS选择视频任务，再返回该任务所有未隐藏候选；图片、音频和文档仍按结果条件裁剪。
- 卡片提供预览、状态、创建时间及合法动作；收藏与更多入口独立于打开预览，点击不误触导航。批量时用复选框取代卡片打开动作；只选择当前已经加载且有权操作的目标，不宣称跨所有页全选。
- 当前画布与短剧展示服务端系统模板，明确“模板”标记；使用模板创建带真实预填节点的新项目和主画布，不修改模板、不自动选择模型或执行生成。默认新建在当前空间直接创建项目与主画布；资产页不再展示“添加到已有项目”辅助动作。
- 画布下提供“画布／历史画布”二级分类，分别绑定服务端`collection=current|legacy`；该字段必须由明确迁移来源持有，不能按归档、回收、命令协议版本或内容猜测。短剧采用显式`kind=short_drama`。

筛选通过官方菜单的分组与复选项表达；同组多选、组间组合由服务端在分页前完成。开启收藏时触发器显示“收藏”，其他条件仍保留；清除条件不改变素材自身收藏。切换媒体清除不相容条件、游标和临时选择。搜索复用顶栏入口，不增加第二个搜索框。时间保留全部、最近一周、最近一个月、最近三个月和自选日期；结束日包含当天，API使用下一日零点的半开上界。生成历史使用近远顺序，画布额外按创建或修改时间排序。

#### 单项与批量动作

- 生成结果动作包括收藏/取消收藏、下载、发布和删除；音频、文档及视频配音不显示发布；只有图片和符合条件的视频提供发布。处理中、未审核通过或无原件的目标不可下载或发布，按钮依据真实状态及能力禁用。
- 收藏按具体结果写入，不能把任务布尔值当成全部候选的收藏。批量动作冻结选中目标和原幂等键，显示逐项回执；部分失败保留失败项，不能全部清空并显示成功。
- 历史删除必须确认所选目标、范围及实际删除语义，保护任务执行、费用与画布引用事实。最终文案随服务端真实合同统一，不把“删除历史”写成不可逆删除媒体原件。
- 下载逐项重新授权，成功仅表示浏览器已开始保存。音视频图片使用原件响应；有正文的文档提供PDF／Markdown，从完整任务详情读取已完成且审核通过的真实正文。仅有正式原件的文档默认显示“下载原件”，禁用PDF／Markdown并说明原因；混合批量按每项真实能力导出，逐项标明正文格式或原件。PDF按需加载渲染库和授权CJK字体，子集嵌入、真实分页与可选择文本；缺字时明确失败并保留Markdown出口，不用打印窗口、截图或改扩展名冒充转换。批量展示成功与失败项目，不将预览URL冒充Blob或虚构ZIP。
- 发布先显示标题、描述和“同时公开提示词”选择，并明确作品内容将公开。只提交选中的图片或可发布视频结果；回执逐项显示作品链接和失败项。音频、文档与视频配音不能通过批量混入发布。
- 画布及短剧支持真实收藏、删除；单项增加重命名与复制项目。主画布重命名/删除遵循项目联动与修订合同，普通画布使用画布合同；历史对象按实际限制显示动作，不借助错误路径绕过保护。

已补证的界面上限：图片选择／下载200、收藏／删除50、发布7；文档选择／下载200、收藏／删除50；音频和视频选择50；画布及历史画布选择50、现代短剧选择100。达到选择上限时保留原选择并提示。视频发布保留任务内全部选定结果，超过本产品后端每请求16个结果时逐批提交，每批使用独立冻结幂等键；前批完成、当前批未知或部分失败均不丢失回执和剩余目标。图片超过7项时仅禁用发布并说明上限。

#### 详情、再次创作和恢复

打开结果时携带任务与结果身份，展示对应媒体或文档，同时能查看真实提示词、模型参数及状态。再次创作复用既有生成器与冻结任务参数，准确使用原能力值（包含音频、编辑及结构化文本能力），重新读取可用模型并报价，不自动确认付费生成。详情返回保持当前查询和滚动；账号/空间切换关闭详情、取消旧请求、清空选择。

#### 交互和验证边界

普通空态、筛选空态、读取失败、加载、未登录、无权限、零选中和部分失败均保留明确出口。写入期间锁定来源、类型和筛选，未知结果只允许重试冻结命令；删除生成历史、画布、短剧及参考素材移入回收站的确认统一复用shadcn AlertDialog，包含Header、Title、Description、Cancel和destructive Action；默认聚焦取消，提交时保持弹窗，收到明确回执再关闭，未知结果保留原幂等重试。弹窗内错误和列表逐项持续结果使用shadcn Alert/AlertTitle/AlertDescription，失败采用destructive变体；列表结果容器保留polite播报，禁止以裸文本替代反馈组件。其他瞬时错误使用共享Sonner。桌面与390px使用同一语义和组件，工具栏可换行，触摸目标保持44px，卡片和长名称不产生横向溢出。命名、接口与返回字段同步后更新原生Figma及最终交互原型；不能只凭页面按钮齐全判断全量接受。

查询状态使用可回访的URL白名单，保留当前来源、媒体、画布集合、兼容筛选和参考素材目录／回收／排序；刷新和浏览器前进后退均能恢复合法条件，非法值回到安全默认。更新条件保持当前滚动，不因纯查询同步整页重置。日期校验在对应字段就地说明、关联读屏描述并聚焦第一个错误；批量卡片提供pressed状态和44px选择命中，异步逐项回执有live区域。资产详情首读失败显示重试，401／403／404清除私有详情及复用草稿；没有可导出正文的完成任务给出明确说明，正式候选非最终状态不可下载。

### 7.8 生成结果发布合同

发布使用本人可靠发起且当前仍可写的项目中的成功、审核通过的图片、视频结果；音频、文档不提供发布。发布前明确展示所选结果、作品标题、描述和“公开提示词”选项，后者默认关闭。标题默认“创作作品”，不从私有提示词静默派生。图片界面最多选择7项发布；HTTP单次最多16个具体结果，视频多结果按16个切分为独立冻结批次。每个结果生成独立作品；同一账号重复发布同一结果返回已有作品，不假造新副本。公开范围只包括该结果和用户明确选择公开的提示词，不开放项目、输入参考图、其他候选或供应商回执。

`POST /api/operations/history/publications` 接收 `targets[{operation_id,output_id}]`、`title`（1～120字）、`description`（最多2000字）、`publish_prompt`，使用UUID幂等键；逐项返回 published/failed、work_id、站内 `/works/:id` 链接及稳定错误码。重复键不同正文冲突，相同正文返回原回执。发布失败不改变个人收藏或历史。`GET /api/works/:id` 只读已经发布的安全作品投影与短效媒体地址；媒体、结果或项目已删除或审核撤销时不再展示，访问不等于取得项目权限。作品页支持真实图片、视频预览及公开提示词，不能跳到占位的探索图库来冒充发布成功。

这属于织光为实现竞品发布能力建立的真实合同；即梦私有发布接口和完整公开社区治理不作为本次的推断。测试只发布隔离环境的合成可丢弃素材，不自动公开当前用户既有作品。
