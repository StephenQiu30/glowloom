# 画布数据与接口设计

## 1. 摘要

保存完整画布、Yjs协作状态及接受回执，提供业务读取投影、素材引用和历史恢复。Go负责项目权限、业务约束与持久接受。

## 2. 参与者

画布客户端、Yjs协作服务、Go业务服务、PostgreSQL及现有素材存储服务。

## 3. 背景

来源为[数据需求08](../requirement/08-画布数据库持久化与DAG需求.md)及[协作需求10](../requirement/10-画布协作编辑需求.md)。交互见[设计10](10-画布交互设计.md)，传输见[设计15](15-画布WebSocket实时通道设计.md)，协作见[设计17](17-画布Yjs协作编辑设计.md)。

## 4. 目标

所有已确认内容可在换设备、清理浏览器数据和服务重启后恢复；每次编辑有可查询的确定结果，图与引用始终符合当前权限及业务约束。

## 5. 使用场景

打开项目画布、上传并引用素材、连续编辑、多端同步、查证未知提交、复制项目、浏览与恢复版本，以及生成结果回写。

## 6. 价值

画布内容、素材身份和任务来源保持一致，用户可以核实保存结果并继续创作。

## 7. 方案

### 7.1 文档身份与权威状态

文档具有稳定ID、项目归属、schema版本、协作epoch与接受修订号。修订号以十进制字符串跨语言传输。每个epoch只有一个有效写入通道。

持久保存Yjs二进制状态、增量与原始提交身份；业务读取使用同次接受产生的类型化投影。恢复从二进制基线与更新重建Y.Doc，JSON用于业务读取及导出。

### 7.2 节点字段与数据归属

节点按稳定ID保存类型、标题、位置、尺寸、层级、配置及内容。坐标为有限数值，尺寸为正值；位置和尺寸分别按完整字段组更新。分组成员、连线端点、输入依赖及来源关系使用稳定ID。

Tiptap正文使用共享富文本结构，业务投影保留段落、格式、引用提及和引用元数据。引用保存referenceId、assetId、绑定版本及来源；媒体使用稳定素材身份，临时展示URL由读取服务签发。

生成输入版本与节点布局分开管理；结果绑定发起时冻结的输入、引用和任务身份。个人视口、选中状态、在线光标及拖动预览按交互与协作设计管理。

### 7.3 图与引用约束

| 数据     | 接受规则                                           |
| -------- | -------------------------------------------------- |
| 标注连线 | 端点存在，按连线身份去重，可表达视觉环路           |
| 分组     | 成员存在，父子关系无环，删除与取消分组保持成员合法 |
| 执行依赖 | 输入端口与类型有效，依赖图无环                     |
| 素材引用 | 校验项目可见性、授权、素材身份与绑定版本           |
| 生成结果 | 保存输入版本及来源关系，结果回写保留后来编辑的输入 |
| 历史结构 | 完整保留类型、字段和引用；版本不兼容时提供只读读取 |

删除节点按关系语义清理其引用边，素材回收由素材服务管理。项目复制重新映射节点、关系和正文引用，并保持授权与来源可追溯。

### 7.4 接受与持久化

协作服务基于已接受状态构造隔离候选；Go验证当前身份、项目状态、schema、图和引用。接受时原子保存协作状态或增量、业务投影、修订号和回执，提交后广播。

提交由文档、epoch、提交ID、发起身份及载荷哈希确定。重复请求返回原结果；同身份不同载荷明确拒绝。结果未知时查询原提交，缺失时原样重试。失败与拒绝保持已接受状态完整。

单写者切换、进程重启和超时恢复需通过持久版本条件防止旧实例写入；跨服务接受调用以原提交身份幂等处理。拒绝后的客户端恢复规则见[设计17](17-画布Yjs协作编辑设计.md#73-合法接受与恢复)。

### 7.5 数据接口

HTTP提供项目与画布生命周期、快照读取、历史读取，以及素材上传、授权预览和下载。编辑、确认、远端变化与回执查证通过WebSocket传输。所有入口使用统一身份、项目归属与当前授权。

上传先取得素材服务回执，再提交画布引用。图提交失败时可沿原素材和提交身份恢复；异步结果始终核对发起项目、画布及目标节点。

读取错误返回明确错误状态；归档、撤权或版本不兼容保留可解释的恢复入口。分页、报文大小及候选处理资源设定可配置上限。

### 7.6 历史、迁移与恢复

历史检查点保留二进制状态、schema、epoch、修订号及素材引用。历史查看提供只读快照；版本恢复经当前授权和引用校验，生成新的持久版本，并按epoch隔离恢复前的未确认编辑。

存量转换保留原始只读快照，逐项核对节点、正文、格式、引用、关系与生成来源；转换可回读后按画布启用新epoch。旧客户端写入被版本门禁拒绝。备份、回退及故障恢复按真实数据演练验证。
