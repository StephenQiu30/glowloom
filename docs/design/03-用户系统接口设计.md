# 用户系统接口设计

状态：目标合同，未替换运行中的 API。依据[需求规格](../requirement/01-用户系统需求.md) FR-USER-01～25、IR-01～06；字段存储见[数据库设计](02-用户系统数据库设计.md)。本文定义 HTTP 合同，Go 应用类型在各执行任务中定义，传输 DTO 不反向进入领域层。

## 1. 公共协议

前缀 `/api`，JSON UTF-8，同站代理。UUID 使用字符串；时间 RFC3339 UTC；revision/epoch 为十进制字符串以避免 JavaScript 精度丢失，服务端解析为正 int64。未声明的输入字段拒绝 422，尤其 role/platform_role/owner_id；空值仅用于明确可清除字段，省略表示不修改。

读请求 no-store；敏感写入必须验证 Origin 与会话绑定的 X-CSRF-Token，公共认证写入校验可信 Origin，注册步骤额外绑定预认证 flow。生产 Cookie HttpOnly、Secure、SameSite=Lax、Path=/、无 Domain；本地 HTTP 仅配置化关闭 Secure。登录防固定会话，退出删除 Cookie。会话 Cookie 与预认证 flow Cookie 不共用，grant/reset token 不存 localStorage 或日志。邮件链接凭据放 URL fragment，落地页读入内存后移除，GET 不消费，刷新可重新打开邮件；只允许同站 return_to。

复用现有 `httpapi.Problem`：`type/title/status/code/detail/request_id/meta`，字段错误放 `meta.field_errors`，不新造另一套 message envelope。成功直接返回下述 DTO；无内容返回 204。列表返回 `{items,next_cursor,as_of}`，next_cursor 无更多时为 null。

| 状态 | code                                                                                       | 客户端处理                                         |
| ---- | ------------------------------------------------------------------------------------------ | -------------------------------------------------- |
| 401  | unauthenticated                                                                            | 清理私有缓存，保存允许的当前输入并显示登录         |
| 403  | forbidden / reauthentication_required                                                      | 提示权限不足或 5 分钟密码复验；不重试提权          |
| 404  | not_found                                                                                  | 对未授权对象隐藏存在性                             |
| 409  | revision_conflict / idempotency_conflict / last_admin / capacity_exceeded / state_conflict | 重新读取当前状态；不静默覆盖                       |
| 422  | invalid_request / proof_invalid                                                            | 字段反馈；过期/撤销/错误凭据统一无效               |
| 429  | rate_limited                                                                               | Retry-After 秒；真实等待时间，不能暴露地址是否存在 |
| 503  | temporarily_unavailable                                                                    | 保留输入，允许同幂等键重试；不误报未登录           |

更新携带 expected_revision；删除会话为幂等特例，不需要版本。创建和状态动作携带 `Idempotency-Key`（UUID），服务端保存 24 小时的安全结果为候选方案；同键不同载荷 409，重试先重查授权再取结果。密码/token 不保存到通用重放表；哈希后的请求比较必须使用服务端密钥，避免低熵密码离线枚举。返回新秘密的登录/复验/验证不走通用响应缓存，客户端丢结果须重新验证。

分页 limit 默认 20、最大 100，search ≤100 字符。游标签名绑定 actor、scope、筛选、排序、as_of 和最后稳定 `(create_time,id)`，10 分钟到期是本设计建议。默认降序，支持显式升序；拒绝任意列排序。时间过滤 `[from,to)`；统计与导出对同一过滤做单次数据库一致性读取并标 as_of；导出创建事务内物化有上限的加密行快照，worker只格式化该快照，不能异步再查询却沿用旧as_of。普通列表固定 create_time 上界及 keyset，允许成员状态在后页变化，刷新才能看新增；不承诺跨请求冻结快照，不允许重复同一 ID。

平台账号目录的展示状态为 `active`、`disabled`、`deleted`：`is_delete=true` 优先投影为 `deleted`，不新增数据库账号状态或恢复流程。目录、统计、导出使用同一状态筛选；已注销条目可供平台查看安全摘要，`allowed_actions` 为空。

各 status 取[数据库设计](02-用户系统数据库设计.md)对应闭集；safe_diff/filter/account_states/member_states 在实施 DTO 中用显式属性，拒绝任意字段写回。prompt_suffix 建议上限 2,000 Unicode 字符，空串可清除，作为需求参数评审，不默认为用户已接受。

登录 POST /api/sessions 由 HTTP 层传入实际 peer，应用层持久执行独立 100 次/滚动 15 分钟本地候选来源预算；成功解码后的所有尝试计数，耗尽返回 429 rate_limited 和 Retry-After（先于密码验证），不信任 X-Forwarded-For/X-Real-IP/Forwarded。当前 BFF 客户端共用后端看到的 peer 桶，内部无来源调用共用 unknown 桶；细分代理来源与容量调优需另行明确可信边界。该额度与邮箱失败锁、SMTP 邮件预算独立。

POST /api/me/password 与 POST /api/me/reauthentication 共享账号密码证明 guard（滚动 15 分钟 5 次失败、锁 15 分钟）；锁内不验证密码、不续期，失败预算/审计提交后返回各入口现有业务错误。主动改密仍须当前密码，不复用近期证明跳过；成功改密原子排队一封加密 password_changed 通知，入队失败回滚密码、epoch、会话与事件，SMTP 保持异步。

`credential_epoch` 仅本人 Session 投影用于改密 CAS，Me与平台目录 DTO 不包含它。认证页刷新丢失 grant 时重新验证；不会通过公开 GET 查询 grant。丢失原邮箱的支持流程未定义，不开放管理员改邮箱 API。

空间切换是 UI 选择，不修改全局会话。现有业务 API 携带 `X-Creation-Scope: <scope_id>`；服务端先 ResolveScope，再校验资源 owner_scope_id 与对象权限。header 不匹配资源返回 404；缺少范围拒绝 422，不回退旧 org_id。队列消息保存 actor_id/scope_id/原始命令 ID，在排队、派发、写回三个边界检查当前资格；已外发供应商请求标明实际完成/无法取消状态。

目录仍是操作者本人在所选空间内的分类，不因团队拥有项目而自动变成共享目录。目录、归类、目录过滤和命令回执必须同时匹配当前账号、所选 `owner_scope_id` 与其物理分区；无法证明的历史归属隔离。整体项目复制接口只接受当前选择空间，源与新目标均归该空间；跨空间素材转存继续走独立 media 合同。copy 的准入、回放、派发和每次租约内写入均重查实时资格，工作者使用持久执行账号与任务空间；停止证明只允许原工作者记录真实 I/O 终止，不开放内容访问。复制子模块仍须核对同一 job、源/目标、阶段和 worker fence。

脚本源写入恢复及导入的取消/调和允许当前有项目写权限的团队成员操作保留任务；平台角色与原作品作者不授予额外内容权限。导入 `can_control` 表达取消/调和资格，`retryable` 另外要求原发起者且满足原状态机，不因控制权扩大而接管冻结的执行身份。归档空间/项目仍可读取任务，但这两个操作标志为 false；HTTP 回放重新检查当前会话。未知对象或外发状态保留原回执与停止/清理证明，不自动重提。

头像上传先检查当前会话，再有界读取和解码，拒绝SVG、动图、伪MIME与超限尺寸，服务端等比缩小长边至最多1024像素，不放大小图，转为8位NRGBA再重编码PNG后写入现有个人media_asset；成品采用独立6MiB上界，头像自动处理，保留输入≤5MiB/4096×4096的合法合同。只有具备专用头像成品标记且归属于当前账号的ID可以绑定。GET /api/me/avatar返回no-store短期私有签名URL，不返回独立object_key字段；签名可能查询对象存储区域，采用5秒上限，在数据库锁外签名并在返回前重新校验当前会话和同一头像绑定。账号软删除、会话撤销或改绑后不能取得新的预览，已签发URL在剩余最多60秒窗口内仍可能有效。

邮箱换绑的旧/新验证码使用同一operation_id、创建/到期时间；flow_secret_digest绑定发起session_id与账号revision，email_version和credential_epoch分别绑定邮箱/凭据版本。Verify仅在对应邮件状态为submitted/delivered后消费对应side，双证明完成不自动登录；Complete再次检查近期密码复验、当前绑定、邮箱占位和版本，事务内更新邮箱与版本、撤销全部会话/证明并排队向两个邮箱发送加密通知。邮箱冲突返回409 email_unavailable；失败猜测计入地址共享预算；开始新操作撤销旧操作，软删除账号的邮箱仍保留占位。

不提供冷静期取消、自动物理清理或自助恢复接口。`reauthentication_required` 返回 403；`administrator_transfer_required` 返回 409 并引导先处理管理职责；版本冲突返回 409；错误、过期或已消费的证明返回 422。删除后保留账号、资源和邮箱占位，任何旧会话或恢复证明均不能恢复访问。

## 6. 界面、生成合同与演进

认证弹窗与 /login、/register 共用验证流程；/reset-password 区分邮件恢复与已登录主动改密。账号页包含资料/安全/偏好；团队页包含资料/成员/邀请/活动；平台页包含用户/团队/审计/设置。前端只发送显式字段，不把 GET 对象整包 PATCH。团队切换取消旧请求，以 actor_id+scope_id+请求序列隔离缓存；迟到结果不能渲染到新空间。加载/空/错误/无权/冲突各有状态，403 不当空列表。

实施时 Handler DTO + swag 注解生成规范到临时目录，再用仓库锁定的 @umijs/openapi generateService 生成客户端。`backend/tests/app/public_contract_test.go` 继续核对所有实际路由和 operationId；禁止手改 generated 文件或开放在线 Swagger。旧 `/api/accounts/register`、`/api/accounts/availability` 和 `/api/admin/users` 在完整切换后删除，不保留公开登录名兼容入口；切换前不得半套新身份+旧授权同时开放。

第三方邮件回调不是公共用户 API，放独立受验签内部适配器，记录 provider_message_id 并去重；媒体上传复用既有 upload 流程，验证及重编码后产出可绑定头像 ID。实际供应商请求、送达回执和用户收信分别验收。

治理写入的 `204` 只表示事务提交完成，不表示邮件已投递；前端成功后按当前权限重新读取相关目录或详情。自撤销平台权限、撤销自身会话等动作不能在提交后再强制读取受保护用户 DTO，否则已成功的变更会被误报为读取失败。提案创建仍返回 `201 Proposal`，设置更新仍返回当前设置与字符串版本。

### 媒体转存的双空间归属

个人与团队项目之间的转存必须分别验证源读取和目标写入。`media.transfer_job` 保存不可变的 `source_scope_id`、`target_scope_id`、`source_org_id`、`target_org_id`；原 `org_id` 保留项目侧调度/审计分区含义，不再表示双方资源权限。个人库始终解析当前操作者本人的个人空间，项目侧请求必须匹配所选创作空间。对象路径与冻结清单按目标实际物理归属生成；后台派发、对象访问与写回均重查两侧账号及成员资格。新增返回字段只暴露空间ID，不暴露私有对象地址。旧任务仅按明确个人拥有者及项目owner_scope_id映射回填；无法核验者保持NULL并拒绝执行，不改写已外发对象或重新发起任务。增量007已由同仓库的运行环境任务应用于现有数据库；本用户系统任务另以回滚事务验证权限边界。迁移已应用不等于完整对象存储或浏览器流程已验收。

平台团队目录筛选：`id` 为精确团队 UUID；`administrator_id` 为当前有效团队管理员 UUID（active 成员、team_admin、账号 active 且已验证邮箱且未删除）；`created_from`/`created_to` 为 RFC3339 时间，区间为 `[created_from, created_to)`，同传时起点必须早于终点。`search` 按名称包含匹配。UUID 与时间统一规范化后参与签名游标绑定；重复、未知、空值和无效筛选返回 422。

登录约束（用户确认）：登录成功始终返回普通会话。历史 `must_change_password` 字段不产生强制跳转或权限限制，客户端不得据此导航到改密页；主动改密和找回密码入口仍保留。会话撤销接口不提供要求下次改密选项。当前 Session、平台用户 DTO 与撤销会话请求均不提供强制改密字段；历史数据库列仅保留存储兼容，不用旧值恢复这一行为。
