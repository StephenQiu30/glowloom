# 用户系统接口设计

状态：目标合同，未替换运行中的 API。依据[需求规格](../requirement/01-用户系统需求.md) FR-USER-01～25、IR-01～06；字段存储见[数据库设计](02-用户系统数据库设计.md)。本文定义 HTTP 合同，Go 应用类型在各执行任务中定义，传输 DTO 不反向进入领域层。

## 1. 公共协议

前缀 `/api`，JSON UTF-8，同站代理。UUID 使用字符串；时间 RFC3339 UTC；revision/epoch 为十进制字符串以避免 JavaScript 精度丢失，服务端解析为正 int64。未声明的输入字段拒绝 422，尤其 role/platform_role/owner_id；空值仅用于明确可清除字段，省略表示不修改。

读请求 no-store；敏感写入必须验证 Origin 与会话绑定的 X-CSRF-Token，公共认证写入校验可信 Origin，注册步骤额外绑定预认证 flow。生产 Cookie HttpOnly、Secure、SameSite=Lax、Path=/、无 Domain；本地 HTTP 仅配置化关闭 Secure。登录防固定会话，退出删除 Cookie。会话 Cookie 与预认证 flow Cookie 不共用，grant/reset token 不存 localStorage 或日志。邮件链接凭据放 URL fragment，落地页读入内存后移除，GET 不消费，刷新可重新打开邮件；只允许同站 return_to。

复用现有 `httpapi.Problem`：`type/title/status/code/detail/request_id/meta`，字段错误放 `meta.field_errors`，不新造另一套 message envelope。成功直接返回下述 DTO；无内容返回 204。列表返回 `{items,next_cursor,as_of}`，next_cursor 无更多时为 null。

| 状态 | code                                                                                       | 客户端处理                                          |
| ---- | ------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| 401  | unauthenticated                                                                            | 清理私有缓存，保存允许的当前输入并显示登录          |
| 403  | forbidden / password_change_required / reauthentication_required                           | 提示权限不足、受限改密或 5 分钟密码复验；不重试提权 |
| 404  | not_found                                                                                  | 对未授权对象隐藏存在性                              |
| 409  | revision_conflict / idempotency_conflict / last_admin / capacity_exceeded / state_conflict | 重新读取当前状态；不静默覆盖                        |
| 422  | invalid_request / proof_invalid                                                            | 字段反馈；过期/撤销/错误凭据统一无效                |
| 429  | rate_limited                                                                               | Retry-After 秒；真实等待时间，不能暴露地址是否存在  |
| 503  | temporarily_unavailable                                                                    | 保留输入，允许同幂等键重试；不误报未登录            |

更新携带 expected_revision；删除会话为幂等特例，不需要版本。创建和状态动作携带 `Idempotency-Key`（UUID），服务端保存 24 小时的安全结果为候选方案；同键不同载荷 409，重试先重查授权再取结果。密码/token 不保存到通用重放表；哈希后的请求比较必须使用服务端密钥，避免低熵密码离线枚举。返回新秘密的登录/复验/验证不走通用响应缓存，客户端丢结果须重新验证。

分页 limit 默认 20、最大 100，search ≤100 字符。游标签名绑定 actor、scope、筛选、排序、as_of 和最后稳定 `(create_time,id)`，10 分钟到期是本设计建议。默认降序，支持显式升序；拒绝任意列排序。时间过滤 `[from,to)`；统计与导出对同一过滤做单次数据库一致性读取并标 as_of；导出创建事务内物化有上限的加密行快照，worker只格式化该快照，不能异步再查询却沿用旧as_of。普通列表固定 create_time 上界及 keyset，允许成员状态在后页变化，刷新才能看新增；不承诺跨请求冻结快照，不允许重复同一 ID。

## 2. DTO 字典

`ID`=UUID string，`Time`=RFC3339 string，`Version`=正整数字符串。以下字段均必填，`?` 为可省略，`|null` 为显式空；`Page<T>` 为上一节列表 envelope。Error 使用已有 Problem。Read DTO 的 `capabilities` 为字符串数组，仅提示按钮，服务端仍重查。

| DTO                | 字段                                                                                                                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accepted           | operation_id:ID, retry_after_seconds:number；已知/未知邮箱结构相同                                                                                                                                        |
| Verification       | outcome:'set_password'或'login_required', registration_grant?:string；仅已验证邮箱持有人可得到区别                                                                                                        |
| Me                 | id:ID,email:string,email_verified_at:Time,display_name:string,avatar_asset_id:ID\|null,platform_role:'creator'或'platform_admin',status:string,revision:Version,capabilities:string[]                     |
| Session            | actor:Me,session_id:ID,last_active_at:Time,absolute_expires_at:Time,persistent:boolean,must_change_password:boolean,credential_epoch:Version,csrf_token:string                                            |
| SessionItem        | id:ID,current:boolean,device_summary:string,created_at:Time,last_active_at:Time,absolute_expires_at:Time                                                                                                  |
| Preferences        | theme:'light'或'dark'或'system',prompt_suffix:string,revision:Version                                                                                                                                     |
| Team               | id:ID,name:string,avatar_asset_id:ID\|null,status:'active'或'archived'或'suspended',governance_blocked:boolean,revision:Version,capabilities:string[]                                                     |
| MemberPublic       | user_id:ID,display_name:string,avatar_asset_id:ID\|null,role:'member'或'team_admin'                                                                                                                       |
| MemberAdmin        | MemberPublic + email:string,status:'active'或'suspended'或'removed',access_available:boolean,joined_at:Time,source:string,last_team_activity_at:Time\|null,revision:Version                               |
| Space              | id:ID,kind:'personal'或'team',team_id:ID\|null,name:string,role:'owner'或'member'或'team_admin',writable:boolean；不返回 physical_scope_id                                                                |
| PlatformUser       | Me + create_time:Time,last_login_at:Time\|null,active_team_count:number,must_change_password:boolean；不包含 csrf_token/password_hash/credential_epoch                                                    |
| PlatformUserDetail | user:PlatformUser,teams:Array<{team_id:ID,role:string,status:string}>,allowed_actions:string[]；安全事件单独分页                                                                                          |
| Invitation         | id:ID,kind:'account'或'team',team_id:ID\|null,email:string,team_role:'member'或'team_admin'或null,status:string,expires_at:Time,revision:Version,delivery_status:string；不含 token                       |
| InvitationPreview  | id:ID,team_name:string\|null,inviter_display_name:string,role:'creator'或'member'或'team_admin',masked_email:string,expires_at:Time；有效 proof 后可看                                                    |
| Proposal           | id:ID,kind:'platform_grant'或'team_transfer'或'platform_takeover',team_id:ID\|null,target_user_id:ID,status:string,expires_at:Time,revision:Version                                                       |
| Event              | id:ID,actor_id:ID\|null,target_user_id:ID\|null,team_id:ID\|null,action:string,result:string,reason:string,request_id:string,safe_diff:object,created_at:Time；按角色过滤字段                             |
| Statistics         | as_of:Time,filter:object,total_users:number,account_states:object,verified_users:number,active_team_users:number,membership_count:number；团队版本只返回 team_id/as_of/filter/member_states/total_members |
| Export             | id:ID,status:string,row_count:number,as_of:Time,expires_at:Time\|null；无永久下载链接                                                                                                                     |
| Settings           | registration_enabled:boolean,team_creation_enabled:boolean,revision:Version                                                                                                                               |
| Deletion           | id:ID,status:string,execute_after:Time,policy_version:string,revision:Version                                                                                                                             |
| Mutation           | expected_revision:Version,reason:string（5～500 字符）                                                                                                                                                    |

各 status 取[数据库设计](02-用户系统数据库设计.md)对应闭集；safe_diff/filter/account_states/member_states 在实施 DTO 中用显式属性，拒绝任意字段写回。prompt_suffix 建议上限 2,000 Unicode 字符，空串可清除，作为需求参数评审，不默认为用户已接受。

## 6. 界面、生成合同与演进

认证弹窗与 /login、/register 共用验证流程；/reset-password 区分邮件恢复与已登录主动改密。账号页包含资料/安全/偏好；团队页包含资料/成员/邀请/活动；平台页包含用户/团队/审计/设置。前端只发送显式字段，不把 GET 对象整包 PATCH。团队切换取消旧请求，以 actor_id+scope_id+请求序列隔离缓存；迟到结果不能渲染到新空间。加载/空/错误/无权/冲突各有状态，403 不当空列表。

实施时 Handler DTO + swag 注解生成规范到临时目录，再用仓库锁定的 @umijs/openapi generateService 生成客户端。`backend/tests/app/public_contract_test.go` 继续核对所有实际路由和 operationId；禁止手改 generated 文件或开放在线 Swagger。旧 `/api/accounts/register`、`/api/accounts/availability` 和 `/api/admin/users` 在完整切换后删除，不保留公开登录名兼容入口；切换前不得半套新身份+旧授权同时开放。

第三方邮件回调不是公共用户 API，放独立受验签内部适配器，记录 provider_message_id 并去重；媒体上传复用既有 upload 流程，验证及重编码后产出可绑定头像 ID。实际供应商请求、送达回执和用户收信分别验收。
