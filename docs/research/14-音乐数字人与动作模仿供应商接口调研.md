# 音乐、数字人与动作模仿供应商接口调研

调研日期：2026-10-29。范围：官方公开文档与接入条件；未登录供应商控制台，未读取密钥，未请求付费生成。

## 1. 结论与证据边界

火山引擎已经分别公开音乐生成、OmniHuman 数字人和动作模仿 API，具备开展真实适配开发的文档基础。三类服务不共用一个 Ark 文生视频协议，必须分别实现提交、状态查询、引用约束与费用映射。账号开通、实际可用版本与真实质量仍需独立验收。

- **音乐**：火山音乐服务可作为首选调研结果，新计费页与旧快速接入指南对个人/企业开通有差异，不能认定仅企业可用。腾讯 TokenHub 的 Mureka 是有公开协议的新账号备选。MiniMax 仍展示音乐接口，但计费公告明确限制新用户，不能据接口页面存在就列为默认可用供应商。
- **数字人**：火山 OmniHuman 1.5 有图片加音频生成视频的明确协议。两份官方调用文档使用不同 `req_key`，应固定经账号确认的一个版本，不能自动混用。本文不把 1.5 宣称为火山最新版本。
- **动作模仿**：火山动作模仿 2.0 文档最接近“主体图＋动作视频”的产品模式；阿里万相 `wan2.2-animate-move` 可作备选。换人替换模式与动作模仿应分开命名。

证据标记：**O**＝本轮读取到的官方文档事实；**I**＝基于事实提出的接入建议；**U**＝尚未确认。公开文档不是账号权限、真实调用、质量或收费验收。部分火山文档直接打开只返回 JavaScript 页面外壳；本轮结合官方页面的搜索索引正文核对协议，没有把社区文章或第三方代理说明当官方证据。后续补查价格时搜索工具返回 429，改为只读获取阿里官方页面正文，未取得的细项明确保留 U。

本文是调研材料，不能替代原始需求、设计、PRD、Plan 或 BACKLOG；不记录实施完成状态。项目现有协议的独立源码审计见[七类能力审计](evidence/2026-10-29-creation/seven-type-capability-audit.md)，其“代码未实现”不意味着市场不存在相应 API。

## 3. 火山音乐：独立音乐服务，不是 TTS

### 3.1 提交协议

O：请求主机是 `https://open.volcengineapi.com`，HTTP POST，Query 版本为 `2024-08-12`。人声歌曲的 Action 为 `GenSongV4`（预付费）或 `GenSongForTime`（后付费），不是通用语音合成或 Ark 视频 endpoint。请求支持 `Lyrics`、灵感 `Prompt`、模型版本及曲风等字段，返回 `Result.TaskID` 与预计等待时间。中文歌词范围 5–700 字符、英文 5–2000 字符。音色数量与具体模型版本相关，不能统一写死。[生成歌曲接口](https://docs.volcengine.com/docs/Audiovideounderstandingandprocessing/Generatevocalsongs?lang=zh)

O：纯音乐对应 `GenBGM`／`GenBGMForTime`；`Text` 是描述，另有 `Duration`、`Segments`、回调与存储选项。文档当前说明 v5.0 时长 30–120 秒，默认 60 秒；分段总时长优先级高于文本中指定时长，再高于外层 Duration。旧 v4.0 的限制不能套到 v5.0。纯音乐和人声歌曲应采用不同参数校验。[生成纯音乐接口](https://docs.volcengine.com/docs/audio-video-understanding-and-processing/generate-pure-music-1?lang=zh)

### 3.2 查询与结果

O：POST 同主机，`Action=QuerySong&Version=2024-08-12`，请求体为 `TaskID`。状态值 0 等待、1 处理中、2 成功、3 失败；返回进度、失败原因及 `SongDetail`，包括 `AudioUrl`、歌词、字幕和时长。文档提示默认 WAV，但可能因转码返回 MP4，要求自行转存并按需转码；不能只凭文件后缀认定音频格式。结果链接文档有效期为一年。[查询任务接口](https://docs.volcengine.com/docs/Audiovideounderstandingandprocessing/Querytask-1?lang=zh)

### 3.3 鉴权、开通与未知

O：快速接入指南要求实名／服务开通，并写明购买需企业认证；通过 AK/SK 授权，子账号需要对应产品权限。生成接口签名示例包含 `X-Date`、`X-Content-Sha256`、`Authorization`，响应元信息使用 `imagination` 服务与 `cn-beijing` 地域。不能把 Ark Bearer Token 直接带入该协议。[快速接入指南](https://docs.volcengine.com/docs/audio-video-understanding-and-processing/api-quick-access-guide?lang=zh)、[歌曲接口](https://docs.volcengine.com/docs/Audiovideounderstandingandprocessing/Generatevocalsongs?lang=zh)

U：本项目账号是否企业认证、具体模型获准版本、直连接口并发、价格阶梯、失败收费与退款规则、提交幂等语义均未确认。Coze 插件也调用此服务，但插件限制不能直接推导成直连 API 配额。回调字段存在不代表本轮已核实回调验签合同。

I：产品上将“音乐生成”的人声／纯音乐作为明确模式；不要复用“音频生成”的音色朗读参数。报价应采用确认后的具体产品、模型、计费单位与输出数量，未知价格不能显示为免费或零积分。

## 4. 火山数字人：OmniHuman 1.5

### 4.1 正式调用合同

O：POST `https://visual.volcengineapi.com?Action=CVSubmitTask&Version=2022-08-31`。一份官方生成文档指定 `req_key=jimeng_realman_avatar_picture_omni_v15`；必填 `image_url`、`audio_url`，可选 `mask_url`、`seed`、`prompt`、`output_resolution`、`pe_fast_mode`。分辨率可为 720 或 1080；文档建议按分辨率匹配快速模式以对齐即梦效果。[生成视频接口](https://docs.volcengine.com/docs/jimeng-ai/call-step3-video-generation?lang=zh)

O：同主机使用 `Action=CVGetResult` 查询，提交 `req_key` 和 `task_id`；需先检查外层业务码，不能把 HTTP 200 当生成成功。状态包含等待／生成／完成及找不到／过期；`done` 本身仍需核对结果与业务错误。视频 URL 有效期一小时，任务记录可能在十二小时后过期。[生成与查询合同](https://docs.volcengine.com/docs/JimengAI/CallStep3VideoGeneration?lang=zh)

O：另一份官方生成页指定 `req_key=jimeng_realman_avatar_picture_omni15_v2`。两者是版本差异证据，本文不将其解释为可随意互换的别名。[另一版本生成页](https://docs.volcengine.com/docs/jimeng-ai/call-step3-video-generation-1?lang=zh)

### 4.2 引用、费用与接入限制

O：产品页要求图片 JPG／PNG／JFIF，小于 5 MB、尺寸小于 4096×4096；音频小于 60 秒，并建议不超过 15 秒。输出为 720P／1080P MP4；提示词最多 300 字符。需要选择说话主体时须结合主体识别与遮罩流程。控制台开通对应产品，页面标价 1 元／秒，并发为 1。[产品介绍](https://docs.volcengine.com/docs/JimengAI/Productintroduction-6?lang=zh)

O：Visual 系列文档给出 AK/SK 签名调用；具体账户应使用相应服务和地域配置。U：上述两个 `req_key` 对本账号的可用性、是否还有更新版本、API Key 替代鉴权是否适用于该版本、音频完整编码／声道限制、主体识别前置接口的完整合同，均需继续核对，不能从图片演示补全。

I：先定义“单张主体图＋驱动音频→数字人视频”的独立模式；音频已存在与文本先转语音是两个流程。后者会产生额外 TTS 成本，不能把两次生成当作一次免费参数转换。多人选主体需要单独的识别、遮罩结果及失败状态，不能只增加一个人物下拉框。

## 5. 火山动作模仿 2.0

O：提交为 POST `https://visual.volcengineapi.com?Action=CVSync2AsyncSubmitTask&Version=2022-08-31`，`req_key=jimeng_dreamactor_m20_gen_video`。输入一张图片（`image_urls` 或 `binary_data_base64`）与 `video_url`；两种图片表示并存时 base64 优先。可选 `cut_result_first_second_switch` 默认开启，去掉开头一秒过渡。此版本请求体未列提示词字段，不能把普通视频生成 prompt 强行透传。[动作模仿 2.0 接口](https://docs.volcengine.com/docs/jimeng-ai/action-imitation-20-interface-documentation?lang=zh)

O：图片 JPEG／JPG／PNG，至少 480×480、小于 4.7 MB；文档上限及缩放说明为 1920×1080。动作视频最长 30 秒，MP4／MOV／WEBM，至少 200×200、最大 2048×1440。输出 MP4、720P、25fps，比例近似跟随图片。查询 Action 为 `CVSync2AsyncGetResult`，传相同 `req_key` 与 `task_id`。结果 URL 一小时有效，任务可能十二小时过期；`done` 仍需判断成功结果或错误。[输入与查询约束](https://docs.volcengine.com/docs/JimengAI/ActionImitation20-InterfaceDocumentation?lang=zh)

O：文档示例使用 AK/SK 签名、`cn-north-1` 地域与 `cv` 服务，同时提供 API_KEY 接入说明链接。U：本轮未读取该替代鉴权页面的完整请求规则，不能声称只允许 AK/SK，也不能声称可以直接使用 Ark Key。产品需在控制台开通；专属产品页列 0.4 元／生成秒、并发 1。[接口鉴权入口](https://docs.volcengine.com/docs/jimeng-ai/action-imitation-20-interface-documentation?lang=zh)、[产品与价格](https://docs.volcengine.com/docs/jimeng-ai/action-imitation-20-product-introduction?lang=zh)

I：引用角色应固定为主体图片与动作视频，文本输入在该型号下隐藏或禁用。报价须明确裁剪一秒对实际输出与收费秒数的影响；文档没有充分解释时不能自行减一秒计费。RTF 等产品指标不能作为本项目超时承诺。

## 6. 可替代平台

### 6.1 阿里万相动作模仿

O：`wan2.2-animate-move` 通过 POST `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/image2video/video-synthesis` 提交，另有新加坡地域。需地域对应 Bearer API Key 和 `X-DashScope-Async: enable`。输入是公开可访问的 `image_url`／`video_url`；参数支持 `wan-std`、`wan-pro` 与图片检测。图片支持 JPG／JPEG／PNG／BMP／WEBP、200–4096 像素、最大 5 MB；视频 MP4／AVI／MOV、2–30 秒、200–2048 像素、最大 200 MB。异步返回 task_id，文档说明有效期 24 小时。[动作模仿 API](https://help.aliyun.com/zh/model-studio/wan-animate-move-api)

O：同地域主机 GET `/api/v1/tasks/{task_id}` 查询，状态为 PENDING、RUNNING、SUCCEEDED、FAILED，任务过期为 UNKNOWN。官方分别说明 task_id 和结果 URL 均有 24 小时有效期；建议立即转存结果，查询默认 RPS 为 20。[查询合同](https://help.aliyun.com/zh/model-studio/wan-animate-move-api)

O：型号价格表按输出计费，北京地域标准模式 0.4 元／秒、专业模式 0.6 元／秒；新加坡为 0.880709／1.321063 元／秒。页面另列北京免费额度及有效期，但不能假定本账号仍有额度。U：当前账户折扣、余额和提交并发。[官方模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)

O：`wan2.2-animate-mix` 是保留原视频场景的角色替换，与将图片人物按参考视频动作驱动的 move 模式不同。[角色替换 API](https://help.aliyun.com/zh/model-studio/wan-animate-mix-api)
