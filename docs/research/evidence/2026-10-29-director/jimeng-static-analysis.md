## 2. 导入、资源边界与尺度

- **S** 模型文件必须非空且不超过 `0x12c00000` = 314,572,800 bytes（300 MiB，界面称 300 MB），按后缀识别 FBX/GLB/GLTF/OBJ（1226800–1227500）。
- **S** 角色弹窗只接收 `.fbx`，物体接收 `.glb,.gltf,.fbx,.obj`（769218–769800；959045–959800）。角色需要兼容 Mixamo 骨架；动作导入文案要求兼容 65 骨骼、包含动画的 FBX（26854–26985）。具体骨骼名称检查在依赖模块，未核验。
- **S** FBX 必须有二进制头 `Kaydara FBX Binary`；FBX 源单位按厘米换算 0.01，GLB/GLTF/OBJ 按米（1227100–1228500）。GLB 检查魔数、版本 2、总长与 JSON chunk。
- **S** GLTF buffers/images 的 URI 只能内嵌 data URI；加载管理器只接受 data/blob 资源，拒绝外部模型资源（1228200–1228800；1231100–1231600）。**注意：旧文案“带上 textures/BIN 文件”与当前解析分支冲突，不能把旧文案当现行支持。**
- **S** 导入先检查包围盒/高度/可见 mesh；统计 mesh、三角面、材质、纹理及估算纹理字节；将底部中心设为放置锚点 `bottom-center-v1`，保存 offset 与米制尺寸（1229000–1230900）。这不改原始模型文件。
- **L** 动作文件上限 100 MiB；多动画文件一次导入一个 clip；可预览但不影响场景；缺动画、骨架不匹配、长度/容量超限、解析失败分别报错（26604–28699）。具体长度/数量上限未在本包定位，U。
- **S** 背景上传接受 PNG/JPEG/WebP/BMP/GIF，可多选（731485）；背景尺寸/数量/文件上限 U。
- **L** 包中还有 SPZ 三维世界导入文案（20367–20825），不能据此断言当前 Web UI 开放；标为待核，不计入已确认一致性目标。
- **S** 预览和导出清理 AbortController、Object URL、纹理和模型资源（1223000–1223500；1319800–1320500；1361500–1366500）。

## 3. 时间线、动作、关键帧与运镜

- **S** 显示帧率选项为 24/25/30/50/60 加当前保存的 displayFps（1124315）。**L** 改短总时长会为了保留片段及机位关键帧扩展时长（34760），具体最大时长 U。
- **S** 拖动片段的帧偏移必须为有限整数，不得移动到 0 帧前；移动后检查碰撞，冲突返回原 clips（1042900–1044200）。**L** 同一角色片段不可重叠，释放回到原位（40415）。
- **L** 片段支持删除、复制、循环、速度、与前一段的按帧混合；隔有空档则不混合。静态姿势可变成默认 1 秒片段，拖边缘改时长（30230、33384–34343）。
- **L+S** 时间线包含分镜（选择机位、添加/重排/裁时长/删除镜头）、机位轨道与对象属性轨道；关键帧可移动/删除/patch，机位和注视点可独立记录（36821–40415；1041000–1042900）。
- **S** 曲线支持 linear/smooth/hold；切线有 vector/aligned/free；自定义 Bézier 四参数 clamp 到 [0,1]；修改相邻片段切线时保留另一侧切线（1044300–1046300）。**L** 曲线图横向帧、纵向值，归一曲线端点不动、拖切线调缓动（37907–40364）。
- **L** 对象移动/行走路径：在地面定位并拖动高度，指定开始/结束时间，按路程分配关键帧以保持近似均匀速度；帧数不足/时间范围非法/覆盖原关键帧需反馈（34863–36147）。路径点数量上限 U。
- **L+S** 机位运镜是“锚点→路径→时间和预览→确认”暂存流程，只有确认后才写时间线（41242–45327；1046600–1047000）。预设：推、拉、横移、上升、下降、环绕、半环绕、螺旋、滑动变焦、荷兰角、左右摇、上下摇（47883–49955）。
- **L** 自定义运镜分固定机位（移动注视点）、固定注视点（移动机位）、自由运镜（先注视点路径再机位路径，共同时间范围）。预览可看导演视角和机位视角，确认后创建机位并添加路径（45475–47819）。

## 5. 保存、恢复与并发

- **S** 本地草稿是 `director-stage-local-draft`，包含 project 和 baseVersionId；本地数据库名 `director-stage-local-drafts`，drafts+metadata 两个表；预算 64 MiB/50 条，按 lastUsed 淘汰（1564600–1569100）。
- **S** 可从旧 localStorage 迁移，仅成功写入后删除旧条目；资源临时 mediaUrl 清空，保持资源 ID；读写串行、支持权限/AbortSignal、打开库 5 秒超时。
- **S** 编辑后 500 ms 批量写本地草稿，卸载时 flush；云端保存成功后 markSaved 与更新 baseVersionId，本地草稿失败会单独提示（1584200–1586100）。
- **S** 云端 body 最大 4 MiB，3 MiB 起警告；规范化键排序并计算内容摘要，unchanged 不重复写；save 带 projectId/nodeId/writeId/contentSha256，成功返回 versionId（1558800–1560200；1563600–1564500）。具体远端 API/事务保证 U。
- **L+S** 远端新版本、恢复草稿基线不一致有覆盖提示；退出有继续编辑、仅保留本地后关闭、保存并关闭。加载远端最新会明确替换本地未保存改动（52961–54573；1557500–1558800）。
- **S** 只读不允许编辑/保存/写回；读中或资源不可用分别处理，渲染错误有重试/关闭；异步操作检查账号、项目 scope 与 generation 防止过期结果写入（1577900–1584200；1361500–1366500）。

## 给主调查的结论

一致性目标应覆盖两种工作区的转换规则、事务式交互预览、焦点路由、资源尺度归一、分镜/关键帧/路径、保存版本冲突、输出与画布回写分离，而不只是复刻三栏 UI。发布包含有文案与当前逻辑不一致（GLTF 外部资源）及可能未开放功能（SPZ、桌面分支），需求矩阵须以当前现场 UI/实际行为为主，静态发现作补充，不能把全部字符串算成已开放功能。
