# 连线偏移与高亮纠错

2026-11-03。用户截图显示基线与彩色流段不重合，选中剧本节点导致整条关系持续高亮。

## 原因与修正

CanvasNodeDrag.paintEdges 在拖动期间直接更新 SVG d；ConnectionFlowLayer 原来只按 React 的 path props/注册变更上传网格，因而流段仍沿旧路径绘制。现在每帧读取注册路径的实际 d，只有变化时重建并上传；取消回弹也走同一过程，静止不重复上传。原周期、颜色、尾长和共享 WebGL 表面不变。

关联节点 active 不再触发蓝色基线/流光；直接选中边、悬停边、生成中与新建连接预览保留原活动反馈。此为用户截图纠正后的本项目行为，不声称已重新完整标定即梦所有状态。

## 验证

- 修改前新增两条断言均失败（red.log）：命令式改 d 后未重新上传；仅 active 仍出现流光。
- 修改后5文件20项通过（green.log）。覆盖拖动改线、取消恢复、静止不重复上传、缩放参数、低动态暂停、悬停/选边与几何编辑。
- `pnpm --dir frontend exec tsc --noEmit` exit0；4文件 ESLint 通过；范围 diff --check通过。
- Chrome 浏览器扩展接口不可用，改用原生 Chrome 可访问性操作打开用户截图原项目/画布。4节点、已保存、选中剧本后两条线保持灰色，截图 node-selected.png。未修改节点内容或位置，未触发生成。原生界面检查不等于生成中拖动的GPU逐帧验收；后者本轮由实际路径驱动的组件回归覆盖。
