| 编号        | 前序观察                                                                              | 采用边界                                                                     |
| ----------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| OBS-CONV-01 | 空文字且无参考时发送禁用；图片参考可使Agent发送可用；仅引用旧文本且没有新输入时仍禁用 | 实现显式区分新输入、可用媒体和引用文本，不泛化所有模型支持图片               |
| OBS-CONV-02 | 取消文件选择保留草稿；移除其中一图保留正确的另一图；移除全部后按剩余文字重新判断发送  | 复用真实绑定身份，不按显示位置删除                                           |
| OBS-CONV-03 | 发送进入工作区、出现历史与用户消息；Agent输入清空；图片模式可保留原生成提示词         | 两模式保留各自提交语义，不能全局强制清空                                     |
| OBS-CONV-04 | 停止后保留用户消息与已有输出；页面曾同时显示外层“已完成”和嵌套“思考已暂停”            | 本项目以持久run状态解释停止；不照搬矛盾文案或展示私有思维链                  |
| OBS-CONV-05 | 失败/停止后重新生成追加新尝试；重试中再停止仍保留旧记录                               | 新尝试有独立身份；网络恢复不等同重新生成                                     |
| OBS-CONV-06 | Agent可自主生成图片，前序一次单图结果依次展示活动、图片完成和最终回复                 | 确认产品形态，不据此锁死Seedream模型名、比例、分辨率或消费金额               |
| OBS-CONV-07 | 前序图片队列未找到可用取消入口；Agent也未实际取消，任务随后自然完成                   | 未证明取消或退款，不展示“已取消”假结果；本项目已有正式取消能力时按其回执呈现 |
| OBS-CONV-08 | 图片“重新编辑”回填输入；“再次生成”产生新批次；文本也有重新生成与引用                  | 回填不执行；新消费需要明确动作和现有授权检查                                 |
