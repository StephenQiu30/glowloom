# Magpie 供应商与模型接入实测

依据：[SRC-AI-51](../requirement/04-AI平台接入与预设管理需求.md#src-ai-51-自定义供应商模型配置与-logo2026-11-14)。2026-11-14 使用用户指定的 agent-desktop，在本机 Magpie 窗口 `w-17822` 只读查看；应用版本未核对，以下结论限于当前可见界面。

## 观察与设计取舍

| 本机观察 | 织光设计取舍 |
| --- | --- |
| “添加供应商”先展示预设目录，并提供“自定义供应商”；自定义弹窗集中填写名称、Base URL、协议、API 密钥、图标和模型。 | 预设与自定义共用供应商配置流程；供应商是地址、凭据、Logo及后续模型的归属。 |
| 自定义协议选项显示 OpenAI 兼容、OpenAI Responses、Anthropic 兼容、Gemini 兼容和 System One。 | 借鉴先选协议再填地址；织光只展示其已实现并支持该地址能力的协议。界面存在某选项不证明已验证其真实协议行为。 |
| 图标区有“选择图片…”、“获取图标”和“内置图标”。 | 首期采用上传、更换、移除与默认回退；自动抓取图标不作为首期条件。供应商级资源与跨账号可见性按织光自己的合同处理。 |
| 自定义模型区有“获取模型”按钮与模型输入；说明文案称可勾选目录、直接填ID，或保存后自动获取。 | 用户明确要求移除独立手工ID流程。织光采用显式读取目录、选择候选后补全统一表单；不因保存供应商而自动发起目录读取或生成。文案中的自动获取仅为观察到的说明，未做保存实验。 |
| 已有供应商的“调整”弹窗内有模型选择、添加模型、重新获取模型、测试模型和模型设置。 | 保存供应商后，在同一供应商入口持续新增、选取和配置模型，避免重复建立同一供应商。 |
| 模型设置展开显示名称、模型映射、上下文窗口、最大输出、价格及其他能力项。 | 名称、模型标识和能力默认显示；协议支持的上下文与输出限制放在高级设置。价格仍在既有价格/发布流程维护，同名模型不继承其他渠道的采购事实。 |
| 供应商高级区包含额外请求头、额外请求体、透传头、代理、并发/速率、上下文及输出限制等，并有更多端点区域。 | 采用默认收起与按能力展示；私有鉴权、任意请求改写、模型别名、代理及多端点不是本次已确认范围，不直接复制成新需求。 |

## 证据与限制

已实际打开添加供应商目录、自定义供应商弹窗及高级区、已有供应商调整弹窗和模型设置，并用取消/关闭返回供应商列表。未填写字段、上传图片、保存配置、点击获取模型、检测协议或测试模型，也未显示、复制或读取密钥。没有读取 Magpie 本地配置文件。

本轮仅确认界面结构及可见字段。Logo 替换后是否实时传播到旧模型、保存后的自动读取、实际协议兼容和真实费用均未实测，不能写成 Magpie 已验证行为。模型设置中的元信息来源或价格说明也不是织光的计费接受依据。
