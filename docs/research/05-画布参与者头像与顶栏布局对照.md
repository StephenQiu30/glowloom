# 画布参与者头像与顶栏布局对照

日期：2026-10-24。范围：画布信息布局、参与者头像及相关设计状态。设计来源：[设计10 §7.7.1](../design/10-画布交互设计.md#771-参与者头像与顶栏信息分组2026-10-24)。本记录不证明生产页面或协作后端已完成变更。

## 用户来源

本轮要求：“使用 shadcn 中的头像组件，展示参与人的信息，并且 hover 的可以看到，然后历史版本去掉……先对设计稿进行修改优化”。随后提供官方 Avatar 示例，要求认真核对头像组件，纠正协作用户展示。

## 一手资料与观察边界

- [shadcn Avatar（Radix）](https://ui.shadcn.com/docs/components/radix/avatar)：使用项目包管理器执行 `pnpm dlx shadcn@latest docs avatar hover-card popover`、`view @shadcn/avatar`、`view @shadcn/avatar-example`，核对实际 registry 结构。当前项目已提供 AvatarImage、AvatarFallback、AvatarBadge、AvatarGroup、AvatarGroupCount，无需另造头像组件。
- [shadcn HoverCard](https://ui.shadcn.com/docs/components/radix/hover-card)与[Radix HoverCard](https://www.radix-ui.com/primitives/docs/components/hover-card)：HoverCard是视觉预览，读屏器忽略其内容；点击、键盘及触屏必须能访问同样的信息。
- [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines)：核对键盘可用、可见焦点、视觉与命中目标一致、移动端44px目标、图片预留尺寸、状态不只依赖颜色。Vercel插件搜索未命中这份规范，直接读取官方页面补足。
- Jimeng已登录画布：`/ai-tool/ai-canvas/284cfd4e-5e10-4f6e-8fc9-2dbe7097381e`。仅观察当前页面、DOM、截图及该页已加载的前端脚本；没有创建、生成、分享或改写对方画布。

## Jimeng信息布局观察

1512px宽视口的当前状态：左侧依次为品牌、画布标题/项目菜单、节点数、保存状态；右侧搜索和生成历史成组，之后为分享、更多、积分及账户。搜索、生成历史的DOM框约28px，与本项目已经确认的44px操作热区并不相同。

本项目采用相同的信息分组原则：文档身份与保存状态放左侧，参与者及操作放右侧；保留本项目主题入口，不复制积分/会员模块。当前观察没有发现版本历史入口，不据此断言对方产品全局没有该功能。生成历史与版本历史不是同一能力。

## 官方组件核对与设计修正

| 项目 | 官方结构/本轮设计 |
| --- | --- |
| 头像尺寸 | 默认32px；小24px，大40px；图片object-cover并圆形裁切 |
| 组内排列 | AvatarGroup中的头像直接重叠8px，2px背景环；3个默认头像总宽80px |
| 溢出 | 独立AvatarGroupCount，默认32px；3个头像加`+2`总宽104px，表示5位用户 |
| 回退 | AvatarFallback是图片不可用时的回退，不是所有用户的默认主展示 |
| 徽标 | 默认头像右下10px徽标、2px背景环；本项目仅在详情头像显示，配合“在线”文字 |
| 浮层 | HoverCard预览；Popover承载点击、键盘及触屏可访问详情；可关闭、回焦、避开视口边界 |
| 用户去重 | actorId对应的已验证用户身份聚合连接；clientId只标识页面，不能充当人数 |
| 资料缺失 | 未获授权公开资料时采用通用名称/缩写，不把原始ID或虚构身份展示为真人资料 |

此前分开的44px圆圈容器已在设计中移除，它会破坏官方头像重叠。桌面头像露出24px；触屏使用整组44px高的入口打开名单，避免扩大单头像透明热区后互相遮挡。AvatarGroup自身内置的负间距属于官方组件内部结构，不是业务层重新拼装间距。

设计采用官方示例中的公开头像素材；这些图片与示例姓名仅用于设计展示，不表示真实在线用户。生产资料仍需从授权公开成员资料接入，现有YjsPeer只有actorId、clientId、cursor、updatedAt。
