# 模型启用开关与 1122 验收

日期：2026-11-13。范围为模型列表、详情及启停/配置生效逻辑；未执行收费生成。

## 设计与实现

唯一来源为[设计07 §7.33](../design/07-AI平台接入市场调研与架构设计.md#733-模型启用开关与配置生效2026-11-13)，对应 [Figma 列表](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT?node-id=3413-73918)及[详情](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT?node-id=3408-73653)。

- 列表、详情复用 Switch 和同一激活编排；移除详情与行菜单的“发布”入口。
- Switch 依据模型自身状态，可用性保留服务端独立投影。
- 首次启用自动校验配置、价格和只读鉴权；重新启用恢复原生效 release，应用新草稿使用独立“应用更新”。
- 停用复用有审计、幂等键和修订号检查的接口；提交中不提前改变开关值，结果未确认时提供查询入口。
- 修正保存模型配置草稿使原 release 不可用的问题，公共目录和新执行检查继续使用原绑定；连接配置或 Key 变化仍按实际合同校验。
- 固定列表启用列的渲染函数，刷新后保留操作进度及失败提示。

## 1122 实页验证

使用已有管理员会话，在 `http://localhost:1122/models?provider=e5177f0e-b209-4f76-a827-b4441bad2476` 通过实际 UI 操作：

| 场景                               | 观察结果                                                               |
| ---------------------------------- | ---------------------------------------------------------------------- |
| 新镜像加载                         | 列表增加启用列和 Switch，可用性独立显示                                |
| 列表停用 Seedance 2.0 Mini         | 开关关闭，显示未启用、不可用；详情同步                                 |
| 详情重新启用同一模型               | 自动完成必要检查，显示已启用、可用；列表同步                           |
| 刷新持久化                         | Seedance 2.0 Mini 保持开启和可用                                       |
| 缺少价格的 Seedream 5.0 Pro        | 提示“请先在「价格」保存有效价格。”，开关保持关闭，列表刷新后反馈仍可读 |
| 编辑未保存的上游模型 ID 后切换标签 | 输入保留，启用状态不受影响；验收后已恢复原输入且未保存                 |
| 桌面与 390×844                     | 列表可见开关，详情标题、开关、模型设置/价格和保存按钮均可见；无发布页  |

Seedance 2.0 Mini 最终恢复验收前的已启用状态；Seedream 5.0 Pro 保持未启用。未保存新模型配置或价格，未发起供应商生成。真实版本恢复的精确绑定与并发参数另由组件/编排测试验证，不把 UI 截图视为供应商生成验收。
