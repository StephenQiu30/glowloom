### 实际缺陷与修复

P1：前端 `src/app/api/[...path]/route.ts` 白名单只包含旧 `agent-sessions`，当前页面和 Go 已采用 `agent/sessions`、`agent/skills`。因此请求在前端返回 `404 {"code":"not_found"}`，并未到达业务处理器；服务健康、登录和项目正常仍无法读取对话。

复现：登录→选择已有 QA 项目→Agent 模式→左侧历史出现重试读取→重试仍 404，技能也 404。证据为 `history-read-repro.webm`、修复前后截图和脱敏请求摘要。修复将白名单对齐当前 Go 合同，覆盖会话、运行、控制回执、消息分页、原发送核对及技能路径，保留方法/UUID/查询边界，移除未使用的旧路径。浏览器复验 sessions/skills 均 200。

同时核对事件流代理合同，补传 `Last-Event-ID`；事件订阅沿浏览器取消信号存活，不再被普通 API 的 10 秒期限截断。相关回归验证了流内容、续传头和取消传播，**尚未经过真实在途 run 的长连接验收**。
