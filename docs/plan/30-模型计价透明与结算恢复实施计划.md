# 模型计价透明与结算恢复实施计划

唯一来源PRD：[PRD21](../prd/21-模型计价透明与结算恢复.md)。Goal：使已冻结消费的金额与恢复行为可解释、可查证、不可重复购买。Architecture：扩展现有operation报价/查询/工作流及billing事务，保持一套价格与账本。Tech Stack：现有Go、PostgreSQL、PostgreSQL任务/Outbox、Next.js及生成API。

本计划定义用户授权实施的步骤与测试要求；授权出处见需求04 SRC-AI-35。当前状态、优先级、估算、外部条件及下一步只见[BACKLOG](../../BACKLOG.md#beeftv-adoption)。

## 全局约束

唯一技术规则由PRD来源设计34持有：int64 CNY微元/big.Rat、价格/汇率冻结、缺失不等于零、未知不重发、服务器而非UI决定准入。1:10/零加价外部承诺、分数积分、缓存/视频Token、迟到原币账单及退款补偿政策依赖DEC-BIL-03/05/07，相关扩展未确认不得开放。

不引入backend/internal/billing/pricing.go第二套算法；继续operation/application/pricing.go。初始工程阶段无业务库schema重放、服务启动、真实收费和Git发布授权；后续Git交付及首个模型本地运行授权分别以需求04 SRC-AI-35/36为准，不扩展为生产全量迁移或无限收费。禁止秘密回显；按正式实施任务创建必要生产文件，不预建无消费方脚手架。

SRC-AI-38执行切片：先固定缓存用量、视频Token报价/回执、图片参考计数在发布校验/报价/实际结算间的反例，再扩展已有函数并跑隔离回归。通过原发布命令追加模型/价格草稿，保存来源；不发真实生成、不改变现有Flash发布和账本。DeepSeek分时两档只审价留存；进度与剩余外部条件见BACKLOG。
