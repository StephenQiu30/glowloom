# 平台用户管理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立全站账号目录、独立平台权限、治理、审计及受控导出。

**Architecture:** identity负责全局治理，app同库事务协调账号禁用与workspace团队冻结。平台投影与业务内容授权分离，读写都查当前权限。

**Tech Stack:** 既有Go/Gin/GORM/PostgreSQL、Next.js/React与生成客户端。

**Spec:** [SRS](../requirement/01-用户系统需求.md)、[总体设计](../design/01-用户系统总体设计.md)、[数据库](../design/02-用户系统数据库设计.md)、[接口](../design/03-用户系统接口设计.md)、[PRD](../prd/01-用户系统.md)。

## Global Constraints

- 前置01；至少保留一个active且verified的平台管理员，临时锁定不影响治理资格计数。
- 敏感动作5分钟复验、原因5～500字符、expected_revision；旧团队管理员不能自动获得平台权限。
- 分页20/最大100、搜索100字符；导出最大10000行、完成后15分钟有效，生成/下载均重查当前权限。
- 各动作通知/审计同事务，通知故障不回滚已提交授权变化；遵守[总览](00-用户系统执行总览.md)检查点。
