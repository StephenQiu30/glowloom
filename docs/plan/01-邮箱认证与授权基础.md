# 邮箱认证与授权基础 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成真实邮箱认证及所有业务入口的个人/团队范围授权。

**Architecture:** identity 处理凭据和会话，workspace 提供明确范围事实；internal/app 注入依赖。沿用单库事务、服务器会话和现有 HTTP 合同生成链。

**Tech Stack:** Go 1.26 / Gin / GORM / PostgreSQL / Next.js 16.3.6 / React 19.2.8 / Vitest；版本以执行时锁文件核对。

**Spec:** [SRS](../requirement/01-用户系统需求.md)、[总体设计](../design/01-用户系统总体设计.md)、[数据库](../design/02-用户系统数据库设计.md)、[接口](../design/03-用户系统接口设计.md)、[PRD](../prd/01-用户系统.md)。

## Global Constraints

- 前置 06-P1 完成只读迁移预检；用户已授权在 main 实现。只复用现有连接和已运行服务，不创建隔离环境；发信及切换取决于真实配置和已核验映射。
- ASCII 邮箱≤254字节；密码8～128 Unicode字符；验证码6位/10分钟/5次；注册grant10分钟；恢复30分钟。
- 失败5次/15分钟锁15分钟，锁内不续期；邮件60秒间隔、5次/小时、10次/天。
- 会话空闲12小时/绝对7天；复验5分钟；个人、团队、平台权限独立，任何授权源错误都拒绝受保护访问。
- 下列 Create 为未来实现文件，Modify 为现有文件；只创建当前任务需要的文件。按文件职责注入时钟，禁止全局工具包。所有任务遵守[执行总览](00-用户系统执行总览.md)共同检查点。
