# 短剧工作室实施计划

唯一产品来源为 [PRD24](../prd/24-短剧工作室.md)。

1. 用 REA 与可见界面建立 [即梦需求基线](../requirement/23-短剧工作室对齐即梦需求.md)。对照当前实现后，在 [原 Figma 文件](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/Glowloom?node-id=3541-96353) 更新工作室、共享导航及项目工作流，核对核心截图。
2. 复用资产读取、模板、写入与权限边界，验证游客入口、近期短剧查询、新建的幂等键和跳转回执。浏览器验证页签及「全部」跳转。
3. 把文件和文本接入剧本来源与导入服务。使用隔离项目测试成功、格式拒绝、提交超时、原任务重试、分集编辑与保存。
4. 明确短剧生成、转绘、预演及后期任务合同。先用受控供应商验证请求、事件、计费与取消，再以允许的真实调用验证产物。
5. 将剧集、分镜和资产映射到项目工作区，检查助手的影响范围、乐观版本校验、3D 导演台与后期的引用写回、只读公开画布与副本权限。
