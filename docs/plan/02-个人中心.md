# 个人中心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让本人真实保存资料、头像、偏好、换绑邮箱及管理设备。

**Architecture:** identity本人用例只修改当前账号，media负责头像验证与重编码；复用01会话和事件。界面按服务器读回展示成功。

**Tech Stack:** 既有Go/Gin/GORM/PostgreSQL与Next.js/React/shadcn/Radix/Vitest。

**Spec:** [SRS](../requirement/01-用户系统需求.md)、[数据库](../design/02-用户系统数据库设计.md)、[接口](../design/03-用户系统接口设计.md)、[PRD](../prd/01-用户系统.md)。

## Global Constraints

- 前置01通过；显示名1～32 Unicode字符；头像JPEG/PNG/WebP≤5MiB且解码≤4096×4096，拒绝SVG/动图和他人资源。
- 偏好后缀≤2000字符，theme为light/dark/system；新后缀只用于新草稿。
- 换绑原、新邮箱证明在同一10分钟窗口，复验5分钟；成功撤销所有会话，不改ID/作品/成员关系。
- 所有任务执行[总览共同检查点](00-用户系统执行总览.md)，无授权不commit、迁移或发真实邮件。

## Review Focus

- 伪图片/超大解码/他人头像 → 02-P1 `TestSelfProfileAndAvatar`。
- 两管理员/本人同时改资料版本冲突 → 02-P1 `TestSelfProfileCAS`。
- 新旧邮箱证明混用操作或邮箱已被占用 → 02-P2 `TestEmailChangeAtomicity`。
- 离线读取会话误触退出 → 02-P3 `session failure preserves retry`。
- 切换账号偏好、旧草稿被后缀覆盖 → 02-P3 `preferences affect only new draft`。
