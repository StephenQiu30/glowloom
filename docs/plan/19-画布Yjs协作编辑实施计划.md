# 画布Yjs协作编辑实施计划

Yjs 唯一协议切换验收：静态检查无 OT 变换/提交/旧前端分支；验证旧协议拒绝、Yjs 原子接受及幂等、稳定身份删除恢复、历史恢复、权限撤销、运行时故障和断线未知请求查证；保留非 OT 业务覆盖及原有未提交改动。实施进度与证据在 BACKLOG 记录。

> 唯一来源PRD：[09-画布协作编辑](../prd/09-画布协作编辑.md)。进度、阻塞与下一步见[BACKLOG](../../BACKLOG.md)。

## 1. 交付能力

Yjs共享画布、Tiptap协作正文、稳定引用、个人撤销、在线状态、持久确认、断线恢复和历史版本恢复。

## 3. 实施顺序

先固定共享模型和接受合同，再验证并发语义；接通协作服务、持久化与Docker运行后，接入节点及Tiptap编辑，完成会话恢复、在线状态与个人撤销，最后验证存量转换与完整链路。

每个画布按epoch切换唯一写入通道。切换前保留原始快照并核对内容与引用，切换后验证旧客户端拒写。代码清理随调用方迁移和回归验证完成。

### 4.2 迁移和回退边界

转换在复制的持久快照上验证；正式切换锁定画布、排清或明确处理未决请求、写入新epoch并关闭旧协议写入口。唯一协议切换后不提供OT回退写入；部署故障应暂停写入，保全已接受状态与回执，再恢复兼容的Yjs服务。一旦新epoch已有接受，不得直接回退数据库快照丢弃新内容。恢复与演练数据分别记录，未做即未通过。

## 6. 第二阶段可复现检查入口

1. 在隔离 PostgreSQL 应用增量脚本；应用账号须具备协作表授权，禁止将schema重建命令指向既有业务库。
2. 安装 `canvas-collab` 的锁定依赖，执行 `pnpm test`；Go真实运行时集成测试依赖Node24和这些依赖，CI须安装后再执行后端测试。
3. 配置隔离测试DSN，执行 `go test -race ./tests/canvas -run TestYjs -count=1`，覆盖并发、回执、writerTerm、审阅失效、事务回滚、非法候选和运行时重载。完整画布回归使用 `./tests/canvas/...`，包含子目录otvectors。
4. 正式前端固定使用Yjs，删除协议构建开关，运行 `yjs-live-session.test.ts` 及全量类型/lint/测试/生产构建。存储断言区分控制器与整个应用；源码不调用存储不替代浏览器全应用缓存审计。
5. 隔离Docker浏览器夹具使用 `browserqa` 构建标签，登录辅助路由不能进入应用二进制。两个账号三个页面记录同段内容/格式、断线、拒绝预览和重开；页签数量与独立Cookie上下文数量分别记录，不混称三个浏览器身份。
6. 故障注入保留在隔离测试进程/外部验证目录，不在正式API增加跳过权限或强制拒绝开关。截图、数据库修订与逐项结果登记BACKLOG及工作区外证据，未执行分支不得整体勾选通过。

### 6.1 剩余优先能力的验证步骤

## 素材同步与算法复核专项

对应 SRC-SAVE-08、AC-COL-03/05/06、CASE-COL-03/04/10/11/13/14，采用隔离数据库、真实对象存储、正式 Go WS 与私有 Yjs runtime，Chrome 两账号三个页面；不以模拟 transport 的单测代替真实链路。

1. 上传横/竖/方图和视频，核对原始尺寸、节点比例、固定文件版本、其他页面和刷新后的尺寸。逐次替换素材，核对节点 ID、中心与引用身份。
2. 待全部资源完成解码后启动 DOM 身份、src、缺失与未解码采样；分别本页拖动、远端拖动、画布平移、单页面断线留页输入/他端继续编辑、恢复与重开。首屏加载不计入同文件抖动统计。
3. 延迟甲的替换原提交，让乙缩放后再释放；反序重复。核对引用/尺寸/placement、额外校正提交与真实恢复项，不用“全端一致”代替用户意图检查。明确重新应用或放弃，并读数据库权威投影。
4. 延迟旧 ACK，使后续已接受快照先到达；原接受历史可查、确实未胜出、历史缺失和身份不匹配分别验证。成功但未胜出的意图无须等待另一人的后续编辑才出现恢复入口。
5. 区间记录 localStorage/sessionStorage/IndexedDB API 使用，只记录键和调用类型、不保存凭据；结合正式路径源码确认无业务写入。该区间证据不得扩张为全部应用路径审计。
6. 按研究04固定 SHA 复核外部实现。先测全量快照、候选重建与页面校正成本，再评估增量广播和权威媒体几何约束；无统一负载对照前不宣称 Yjs 绝对最优，不以本次小修切换自研 OT。
