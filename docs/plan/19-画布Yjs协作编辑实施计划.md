# 画布Yjs协作编辑实施计划

> 唯一来源PRD：[09-画布协作编辑](../prd/09-画布协作编辑.md)。进度、阻塞与下一步见[BACKLOG](../../BACKLOG.md)。

## 1. 交付能力

Yjs共享画布、Tiptap协作正文、稳定引用、个人撤销、在线状态、持久确认、断线恢复和历史版本恢复。

## 3. 实施顺序

先固定共享模型和接受合同，再验证并发语义；接通协作服务、持久化与Docker运行后，接入节点及Tiptap编辑，完成会话恢复、在线状态与个人撤销，最后验证存量转换与完整链路。

每个画布按epoch切换唯一写入通道。切换前保留原始快照并核对内容与引用，切换后验证旧客户端拒写。代码清理随调用方迁移和回归验证完成。

## 4. 验证矩阵

| 验收      | 场景                                                         |
| --------- | ------------------------------------------------------------ |
| AC-COL-01 | 不同节点和同节点不同属性并发，兼容编辑共同保留               |
| AC-COL-02 | 同段正文、格式、引用、删除与连线、合并成环及拒绝恢复         |
| AC-COL-03 | 本人撤销与重做保留远端贡献，远端更新不进入个人撤销栈         |
| AC-COL-04 | 新输入与旧任务结果交错，来源绑定与任务幂等                   |
| AC-COL-05 | 三端连续并发、中文、emoji、IME、引用和选区映射               |
| AC-COL-06 | 原提交查证、丢回执、断线重放、撤权、服务重启及独立浏览器重开 |

补充验证presence过期、只读浏览、版本恢复、旧画布转换、拒绝更新依赖恢复、二进制状态与业务投影一致，以及Docker依赖与健康检查。
