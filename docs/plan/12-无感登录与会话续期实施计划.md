# 无感登录与会话续期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有环境中完成可信站点上的无感登录和自动续期，保持原密码登录、即时撤权、创作空间及业务幂等边界。

**Architecture:** 采用已确认的短期 JWT＋轮换 refresh token，Redis 负责有界协调及派生缓存，PostgreSQL 保留身份、会话、权限、轮换与审计的权威事实。扩展现有 Go 身份模块、Next 同站代理和根级 SessionProvider，不建设第二套身份服务或前端会话状态。

**Tech Stack:** 现有 Go/Gin/GORM/Wire、PostgreSQL、go-redis、Next App Router、React、Axios、生成式 OpenAPI 客户端及 Vitest。JWT 适配器已固定 `github.com/golang-jwt/jwt/v5 v5.3.1`，依据[官方发布](https://github.com/golang-jwt/jwt/releases/tag/v5.3.1)；任务03已固定依赖，任务10工程检查包含govulncheck。

**Spec:** [设计10](../design/10-无感登录与会话续期调研设计.md)；[需求第10节](../requirement/01-用户系统需求.md#10-无感登录与自动续期增补)；[用户系统PRD](../prd/01-用户系统.md)。用户于2026-10-18确认设计并要求拆计划；**用户已授权实施；任务01已通过模块验证与独立审查；任务02已完成兼容迁移和回滚验证；任务03已通过模块验证及修复复审；任务04已完成用例、修复复审与PG回滚验证；任务05已通过HTTP验证、Cookie冲突修复复审及PG回滚验证；任务06已通过组合验证及修复复审；任务07已通过前端及合同验证与独立审查；任务08已通过恢复协调验证及修复复审；任务09已通过旧会话升级、修复复审及PG回滚验证；任务10实施与限定运行验证、最终整包审查和修复复审完成；整体AC仍部分接受**。

## Global Constraints

- 用户已授权按01→10实施、验证与审查；只复用现有环境。任务02迁移先审阅，任务10只更新既有应用；未经另行要求不提交或推送。
- 未来实施前重读AGENTS/PROJECT，检查Git根目录、分支和工作区，并记录并行路径/哈希；根级SessionProvider等现有改造先核对再接入，不覆盖、回滚或广泛暂存并行任务。
- 实施仅复用已连接的 PostgreSQL、Redis 及已启动应用环境；不创建测试库、schema、副本、容器、集群、工作流 namespace 或额外环境，不重放 `schema.sql`。
- 登录必须核验既有密码并建立普通会话，不能要求重置密码；`must_change_password` 不参与拒绝、导航或业务授权。
- 保持登录绝对30天/空闲7天；普通登录绝对7天/空闲12小时；access最多15分钟；前台到期前60秒检查。refresh不得延长绝对期限、近期复验仍为5分钟。
- 轮换恢复窗10秒，Redis协调租期5秒；建议peer每分钟60次、sid每分钟12次刷新。所有时间由服务端取锁后采样，边界无隐含宽限；JWT最多30秒容差不延长会话。
- 当前 canonical origin 沿用 `http://127.0.0.1:3200`。别名只对GET/HEAD安全导航，写入不得跨源重放，后端不放宽Origin，BFF不改写浏览器Origin。
- PostgreSQL身份设置→账号→会话→refresh记录→业务范围是统一锁序；Redis网络操作在PG事务外。JWT签名或缓存命中不能替代当前授权。
- access/refresh使用HttpOnly Cookie；独立CSRF证明可读，稳定绑定sid。不得写入localStorage、sessionStorage、URL、日志、聊天、指标标签或仓库。
- 账号注销只做既有软删除及撤权；团队撤权不退出个人身份。refresh不代替敏感操作复验，不重放已发生成/发布/删除/上传完成请求。
- 所有Go测试放`backend/tests/<业务模块>/`。现有业务库默认只允许只读预检及审阅过的合成数据外层回滚测试；任务10的真实双连接竞争例外仅允许另行审阅的专属UUID合成样本、精确清理及不变性核验。禁用清库、全库过期扫描、DDL测试和故障注入到真实账号。
- 真实库的DDL已在任务02审阅及前置核验后执行单份兼容增量；任务10核验而不重放迁移。提交/推送与发布不由本计划自动授权。未来获授权提交时按任务文件白名单，保留并行工作。

## Review Focus

1. 全部Cookie被删除、缺CSRF或Cookie名称冲突：停止恢复循环，明确登录；不放宽CSRF。归属任务05/08，测试`TestSessionV2MissingCSRF`和`restoreWithoutCookiesStops`。
2. 控制权切换、换号与迟到刷新响应：旧身份不能回写、旧团队不能读、写入不能重放。归属任务04/08/09。
3. 身份验证通过但锁等待期间到期，或数据库投影仍使用固定12小时：必须拒绝越界，7天会话又不能提前失效。归属任务01/02/04。
4. PG已提交但缓存/网络失败，客户端与多标签同时恢复：只恢复同一后继，不创建多个代次或误撤销。归属任务03/04/08。
5. 旧协议关闭、签名密钥轮换与缺少部署权限：不回退到弱校验，不强制改密，不把未运行测试说成通过。归属任务03/09/10。

### Task 04：登录签发、刷新与即时撤销
