# 账号生命周期

> 唯一来源 PRD：[01-用户系统](../prd/01-用户系统.md)。技术合同沿其来源设计；实施进度、优先级、估算、承诺及阻塞只见 [BACKLOG](../../BACKLOG.md)。
> 产品交付来源：[用户系统PRD01](../prd/01-用户系统.md)。本计划深化其中账号生命周期范围，按FR-USER-14与原接受条件执行，不另建重复的生命周期PRD。

**Goal:** 本人确认后立即软删除账号，撤销访问，保留个人与团队资源。

**Architecture:** identity 在一个事务中检查本人会话、近期密码复验、邮箱证明、版本与最后管理员职责，然后设置账号删除标记并撤权；复用现有表和 SMTP，不新建清理服务。

**Spec:** [FR-USER-14](../requirement/02-用户系统需求.md#225-fr-user-14-本人注销与数据处理)、[数据库设计](../design/02-用户系统数据库设计.md#31-文首来源与范围)、[接口设计](../design/03-用户系统接口设计.md#31-文首来源与范围)。

### 1.2 顺序、关键依赖与风险

01证明/撤权 + 03/04管理员职责 → T-USER-14 → T-USER-15 → 06综合接受。

上述为依赖链与候选关键路径；缺少工时和资源日历，不能据此计算最长工期。外部依赖负责人和关键知识备份未在原记录明确的，纳入迭代前落实，不臆造人员。

| 风险与触发条件           | 对用户或交付的影响   | 应对及承接位置                                         |
| ------------------------ | -------------------- | ------------------------------------------------------ |
| 唯一管理员或证明版本变化 | 错误注销造成职责丢失 | 执行职责、版本、证明绑定及重复确认用例                 |
| 把注销理解成物理清理     | 破坏已接受保留范围   | 保留资源与作者引用，拒绝旧身份访问；不创建后台清理任务 |

## 3. 任务

### 3.1 T-USER-14：本人软删除事务与接口

**Files:** `identity/application/account_deletion.go`、`identity/adapter/postgres/account_deletion.go`、`identity/adapter/http/account_deletion.go`、`tests/identity/account_deletion_integration_test.go`。

**Interfaces:** `AccountDeletion.Preview(ctx, actor)`、`Start(ctx, actor, source)`、`Confirm(ctx, actor, expectedRevision, operationID, code)`；预览返回版本、团队 ID、阻碍职责及 `soft-delete-v1` 策略。

- RED：`TestDeletionDutiesAndRevoke`、`TestDeletionProofBinding` 验证最后管理员保护、版本冲突、本人/邮箱/会话版本绑定、错误次数与过期、重放拒绝。
- GREEN：复用既有邮箱预算和加密邮件队列，锁 settings → user → session → team/member，完成删除标记、全会话撤销、挑战失效和成员移除，记录安全事件。
- 运行 `go test ./tests/identity -run 'TestDeletion' -count=1 -v`；仅使用现有数据库回滚测试。

调度及原状态字段见 [BACKLOG](../../BACKLOG.md#454-06-账号生命周期t-user-14本人软删除事务与接口)。

### 3.2 T-USER-15：前端确认与保留资源验证

**Files:** 个人中心注销交互、受保护资源访问入口及相应测试。

- 展示“注销后无法登录，资料与作品保留”；先列管理职责阻碍，密码复验后发送验证码，明确确认后退出并清除本地私人缓存。
- `TestDeletionPreservesResources` 验证资源/作者引用仍在，旧会话、恢复证明、成员权限、个人分享与后续任务不能继续访问；团队有效成员仍能访问团队资源。
- 浏览器检查失败/重试/成功退出、键盘操作及窄屏布局；注销失败不能显示成功。

不创建 `account_deletion`、`deletion_item` 或后台清理任务；不会把单元测试通过记录为运行环境切换完成。

调度及原状态字段见 [BACKLOG](../../BACKLOG.md#455-06-账号生命周期t-user-15前端确认与保留资源验证)。
