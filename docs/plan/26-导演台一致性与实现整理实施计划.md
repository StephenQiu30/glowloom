## 执行顺序与退出条件

| 任务              | 输入 / 操作                                           | 可检查产物与退出条件                              |
| ----------------- | ----------------------------------------------------- | ------------------------------------------------- |
| T-DIR-01 来源基线 | 独立检查即梦；先不看项目功能实现                      | DIR-001～035、证据 manifest、已观察/静态/未知分开 |
| T-DIR-02 实现审查 | 固定 参考实现 MIT版本；随后对照当前代码                 | 来源映射、带hash差异矩阵；并行文件所有权清楚      |
| T-DIR-03 设计     | 按静态/动态、资产/对象/属性、动作/运镜/输出和恢复改稿 | 原生层、组件/token、字体与截图验证；节点链接留档  |
| T-DIR-04 数据合同 | 场景V1→V2，引用/复制/删除/权限、生成API与Yjs适配      | Red→Green；旧稿回读、两工作区及协作冲突测试       |
| T-DIR-05 场景编辑 | 整理加载/资源/机位/角色姿势、路径与交互算法           | 单元边界和真实视口行为，临时交互可取消/撤销       |
| T-DIR-06 动态预演 | 动作/关键帧/运镜/分镜与焦点                           | 帧采样/非重叠/轨道独立，真实播放不污染保存        |
| T-DIR-07 输出     | 拍摄、镜头素材、视频导出、资产与回写                  | 实际产物解码、尺寸/时长/帧率、故障恢复与去重      |
| T-DIR-08 接受     | Figma与浏览器全量核对，源码/许可/工作区检查           | 每个DIR标明实现与实测，残余未决不能改为通过       |

## 测试场景

| ID / 目标            | 前置与角色                        | 步骤及可观察结果                                                                      | 例外                                                 |
| -------------------- | --------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| CASE-DIR-01 单帧构图 | 可写项目、合法模型                | 放置→摆姿→选机位→刷新；位置/姿势/镜头保持                                             | 取消不落对象、锁定拒绝移动、坏模型重试               |
| CASE-DIR-02 工作区   | 静态与含时间线动态                | 不同步保持双方；覆盖需确认；冻结当前帧无动画片段                                      | 动态引用缺失角色时拒绝覆盖；取消无变化               |
| CASE-DIR-03 镜头     | 多机位与注视点                    | 改位置/目标/FOV/倾斜/画幅，预览与拍摄相符                                             | 删除绑定对象冻结或清引用、不跳镜头                   |
| CASE-DIR-04 动作     | 兼容骨架与动作                    | 播放头添加、移动/裁切/变速、静态姿势片段                                              | 重叠回退、负时间拒绝、骨架不匹配说明                 |
| CASE-DIR-05 运镜     | 角色/机位轨道                     | 绘路径→时间→预览→确认；分镜按机位切换                                                 | 取消不写轨道、非法范围拒绝、帧数不足反馈             |
| CASE-DIR-06 图片     | 有画面机位                        | 拍摄→入资产→镜头素材→添加画布→刷新读取                                                | 失败保留可重试、无辅助线、只读禁止回写               |
| CASE-DIR-07 视频     | 非空动态场景                      | 1280/1920、不同fps与画幅导出；检查真实文件首帧/时长/codec                             | 取消/中断清理、错误不假成功、旧项目结果拒绝          |
| CASE-DIR-08 可靠性   | 双会话、离线、IME、加载中         | 并发修改提示、草稿恢复、输入不移动场景、卸载取消                                      | 失权/节点删除/epoch变化、WebGL丢失与恢复             |
| CASE-DIR-09 历史迁移 | V1静态/动态、有无动画、被隐藏轨道 | 迁入对应工作区；静态旧稿中的动画保留于动态；ID/资源/轨道/输出引用不丢失，保存刷新一致 | 首帧非零、未知版本、非法字段、不完整资源拒绝静默丢弃 |

各场景分别记录真实页面、单元契约与未覆盖边界，见[实现验收记录](../research/evidence/2026-10-29-director-implementation/validation.md)。即梦调研中的临时角色添加/撤销不等于 Glowloom 接受。
