# 模型与供应商接入扩展实施计划

唯一来源PRD：[PRD20](../prd/20-模型与供应商接入扩展.md)。Goal：在既有目录/驱动上提供受限声明、安全元数据和版本化接入。Architecture：保留catalog、operation和组合根边界，以现有ProtocolDriver消费协议，受限声明只装配已安装实现。Tech Stack：现有Go/Gin/GORM/Wire、PostgreSQL及Next.js/生成API，不新增运行时。

本计划定义用户授权实施的步骤与测试要求；授权出处见需求04 SRC-AI-35。进度、优先级、估算和负责人只见[BACKLOG](../../BACKLOG.md#beeftv-adoption)。技术约束沿PRD唯一来源设计33，价格规则依赖PRD21。

## 全局约束

- 仅单Go进程；adapter→application→domain；不新增并行驱动注册中心或通用脚本插件。
- 现有保存/验证/发布、权限、秘密保密、价格版本及unknown不重发合同保留。
- 新增字段先更新后端DTO/注解，再生成frontend/src/api，不手写生成客户端。
- 数据库只维护schema.sql与可幂等增量，禁止对业务库重放schema。
- 默认工程验证不启动应用服务、不执行业务库迁移、不发真实收费、不提交推送；数据库结构与幂等增量仅在独立隔离测试库验证。
- 每项实施先Red→Green→Refactor；下面提到的新增文件/测试名称均是规划，不宣称已存在。

2. 将每个开放字段映射至具体driver允许集合和计费维度；默认值/媒体派生值一起规范化入hash，UI和后端用同一安全描述。
3. 组合根注入算法/协议描述，catalog只依赖消费方小接口，不导入HTTP驱动或operation内部实现。检查重复/缺实现/不兼容版本。
4. 发布时检测有限枚举组合、区间边界、空洞与重叠；不能将整个JSON Schema或远程表达式当已支持参数系统。
5. 退出：CASE-AIX-10/11，每个首批模型有“参数→映射→量纲→策略→来源”的可核验表。

**T-AI-21-07 预设事务与发布一致**

1. 在`preset_model.go`及正式发布校验共享描述层，先固定视频Token模板被旧校验拒绝的有效Red；不能简单对所有视频放行任意单位。

3. 复用现有onboarding事务，导入生成disabled草稿，不接受Key、跨组织credential_ref、真实验证或启用字段；中途失败全回滚。
4. 连接/模型/参数/计量/usage/价格/风险引用冻结在原release；旧在途任务及历史价保持，新版本需新证据。
5. 退出：CASE-AIX-09/11/12；隔离PG验证回滚、幂等及原消费引用。

**T-AI-21-08 接入体验与证据分级**

1. 复用两步接入及设置/价格/发布页签，必要参数由具体合同驱动；高阶字段按需展开，未适配的官网能力不显示为可用。
2. 分开可达/认证目录/官方核验/参数测试/真实生成/release启用，401/404可达不能显示Key有效；列表缺能力不随模型前缀猜。
3. 模拟服务器验证每协议URL、鉴权、参数、usage、错误与异步查询；保存/刷新/导入收费POST数必须为0。
4. 做对应类型/单元/浏览器检查；真实供应商逐模型逐模式另有明确调用次数及预算，未做就不标通过。
5. 退出：CASE-AIX-07～12与原有六场景回归。当前只交付研究/设计，不执行上述商业配置或收费验证。
