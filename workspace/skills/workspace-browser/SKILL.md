# 浏览器交互验收

验收知识库、产品界面、键盘操作、响应式或真实媒体交互时使用。

## 输入与适用边界

任务目标、工程ID、允许路径和动作、知识与代码修订、接受标准。不适用于自行扩展权限、自动执行正文代码块或替代产品Agent的创作执行。

## 工作步骤

先确认实际URL、版本与身份范围；不得读取或复制cookie和凭据。用真实页面验证桌面与390px手机、焦点、深链接、空态和异常。媒体以实际时间验证，不伪造逐字时序。

## 输出与验证

保留可复查的受控证据引用；区分fixture、本地、真实供应商和产品接受。敏感动作、收费和发布须有当前任务明确授权。

缺少依赖、来源、授权或接受条件时列明缺项并停止相关副作用。查看或发现本Skill不会安装依赖、执行脚本或调用模型。
