# 项目定位与上下文

在新会话进入Glowloom、定位需求来源、业务工程或验证入口时使用。

## 输入与适用边界

任务目标、工程ID、允许路径和动作、知识与代码修订、接受标准。不适用于自行扩展权限、自动执行正文代码块或替代产品Agent的创作执行。

## 工作步骤

读取根AGENTS、PROJECT、BACKLOG，再按目标沿原始需求→设计→PRD→Plan定位。通过projects.json选择工程ID，个人路径只在projects.local.json配置。

## 输出与验证

输出目标、范围、唯一来源、接受条件、工程入口、知识修订和待确认项。按预算提取原文，不把整库或聊天记录当成已确认规则。

缺少依赖、来源、授权或接受条件时列明缺项并停止相关副作用。查看或发现本Skill不会安装依赖、执行脚本或调用模型。
