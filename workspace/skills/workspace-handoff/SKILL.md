# 知识回写与任务交接

结束阶段、断连恢复、新会话接手、知识回写或审阅提案时使用。

## 输入与适用边界

任务目标、工程ID、允许路径和动作、知识与代码修订、接受标准。不适用于自行扩展权限、自动执行正文代码块或替代产品Agent的创作执行。

## 工作步骤

固定文档、代码、Skill和流程修订，读取原run_id、attempt与外部句柄。未知回执先查询，不自动重派有副作用动作。内容或授权变化时复核受影响证据。

## 输出与验证

长期结论回到所属知识文件；进度只回BACKLOG。草稿、落地、提交、合并、部署与接受分开；原始日志和截图保存在受控产物中，不写进知识正文。

缺少依赖、来源、授权或接受条件时列明缺项并停止相关副作用。查看或发现本Skill不会安装依赖、执行脚本或调用模型。
