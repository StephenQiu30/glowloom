# 导演台构图与动态预演

唯一来源设计：[30-导演台一致性与实现整理设计](../design/30-导演台一致性与实现整理设计.md)。原始需求追溯通过该设计链接；执行见[Plan26](../plan/26-导演台一致性与实现整理实施计划.md)。

## 产品结果

创作者在画布内完成角色/场景/机位构图及动态动作/运镜预演，产出可继续使用的真实图片和视频，并能保存、重新进入和处理协作冲突。

## 范围与命名

完整范围对应 DIR-001～035；统一使用导演台、静态预演、动态预演、角色、物体、背景、机位、注视点、姿势、动作、运镜、时间轴、分镜编排、拍摄、镜头素材、导出视频、添加到画布。源代码存在但当前 UI 不开放的 SPZ/桌面分支不计确认范围；AI 动作依赖真实服务。

## 用户故事与接受

| 故事               | 接受条件                                                                                  | 场景              |
| ------------------ | ----------------------------------------------------------------------------------------- | ----------------- |
| US-DIR-01 构图     | 角色/物体/背景放置与取消、对象/姿势属性、机位与注视点、显示/锁定、取景一致                | CASE-DIR-01/03    |
| US-DIR-02 预演     | 两工作区独立；同步/冻结规则可确认与取消；角色片段无重叠、关键帧与机位轨迹独立、分镜可编排 | CASE-DIR-02/04/05 |
| US-DIR-03 产出     | 截图与视频确有文件；比例/帧率/时长正确、无编辑辅助；入资产与添加画布分离，失败可重试      | CASE-DIR-06/07    |
| US-DIR-04 可靠编辑 | 历史场景无损迁移、草稿恢复、保存回执、冲突和失权明确；不串项目；撤销与焦点正确；卸载清理  | CASE-DIR-08/09    |

每条接受覆盖正常、边界、例外、权限、跨端回读与可访问性。完整实现不能用按钮/空状态/静态演示代替。参考实现 只提供整理依据，最终遵循项目的组件、资产、保存与协作合同。

## 非功能接受

按需加载大型 3D/输出模块；编辑瞬时态不污染业务保存；真实 GPU/模型加载测试覆盖错误与卸载；不新增无关框架。保留固定来源及许可证。Figma 使用原生可编辑层并核对字体、裁切、层级、图标与状态。

## 未决依赖

动作资源的可再分发来源、文字生成动作服务、确定性视频输出方案及完整真实素材验收尚需证据；未解决时不得声称与即梦全量一致。当前实施状态见 BACKLOG。
