# AI 工具目录与交互

唯一来源为 [设计39](../design/39-AI工具目录与交互一致性设计.md)。

## 范围

- 目录与命名覆盖 AT-01～21，四组卡片顺序及五个分类见来源设计和词表。
- 入口分流覆盖 16 个素材导入入口、3 个创作模式、1 个导演台模板和 1 个插件安装页。
- 各工具以实际可用的参数、权限、报价和结果状态完成体验。对于仍待核实的即梦行为，收录真实观察并更新设计后再确定一致性。

## 验收

| 验收 | 操作与可检查结果 |
| --- | --- |
| AC-AT-01 | 桌面及手机可从导航进入，使用键盘切换分类，看到稳定顺序、21 项及同一套名称。 |
| AC-AT-02～03 | 本地、拖放、资产库入口按媒体类型验证。零选择禁用确认，取消后可继续，权限或读取失败有明确状态。 |
| AC-AT-04 | 点击图片生成、视频生成、数字人，直接打开对应模式。必填项未完成时不能提交。 |
| AC-AT-05～06 | 位置、时间、画面边界以及结果类型在界面中有明确区别。测试素材可从结果回到创作或资产，保留源引用。 |
| AC-AT-07 | 3D导演台进入模板画布；插件页展示真实支持的宿主及版本，能力不可用时有对应状态。 |
| AC-AT-08 | 输入失效、报价过期、任务未知、失败和成功分别可见。状态恢复保持同一任务和输入，重试按受理状态处理。 |
