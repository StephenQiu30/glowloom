# AI 短剧制作多 Agent 编排

唯一来源设计：[设计49：AI短剧制作三层Agent与六阶段Workflow设计](../design/49-AI短剧制作三层Agent与六阶段Workflow设计.md)。原始需求经来源设计追溯至 [需求34 SRC-SDMA-01](../requirement/34-AI短剧制作多Agent编排需求.md#src-sdma-01)。

## 1. 目标与边界

在已落地的 Mastra + Go MCP 底座上，交付面向 **9:16 竖屏 AI 漫剧/动画短剧** 的三层 5 角色多 Agent 编排、六阶段 HITL 持久化 Workflow、无限画布副驾驶能力、6 套短剧声明式 Skill、短剧专项离线 Scorers 与 Go 内部 MCP 5 组短剧工具契约。

## 2. 验收标准

| ID         | 前置与动作                                                 | 可观察接受结果                                                                                             | 来源          |
| ---------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------- |
