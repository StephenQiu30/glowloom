# PRD：模型与供应商接入扩展

本轮公开预设持久化及音频补齐见[SRC-AI-48](#src-ai-48)，为只交付文档的评审范围，不沿用旧实施授权启动本轮编码。

唯一来源设计：[设计33](../design/33-多设计模式驱动的模型与供应商接入扩展体系设计.md)。状态：评审稿。需求追踪：SRC-AI-35、FR-AI-40及既有SRC-AI-27。执行：[Plan29](../plan/29-模型与供应商接入扩展实施计划.md)；进度、优先级和责任分配只见[BACKLOG](https://github.com/StephenQiu30/glowloom/blob/8549d9d56fab089ac8ca294462899825bcd420a6/BACKLOG.md#beeftv-adoption)。

## 1. 摘要

为模型管理员统一供应商声明、模型候选和安全元数据，让已有协议的新配置可维护、新协议的开发边界可见。创作者继续使用已有工作台，不接触平台凭据。

用户已授权按方案实施（见需求04 SRC-AI-35）；保存仍不自动发起验证，真实供应商和产品接受分别留证。

## 2. 参与者

使用者为平台管理员、个人/团队创作者和模型维护者；产品确认人为用户，具体实施责任人未指定。平台管理与项目创作权限分别校验。

## 3. 背景

现有驱动和元数据注册可复用，但能力、凭据字段和展示存在多个维护入口。本PRD承接设计33的元数据整合及受限声明，不把BeefTV桌面账号和远端钱包移植为本平台能力。

## 4. 目标与衡量

- 一个已有协议的最小声明可完成校验、保存和安全展示，见CASE-AIX-01。
- 不支持协议、非法字段、越权和秘密回显全部被拒绝，见CASE-AIX-02/04。
- 目录更新不改变旧任务，unknown不产生第二个生成POST，见CASE-AIX-03/06。

这些是验收建议，未设未经测量的耗时降低或供应商数量目标。

## 5. 用户与使用场景

| 人群               | 工作与限制                                         |
| ------------------ | -------------------------------------------------- |
| 维护供应商的管理员 | 减少查ID、重复填字段及误用凭据；保存不自动收费验证 |
| 使用模型的创作者   | 看到安全、准确的模型能力和状态，不承担渠道配置工作 |

## 6. 用户价值

| 六要素       | 管理员                   | 创作者                   |
| ------------ | ------------------------ | ------------------------ |
| Who          | 平台模型管理员           | 个人与团队创作者         |
| Why          | 准确接入和维护模型       | 在工作台选择适用能力     |
| What before  | 分散查资料与维护配置     | 通过名字猜测能否使用     |
| How          | 受限声明、版本和分项检查 | 安全目录与真实验证状态   |
| What after   | 保存、验证、发布各有依据 | 不将接入成功误认为已验证 |
| Alternatives | 手工逐供应商配置         | 外部供应商界面与手工归档 |

价值主张：管理员从同一声明管理可验证配置，创作者使用准确的能力目录，模型执行继续受项目授权与计费规则保护。

## 7. 产品方案与验收

### 7.1 范围

纳入现有预设管理的受限JSON声明、安全元数据读取、版本对应和协议兼容回归。首批迁移集合经设计评审及兼容证据确定，不自动增加原生协议、个人BYOK、插件市场、任意脚本或动态执行清单。

页面保留既有极简模式、共享顶栏和组件；高级声明按需打开，默认仍为选择服务、填必要凭据、选择模型、保存。

### 7.2 用户故事

**US-AIX-01 维护受限声明**：作为平台管理员，希望校验并保存供应商声明，以减少字段不一致。来源：FR-AI-40、设计33 §7.2～7.4。讨论：协议须已安装，保存不触发生成。确认条件：有效声明原子保存；非法字段/重复ID拒绝并保留输入；非管理员拒绝。追踪：CASE-AIX-01/02/04。

**US-AIX-02 保留历史快照**：作为管理员，希望升级候选不更改旧连接和在途任务，以安全维护目录。来源：FR-AI-40、SRC-AI-27、设计33 §7.2。讨论：保存与验证独立，旧通过不授予新版本。确认条件：旧任务保持原配置；新版本显示未验证；轮换Key不泄露秘密。追踪：CASE-AIX-03/05。

**US-AIX-03 查看准确能力**：作为创作者，希望看到实际可用模型和验证范围，以选择合适生成方式。来源：FR-AI-40、设计33 §7.3。讨论：品牌和模型名字不是能力证明。确认条件：安全目录不含平台秘密；未验证不标通过；未知图标有文字回退，键盘/窄屏可用。追踪：CASE-AIX-04/05。

**US-AIX-04 查证未知调用**：作为创作者，希望断线后继续查原任务，以避免重复付费。来源：FR-AI-39/40、设计33 §7.6。讨论：收费POST不自动重发，不能靠换渠道恢复。确认条件：迟到响应、重开页面与凭据改版都不创建第二次生成；错误信息不含秘密。追踪：CASE-AIX-06。

### 7.3 测试场景

以下为验收合同；实际工程证据及未覆盖项由BACKLOG链接，按Plan29留证，不以模拟证明供应商可用。

| ID/目标                | 前置条件与角色         | 步骤→可观察结果                                                 | 例外                                 |
| ---------------------- | ---------------------- | --------------------------------------------------------------- | ------------------------------------ |
| CASE-AIX-01 声明维护   | 管理员、已安装协议     | 输入最小合法声明→保存、读回安全元数据；创建新版本               | 保存失败无部分模型                   |
| CASE-AIX-02 声明约束   | 管理员                 | 逐项提交未知协议/版本/字段、重复ID、错误源→明确拒绝，无网络生成 | 输入草稿保留                         |
| CASE-AIX-03 快照       | 已有连接及在途任务     | 更新候选/声明→旧任务ID/配置/价格引用不变，新模型未验证          | 停用不删除回执                       |
| CASE-AIX-04 权限与秘密 | 管理员/创作者/其他组织 | 读取管理/创作目录→仅返回各自有权安全字段                        | 直接请求、错误和日志均无Key/Header值 |
| CASE-AIX-05 保存与交互 | 管理员，未验证连接     | 保存→无收费调用；详情选择模型后独立验证                         | 手机/键盘/未知Logo回退，不假通过     |
| CASE-AIX-06 未知提交   | 已确认任务、故障代理   | POST后断流、刷新/轮换Key→仅查原任务，上游生成计数仍为1          | 不以402/429或超时授权重发            |

### 7.4 假设与未决

首批迁移供应商、新原生协议支持范围和声明字段最终合同需评审；不是现有目录里的每个型号都能真实使用。外部商业授权、实际账号与供应商验收另行确认。

### 7.5 SRC-AI-40 官方模型预设与算法接缝

唯一来源仍为设计33 §7.8～7.13，FR-AI-41～46。逐模型官方事实见其引用研究，计价算法与金额由PRD21依赖承接；不把本PRD变成第二个价表。

**US-AIX-05 选择准确预设**：作为管理员，希望按供应商、套餐和地区快速选择官方模型，以减少查ID/误配Key。讨论：12个首批ID逐项核验，其他未核验候选仍未知；引用CC Switch组织方式，不复制桌面秘密或自动切换。确认条件：地区/套餐选择改变必要凭据和模型集合，未审价可存disabled草稿但不可派发。追踪CASE-AIX-07～09。

**US-AIX-06 管理模型参数与计费合同**：作为管理员，希望一个模型开放的参数都能发出并正确计费，以避免用户选择后才失败。讨论：官方能力可采用明确保守子集，不能静默丢参数。确认条件：模型/driver/计量/价格交集验证、变更成新版本、在途任务不变。追踪CASE-AIX-10～12。

| ID                   | 前置与步骤→可观察结果                                                                         | 例外/证据                                    |
| -------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------- |
| CASE-AIX-07 官方来源 | 管理员导入缺来源/审核时间、退役或不唯一别名候选→标未核验/拒绝发布，不生成假日期或active       | 官方目录、账号可见、真实试运行分别显示       |
| CASE-AIX-08 地区套餐 | 方舟按量/订阅、BytePlus AP/EU及不同Key选择→不可互用凭据/模型，路径版本保持                    | 无EU当前证据不默认开放，缺协议显示待适配     |
| CASE-AIX-09 原子预设 | 有效受限预设→生成disabled模型与草稿；视频Token模板与正式发布使用相同单位能力；非法绑定→全回滚 | 无秘密/验证/启用状态导入，保存产生0收费POST  |
| CASE-AIX-10 参数交集 | Fast选择1080p、2.0选择16秒、未适配图层/编辑/工具→服务端拒绝；Pro/Flash合法保守子集可保存      | 前端禁用不足以接受；直接API同样校验          |
| CASE-AIX-11 联合覆盖 | 一个模式/价格敏感参数缺算法、缺价行、区间空洞/重叠→不创建可启用release                        | 普通图片、拆层、参考视频、Standard/Batch分开 |
| CASE-AIX-12 版本更新 | 刷新目录/改参数/轮换Key/算法升级→仅产生候选/新版本；原任务连接、输入哈希、价格和算法引用保持  | 旧通过不自动迁到新release；未知原消费不重发  |

## 8. 交付与接受

正常/边界/越权/unknown场景全部有对应证据后，才接受相应能力。工程、浏览器与真实供应商接受分别判断；无固定排期承诺。回退停新声明入口但保持历史任务查询。

T-AI-21及其子任务由Plan29定义；T-AI-24仍由PRD19/Plan28承接。本PRD不替代AI接入基础PRD03或计费PRD21。

### SRC-AI-37 接入体验验收补充

唯一来源仍为设计33。现行接入主流程的验收由[PRD03 SRC-AI-46](03-AI平台接入与预设管理.md#src-ai-46)持有。设置/价格/发布页签不丢输入，验证回读后激活条件更新。Select在320px不遮挡文字、不挤箭头，菜单受视口约束，键盘与触摸可用。设计与协议合同分别验证，不用页面简化删除真实能力。

## SRC-AI-48 可重建预设与音频接入

唯一来源仍为[设计33 §7.15～7.16](../design/33-多设计模式驱动的模型与供应商接入扩展体系设计.md#src-ai-48)，追踪FR-AI-57～59、61、63/64及AC-AI-38～40/43。管理员应从同一公开预设减少重复填ID和参数；创作者应能选择音频并获得可归档的声音产物；维护者应能从仓库在新环境重建同样的预设。

**US-AIX-07 重建与升级预设**：作为维护者，希望schema→data能恢复完整公开目录，以保证新环境和已有环境可追溯。讨论：预设无账号权限，公开价参考不等于已审核销售价。确认条件：完整原候选逐项对账、幂等导入、保留管理员配置和旧任务；见CASE-AIX-13/14。

**US-AIX-08 使用火山音频**：作为创作者，希望按文字/参考生成配音或音效并看到本次费用，以复用现有资产和时间线。讨论：优先补齐TTS/Seed-Audio，保留音乐已有范围；ASR/实时语音/训练另列后续建议。确认条件：精确协议、模式、媒体、计量及发布闭环；见CASE-AIX-15～17，积分接受依赖PRD21。

| 场景                       | 前置与角色                                | 步骤与可观察结果                                                                      | 例外                                                              |
| -------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| CASE-AIX-13 空库及幂等     | 维护者，空隔离PostgreSQL、正式schema/data | 依次导入→10个既有供应商及全部候选/公开参考恢复；重跑data→不重复；原目录逐项比较无丢项 | 同键同版本不同摘要报冲突，不能无声跳过；无Key、发布、真实证据种子 |
| CASE-AIX-14 升级保留       | 隔离快照含管理员模板/连接/冻结任务        | 追加新种子版本→新候选可读，原配置/已审核价/账本/任务引用不变                          | 不能重放schema覆盖业务库，不得依赖Go另一份候选清单补缺            |
| CASE-AIX-15 TTS闭环        | 管理员已核验商品/价格，授权测试环境       | 保存专用Key→无生成；显式报价确认→单次SSE请求；终态及字符量→音频归档/结算              | 未核验音色、缺终态、缺usage、断流均不能冒充成功或零消费           |
| CASE-AIX-16 Seed-Audio闭环 | 已发布该模式并有授权预算                  | 纯描述/允许参考→请求、归档音频及启用的字幕；返回原始和播放时长分别保存                | 图片音频混用、参考越限、模型/鉴权不符拒绝；变速不改变计费身份     |
| CASE-AIX-17 四模态覆盖     | 全部迁移候选及开放参数矩阵                | 逐项对照驱动/参数/计量/价格/release→可用项全部覆盖，未完成项有明确原因                | 模拟通过不代表真实供应商接受；不靠删除困难候选宣布完成            |

本轮不交付SQL、驱动实现或真实调用证据。MVP服务边界按设计33复用现有Go、Agent、Canvas和worker，未引入LiteLLM网关。价格及上界未核验的模式不可消费；实施顺序见[Plan29](../plan/29-模型与供应商接入扩展实施计划.md#src-ai-48)，剩余接受只在[BACKLOG](../../../BACKLOG.md#model-presets-audio-20261109)维护。
