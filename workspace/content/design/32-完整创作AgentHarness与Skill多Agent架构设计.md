# 完整创作 Agent、Skill 与多 Agent 设计

来源为[需求19](../requirement/19-完整创作Agent与Skill多Agent需求.md)及[需求25](../requirement/25-多模态创作与Agent编排需求.md)。产品验收见[PRD19](../prd/19-完整创作Agent与Skill多Agent.md)。服务运行架构由[设计48](48-Agent服务Mastra架构与技术选型设计.md)维护，短剧角色与生产编排见[设计49](49-AI短剧制作三层Agent与六阶段Workflow设计.md)。

## 1. 摘要

创作 Agent 将创作目标、项目资料和用户选区组织成可编辑的步骤，调用受权业务工具与专业子 Agent，产出可定位、可采用和可继续修改的作品。用户可查看计划、等待点、费用承诺与结果。

## 2. 参与者

创作者确认方向、修改作品和采用结果。主 Agent 负责计划、分派和验收。专业 Agent 在分配的上下文中完成编剧、设定、分镜、镜头、声音、剪辑或审查。Go 业务服务负责权限、费用、工具和正式产物。

## 3. 背景

参考项目中的主任务组织、阶段素材和长任务恢复见[短剧平台源码对照](../research/45-2026-11-12-短剧制作平台源码与发行包对照调研.md)。外部 Skill 包与工作流接入的证据见[短剧开源 Skill 套件调研](../research/74-2026-11-25-短剧开源Skill套件完整接入调研.md)。

## 4. 目标

对话、选区和项目资料在同一轮组合使用。正式生成和采用有明确权限与回执。可用同一身份查回原运行、已确认提案、任务状态和实际产物。

## 5. 使用场景

- 从小说或剧本创建项目计划、角色、场次和分镜，选择并继续修改感兴趣的镜头。
- 与 Agent 共同修改画布。并行生成准备工作可局部重试，人工挑选、审批或媒体任务等待能从同一运行恢复。
- 搜索已发布的项目资料，区分当前和历史修订，打开可核对的原文、画布或时间码。
- 安装和授权指定 Skill 版本，查看本次用到的工具、附件与结果。

## 6. 价值

减少重复录入与手动传递素材，让多阶段创作保留已采用的结果、生产依据与费用来源。

## 7. 方案

<a id="70-整体方案与完整调用路径"></a>

### 7.1 运行与业务权威

主 Agent 接收带项目、画布或镜头身份的目标，先读当前业务修订和可用工具。计划包含依赖、所需输入、输出义务和人工等待点。子 Agent 权限取父任务授权与自身角色工具的交集。分支输出带来源、修订和实际回执，主 Agent 核验后才推进依赖步骤。用户改动造成真实冲突时，重新读取并重做受影响步骤。

模型、工具、Skill 与业务任务保留可关联的身份。Go 管理项目访问、审批、预算、媒体任务和实际扣费；Agent 保存编排、会话和已提交事件。任务受理、生成成功和作品采纳是不同的业务状态。用户看到的是业务状态和可定位产物。

### 7.2 Skill、MCP 与实际产物

Skill 的发现、启停和正文读取按作用域与版本执行，运行固定正文、依赖附件与工具资格。用户安装、更新或回退后，新运行解析项目当前可用版本。脚本和外部集成通过已授权的工具执行，执行部署边界见[设计48](48-Agent服务Mastra架构与技术选型设计.md)。

外部 MCP 工具需配置、发现并显式授权。区分 tools、resources、prompts。外部任务查询保存提供方任务 ID，金额或写入副作用未知时先查证。工作流、Skill 指令、业务工具及实际产物分别保留各自的身份与版本。

<a id="715-稳定服务再评估与详细执行合同"></a>
<a id="717-源码复核后的执行闭环设计"></a>

### 7.3 等待、恢复与交付

已受理运行可因人审、预算、业务任务或服务故障暂停。批准绑定原候选、版本和预算；重放不重复执行已提交操作。用户停止或撤权后禁止发起新的副作用。等待点恢复前先读取原回执、当前权限和冲突状态。重连通过游标读取已提交事件。完成条件核对实际资产、版本、绑定及可继续编辑的工程。

<a id="creative-context-design"></a>
<a id="harness-module-contracts"></a>

### 7.4 创作上下文

当轮目标、画布或镜头选区、引用、最近上下文和实际回执共同决定输入。显式选择优先，长对话摘要保留对象 ID、有效约束、未决事项及来源。项目事实以带权限的 Go 业务读取为准，私有草稿和已发布项目事实分别维护。

<a id="project-rag-runtime"></a>

### 7.5 项目证据检索

显式稳定 ID 直读，名称和结构字段可辅助定位，描述型查询按授权范围检索。证据返回来源、修订、位置与摘录，打开原文时再次检查当前权限和版本。提交新版本后的索引可异步更新，旧索引不得覆盖当前事实。删除或撤权先停止读取，再清理衍生数据。词法、语义及重排策略以有标注的实际案例评估。

<a id="project-memory-runtime"></a>

### 7.6 项目约定

角色和场景连续性、风格、时长及已确认的约束可保存为项目约定。Agent 可提出候选，具有编辑权限的创作者确认共享内容和范围。更正基于预期修订创建新版本，撤回停止后续使用，历史仍可审计。镜头显式例外优先于项目默认。正式资产选择、费用和采用从业务对象读取。

<a id="7159-可观察性运行手册及放行条件"></a>

### 7.7 运行关联与评测

可定位请求、工具尝试、等待、恢复、产物及费用，日志保留必要标识和状态。按项目和来源分割评测集，覆盖同名、权限变化、并发改稿、长上下文、未知回执和付费采用。离线、隔离真实数据库和真实供应商验收分别记录。
