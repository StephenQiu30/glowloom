# Figma 设计落地实施计划

唯一来源为[PRD11](../prd/11-统一工作台与创作入口.md)。现行设计见[设计09](../design/09-统一顶栏与阶段入口设计.md)与[全局设计规范](../../../DESIGN.md)。实施进度见 [BACKLOG](../../../BACKLOG.md)。

## 实施步骤

1. 确认 Figma 中正式页面、使用的共享组件和待对齐的状态。以设计09为依据同步入口、顶栏、创作壳层和账户状态。
2. 优先复用现有 React 组件与令牌。按正式路由核对主题、焦点、关闭目标、桌面和窄屏滚动。规则改变先更新所属设计。
3. 覆盖游客、已登录、权限受限、空、加载与失败。替身与真实身份分别验收。回归项目选择、素材收藏和账号菜单时，分别验证导航和正式写入回执。
4. 涉及素材管理时按 AC-WB-18 验证目录上传落位、归档失败重试、正文搜索及清除、预览关闭后恢复焦点。涉及账号菜单时按 AC-WB-21 验证管理员入口、普通账号权限、移动返回和焦点及共用认证弹窗。
5. 使用正式构建验证路由和交互。发布与回退按项目部署规则执行，版本与验收证据记录到 BACKLOG。

## 共享顶栏验证

验证公共顶栏跨页面顺序和响应式行为。作品标题、返回、编辑器工具、头像和会话状态按页面所有者的合同检查。对照 Figma 的组件状态，并在运行页面核对键盘、缩放和空状态。

### 侧栏目的地与标签验证（2026-11-27）

使用 `agent-browser` 验证 localhost 上的生产构建。1512px 桌面探索一级标签高 36px、字号 13px、控制圆角 8px，导航与账号中心线差为 0px。二级默认透明，通过文字对比标明选中项。探索网格在 1512px、1024px、390px 分别为三列、两列、一列。390px 聚焦末项后滚动至可见，账号区位置保持稳定，标签高度为 44px。320px 的七个侧栏页面均检查正文和页面横向溢出。浅色主题下核对前景与中性选中底色，减少动态效果时过渡为 0 秒。

交互验收覆盖创作的画布切换、探索各频道及本地预览、AI 工具的视频分类、资产六个来源及画布直链、短剧上传模式与探索直达、动效风格选择、营销模板与海报空态。资产浏览使用游客外壳，登录态数据合同由现有资产测试覆盖。本次验证范围为读取和导航。竞品观察和采用规则见[设计09](../design/09-统一顶栏与阶段入口设计.md)的侧栏目的地章节。

### 侧栏与账号工具复用验证（2026-11-27）

使用 agent-browser 验证 localhost 的生产构建。1512px 探索页侧栏展开 240px、收起 64px，收起状态在导航到 AI 工具后保留。展开的主导航行实测 216 × 32px，图文间距和圆角为 8px。桌面账号组与快捷组均高 36px，账号按钮高 28px，探索搜索为 36px 方形。390px 下侧栏 Sheet 宽 288px，菜单行高 44px，Escape 关闭后焦点回到导航按钮。320px 的七个一级页面检查了顶栏 50px 组高和页面、正文横向溢出。

隔离的模拟会话和钱包响应验证了桌面通知、余额、24px 头像的顺序、余额浮层、账号菜单与键盘焦点，以及手机 44px 头像按钮和菜单内的外观子级。生产构建、类型与文档检查通过。共享壳及相关回归共通过 159 项测试，抽屉宽度修正后复跑布局、账号和主题的 36 项测试。
