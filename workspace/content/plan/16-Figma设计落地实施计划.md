# Figma 设计落地实施计划

唯一来源为[PRD11](../prd/11-统一工作台与创作入口.md)。现行设计见[设计09](../design/09-统一顶栏与阶段入口设计.md)与[全局设计规范](../../../DESIGN.md)。实施进度见 [BACKLOG](../../../BACKLOG.md)。

## 实施步骤

1. 确认 Figma 中正式页面、使用的共享组件和待对齐的状态。以设计09为依据同步入口、顶栏、创作壳层和账户状态。
2. 优先复用现有 React 组件与令牌。按正式路由核对主题、焦点、关闭目标、桌面和窄屏滚动。规则改变先更新所属设计。
3. 覆盖游客、已登录、权限受限、空、加载与失败。替身与真实身份分别验收。回归项目选择、素材收藏和账号菜单时，分别验证导航和正式写入回执。
4. 涉及素材管理时按 AC-WB-18 验证目录上传落位、归档失败重试、正文搜索及清除、预览关闭后恢复焦点。涉及账号菜单时按 AC-WB-21 验证管理员入口、普通账号权限、移动返回和焦点及共用认证弹窗。
5. 使用正式构建验证路由和交互。发布与回退按项目部署规则执行，版本与验收证据记录到 BACKLOG。

## 共享顶栏验证

验证公共顶栏跨页面顺序和响应式行为。作品标题、返回、编辑器工具、头像和会话状态按页面所有者的合同检查。对照 Figma 的组件状态，并在运行页面核对键盘、缩放和空状态。
