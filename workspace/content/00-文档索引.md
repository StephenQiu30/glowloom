## 使用与维护

从领域需求进入设计，经 PRD 明确交付范围，再沿 Plan 执行。进度、优先级、阻塞和下一步统一见 [BACKLOG](../../BACKLOG.md)。工程约定见 [PROJECT](../../PROJECT.md) 与 [AGENTS](../../AGENTS.md)，视觉及共享交互见 [DESIGN](../../DESIGN.md)。

新结论直接更新对应知识的所有者，同时同步下游引用。已替代方案、临时修复、检查快照和交接流水不继续作为正文或独立设计文件；历史过程查 Git。清理时先迁入仍有效的规则和必要证据，再删除重复载体并修复链接，不另建历史堆积目录。

`research/evidence` 中的截图、摘录和检查快照已移出知识库。仍需对照时引用 Git `5c785a12` 的原路径，不把这些过程文件恢复成可管理文档。

稳定业务 ID 与仍有效的用户确认保留，文件编号允许空缺。证据说明其日期、版本、环境及未覆盖范围；单元、模拟、真实数据库、浏览器、供应商、产品接受和发布分开判断。
