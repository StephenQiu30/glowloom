# 短剧视频秒价与模型接入对照

证据日期为 2026-11-21。此文记录同类产品公开价格、Business 项目实现和 Glowloom 的差距。销售与结算见[设计41 §7.5](../design/41-模型销售定价与结算设计.md#video-token-price)。

## 1. 结论

「元/生成秒」便于横向比较分镜预算，公开报价涉及固定时长单价、Token 折算和会员促销。[SRC-AI-56](../requirement/04-AI平台接入与预设管理需求.md#src-ai-56) 已明确 Glowloom 短剧视频按实际计费 Token 结算。方舟按量采购测算以同规格官方示例和本账号账单为依据。

## 4. 同规格采购参考

采购参考来自火山方舟在线推理的官方示例，规格统一为 16:9、720p、输出 5 秒、无视频输入。方舟以视频 Token 计费，分辨率和有无参考视频影响费率，画幅、输入输出时长和帧率影响估量，部分任务有最低 Token 门槛。采购用量取原回执的 `usage.completion_tokens`，实际成本取可归属账单。 [方舟模型定价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh&redirect=1)

| 型号 | 方舟参考 ¥／5 秒 | 参考 ¥／输出秒 |
| --- | ---: | ---: |
| Seedance 2.0 Mini | 2.48 | 0.496 |
| Seedance 2.0 Fast | 4.00 | 0.800 |
| Seedance 2.5 | 7.56 | 1.512 |

Seedance 2.5 在同为 720p 和输出 5 秒、增加 2～30 秒参考视频输入时，方舟官方参考成本变为 ¥8.16～31.75。实际成本需按账号费率、回执用量和账单核对。试算销售费率时，还需计入失败尝试、归档、流量等变动成本。 [方舟模型定价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh&redirect=1)

## 5. Glowloom 对照与证据缺口

- 当前 `execution/gateway` 的媒体报价用空 `Usage` 计算按次售价，媒体驱动要求销售和采购均为固定按次价。方舟 Seedance 的种子有分档刊例说明。要开通 Token 计费，需补网关估量、供应商实际 Token 回执及交付后核销，并从创作入口联验。 [媒体报价](https://github.com/StephenQiu30/glowloom/blob/4ae04882a2898b1e50b718f3d1d508d4c568a324/backend/execution/gateway/application/media.go) · [媒体驱动](https://github.com/StephenQiu30/glowloom/blob/4ae04882a2898b1e50b718f3d1d508d4c568a324/backend/execution/gateway/adapter/provider/media.go) · [公共种子](../../../backend/db/data.sql)
- 同一价格覆盖 9:16 与 16:9、多个时长和首帧输入，以当前渠道能力及各规格样本成本为准。发布前要用该账号的回执与账单核对成功、失败与归档重试的归属，并覆盖已开放时长的边界。公开促销和商品目录没有提供 Glowloom 采购条件。
- 此次只读本地源码、公开目录和官方页面，未购买会员、发起真实生成或核对对应供应商实账。
