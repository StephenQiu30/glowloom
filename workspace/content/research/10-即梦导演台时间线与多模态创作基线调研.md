## 1. 导演台基线（单帧构图与动态预演）

- **双阶段闭环**：导演台围绕「单帧构图（Static Framing）」与「动态预演（Motion Preview）」构建闭环：先在静态视图中调整机位、景别、主体站位与运镜轨迹，再进入动态预演验证镜头运动，并支持随时返回静态微调与版本保存/恢复。
- **画布集成契约**：导演台既可作为独立工作区运行，也可作为画布节点承接上游参考图/主体，并将构图结果与运镜控制输出给下游图生视频节点。

## 2. 画布时间线与全屏工作区基线

- **画布节点与全屏切换**：时间线在无限画布中以聚合节点呈现（显示片段数、总时长与缩略图条），双击或点击展开进入全屏多轨剪辑工作区，保持与画布资产源的双向引用。
- **轨道、编辑与导出语义**：
  - 支持主视频轨、画中画/贴图轨、多条音频轨（对白/配乐/音效）与字幕轨；支持裁剪、分割、吸附对齐、音量包络与转场。
  - 状态须严格分离建模：素材加载态、代理预览态、云端/本地合成渲染态与交付成片态互不混淆，导出产物统一沉淀回项目资产库。

## 3. 七类多模态创作与 Agent 编排链路基线

- **五条核心创作链路**：
  1. **直接生成链**：单次表单/提示词直达模型推理（生图、生视频、生音）。
  2. **Agent 编排链**：由主创作 Agent 拆解长意图（故事 → 角色/场景设定 → 分镜表 → 批量出图/出视频 → 时间线成片），在高成本节点引入用户确认门禁。
  3. **声音到数字人链**：音色设计/克隆或 TTS 生成对白 → 口型同步（LipSync）/数字人驱动 → 绑定分镜视频。
  4. **跨模式接续链**：任意生成结果可无损流转为下一阶段输入（文生图 → 局部重绘/扩图 → 首尾帧视频 → 延长/配音 → 时间线剪辑）。
  5. **工作室与 Skill 链**：将高频垂直制作流程（如 9:16 竖屏短剧、电商带货、MV）封装为可复用 Skill 与结构化工作流，而非要求用户每次从零写长提示词。
- **官方接入与站内产品区分**：调研明确区分供应商公开 API 合同与竞品站内私有编排能力，织光在落地时只对公开可核验能力做精确契约承诺。
