## 1. 项目与画布入口基线

- **顶层入口与主画布关系**：项目作为创作工作区容器，新建/进入项目直达主画布；支持画布列表、历史画布与快速继续创作入口，不强迫用户先填复杂表单再进画布。
- **信息架构边界**：左侧常驻全局导航串联「探索 / 创作 / 资产 / 主体 / 画布」，工作区内保持轻顶栏（项目标题、保存状态、缩放与视图控制、导出/分享）以最大化创作视口。

### 2.2 统一主体库（Elements）
- **核心能力**：将角色、道具、场景沉淀为可跨项目/跨画布复用的结构化主体资产（含多角度参考图、特征描述与封面），在提示词编辑器与画布节点中通过 `@主体` 直接引用，保障多镜头视觉一致性。
- **权限与生命周期**：区分个人主体与公共/团队主体；主体删除或修改不影响已生成历史作品的静态快照。
- **列表续载**：2026-10-29 记录显示主体接口使用 `cursor/limit` 与 `next_cursor/has_more`，首批 20 条。底部可见后触发追加、追加失败可重试来自静态分支；该账户只有 1 项，未验证真实第二批。REA `ev_37196e7282bce29a93c9f82cfaf3713ec1244af638563334dc876a16a4040bb3`，原报告可按 Git `5c785a12` 的 `docs/research/evidence/2026-10-29-subject-list/report.md` 追溯。

## 3. 无限画布交互与节点基线

- **视口与节点组织**：支持平移、缩放、框选、对齐辅助线、编组（Group）与撤销/重做（Undo/Redo）；画布节点按职责划分为文本/提示词节点、图片节点、视频节点、音频节点、参考连线与导演工具箱节点。
- **参考连接与参数面板**：节点间通过有向边表达「首帧/尾帧/参考图/主体/文本提示词」依赖；选中节点就地浮出紧凑参数栏（模型、比例、时长、分辨率、生成数量），不遮挡主体画布区域。
- **状态语义分离**：节点自身的编辑草稿态、异步生成排队/运行态、资产落盘完成态与失败重试态须独立建模，单节点异常不得阻断整张画布的打开与保存。

## 4. 探索与创作首页基线

- **探索页（Explore）**：以瀑布流作品卡片 + 分类标签 + 技能/活动专区构成，核心闭环是「看作品 → 查参数/提示词 → 一键同款/转入创作或画布」。搜索与发布各自维护独立分类维度。
- **创作首页（Creation）**：以统一多参考提示词输入器为核心，覆盖七类创作模式（文生图、图生图、文生视频、图生视频、首尾帧/运镜、音频/配音、数字人/动作模仿），并与全站公共组件（顶栏、模型选择器、比例/清晰度选择器、资产引用弹层、积分预估提示）保持单一视觉与交互契约。
