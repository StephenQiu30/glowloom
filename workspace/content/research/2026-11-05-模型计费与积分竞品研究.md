## 3. 即梦：分来源积分、订阅权益与独立 API

运行证据：

- `ev_814142d8b18bd40fb021e0636e89f53d32bd4dbb430a273b64bb4e4f521fd2d1`：官网默认年付面板，基础会员首年活动价393元、每月725积分；这是周期套餐展示，不是统一的人民币兑积分汇率。
- `ev_da994d38ed6184312061647b12e429dafb6b0da832e61cb3c9a5fb573cd206e6`：点击“单月购买”，基础/标准/高级分别显示79/239/649元，每月725/2210/6160积分，标为一次性付费、不自动续费。证明价格随购买周期变化；未点击支付。[官网](https://jimeng.jianying.com/)
- `ev_a1541fd49ea8ed40cacdd2d5aeb67f50cf7613f00489f64b4d59bb1e1b44cd8b`：未登录生成页被转至创作首页；未取得登录后的实际扣分与失败收据。

[官方积分说明](https://lf26-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/dreamina/bbb8a810-1fd5-4962-a24a-9b01acd3dec4.html)区分日赠、订阅、充值三类；有效期与渠道可用范围不同，优先使用临期额度。[2026-10-30生效付费协议](https://lf3-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/dreamina/b966ce40-d931-4397-8def-38fe5d03c729.html)进一步把充值准入、期限、价格与实际购买页绑定。两份材料存在更新时间及取消订阅表述差异，不据旧 FAQ 推导当前退款结果。官网说明 API 使用额度另购，不与会员积分混用。

可借鉴：费用靠近生成操作、余额可追溯到来源和期限、取消续费与购买周期显式区分。Glowloom 不应复制大量促销兑换口径，也不应直接套用即梦积分数量反推上游 API 成本。

## 4. LibTV：多余额与更复杂的运营权益

目标是[liblib.tv](https://www.liblib.tv/)，不是同名影视网站或非官方镜像。

`ev_b97553031690f7199df63be09acae2faa936d3c4df83fb5a359d58d0afaa447d`：关闭首页活动弹窗，点击会员入口，真实打开会员面板。观察到多个档位、月/季/年购买、积分超市、团队入口、并发与存储权益、指定模型限时零积分、按模型估算视频秒数/图片张数的对照表。面板的部分价格使用滚动数字动画， accessibility 捕获包含0～9序列，因此不把年付大数字当作准确成交价；1500/4600等月积分及会员权益文字可读。对照表说明生成数量受参数影响，不能将其宣传为成片数量保证。

`ev_f1ed2dc13bc69ebbb9fe063bb22afcecd288e1a0245b79fa72b1aaf66abe9ba1`：依次点击四个 FAQ，每次等待600ms后读取展开内容：

| ID      | 页面规则的归纳                                                                             | 不能证明什么                                                 |
| ------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| LIB-C01 | 会员积分按31天有效期轮换；通用充值存在多种期限；另有模型专享积分和日赠额度                 | 不能推导所有购买积分永久有效                                 |
| LIB-C02 | 默认先免费、再模型专享、再会员、再通用充值；同类先临期，并允许用户自定义；免费次数先于积分 | 不能据此断言其他平台同样支持自定义                           |
| LIB-C03 | 页面承诺任务失败后两小时内返还对应积分，原消费条目标示返还                                 | 未发失败任务，未验证到账速度与例外；也不是上游供应商免费证据 |
| LIB-C04 | 会员退款经审核，按使用月份/剩余额度折算；赠送及零积分活动也可能影响退款计算                | 不能照搬其复杂回溯算法成为 Glowloom 用户协议                 |

可借鉴：积分批次、按模型估算购买力、明确区分任务返还与现金退订。暂不采用：模型专享积分、用户自定义扣款顺序、年卡大额促销、多重活动叠加。它们增加退款、过期及跨模型创作解释成本。

## 5. 本项目适配及未解决问题

Glowloom 已有人民币微元预算、不可变价格、预留/结算和未知费用屏障；当前积分为金额投影，不是已充值资金。证据见[设计36 §3](../design/36-模型商业计费与积分钱包设计.md#3-背景)。

本轮已回答：三平台公开计费结构、BeefTV 当前估价实现、LibTV 四项规则及即梦周期价呈现。部分回答：登录态生成报价与会员差异，沿用此前有日期的[即梦报价观察](2026-11-03-即梦报价与模型接入交互拆解.md)，不能冒称本日重测。未解决：竞品真实支付、失败返还、远端账本/支付验签及内部成本；本轮没有这些证据。个别会员入口走查因遮罩、DOM元素类型及超时失败，已改用准确选择器或官网公开价格页，不以失败记录支持成功结论。

产品建议由设计36持有；本研究不使任何套餐、补偿时限、毛利或充值政策生效。
