## 4. 约束与非目标

- 当前 requirement → design → PRD → Plan 分层及其唯一来源关系继续保留。实施调度仍只在根 BACKLOG 维护；执行尝试记录与项目排期分开。
- `backend/db/schema.sql`、`backend/db/data.sql` 和工程生成契约继续由原工程拥有。Workspace 不维护第二套 SQL 或手写客户端，也不在应用启动时执行 DDL。
- 复用现有视觉与工程基线。知识站不预设照搬 Chat4j 的 Java、Vue、微服务拆分或产品权限。
- 本轮不建设向量数据库、自研模型推理循环、通用低代码编排平台或公开知识 SaaS，不触发真实收费调用。
- 完整设计不代表所有功能必须同时实现；静态阅读完成不能代表在线编辑、工作流执行或 Agent 接入已经完成。
