# AI 短剧制作多 Agent 编排需求

## 1. 来源

<a id="src-sdma-01"></a>

### SRC-SDMA-01（2026-11-25，`/grill-me` 需求确认）

用户原文：

> 对应的我想要AI短剧制作平台的话我们当前的ai agent服务应该如何设计，参考 beeftv 和 toonflow 这种 github 的开源项目
> 你可以使用 /grill-me 向我明确一下我们的需求

经 7 轮 `/grill-me` 访谈，AI 短剧制作 Agent 的产品与工程需求全部确认：

1. **核心内容形态**：优先打透 **9:16 竖屏 AI 漫剧 / 动画短剧**（强剧情反转 + 多集连载）。
2. **双交互模式并存**：
   - **分阶段人机协同**（Toonflow 阶段推进）：Agent 沿六阶段 Workflow 推进，产物自动落盘到无限画布，关键里程碑与收费点暂停审批或画布手改；
   - **画布自由操控 + Agent 副驾驶**（BeefTV 画布驱动）：创作者可随时在无限画布自由建节点，圈选局部节点让 Agent 改镜、补镜、出宫格图或生成下游视频。
3. **输入起点与事件图谱**：全源接入（一句话创意、长篇网文 TXT/DOCX 导入、已有分场剧本）；长文本由 `ScriptAgent` 抽取结构化**章节事件图谱（Event Graph）**存入 Go 业务库，多集连载按事件图谱精准检索上下文，防吃书遗忘。
4. **视觉一致性与出图策略**：**双层锁定**——先生成并锁定角色三视图、服装变体与核心场景定妆图到主体库（唯一 `subject_id`）；同场批量分镜默认采用 BeefTV 风格 **2x2 宫格单次出图 + 自动切图放大** 锁死五官/画风/光影；画布支持对任意单镜独立重抽。
5. **动态视频、配音/对口型与采用机制**：**分级动态化 + 角色音色绑定 + 按需对口型 + 显式采用**——常规镜头走首尾帧 I2V + 角色固定 `voice_id` 配音/BGM/音效；仅特写对白镜头按需开启对口型（LipSync）；每镜支持多 Take 抽卡，仅显式 `adopt_shot` 的 Take 进入时间线成片。
6. **监督质检与 HITL 审批粒度**：文本阶段（事件图谱、分集剧本、分镜表）由 `ContinuityReviewerAgent` 自动审校与打回修订（**最多 2 轮防死循环**），不打断用户；**三视图、2x2 宫格、I2V/配音**三大收费阶段各自汇总报价单触发 `suspend()` 一次审批；用户在画布手动触发单镜重抽视同已授权。
7. **本轮交付范围**：端到端完整落地——沉淀知识库文档、在 `agent/` 实现三层 5 角色与六阶段短剧 Workflow + 6 套短剧 `SKILL.md` + 短剧专项 Scorers，并在 Go 侧将短剧核心工具挂入 `/internal/agent-mcp` 完成全链路测试。

对应技术方案见 [设计49](../design/49-AI短剧制作三层Agent与六阶段Workflow设计.md)，验收范围见 [PRD35](../prd/35-AI短剧制作多Agent编排.md)，执行计划见 [Plan44](../plan/44-AI短剧制作多Agent编排执行计划.md)。

## 2. 明确要求

| ID          | 要求                                                                 | 确认边界                                                                 |
| ----------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| FR-SDMA-01  | 落地三层 5 角色多 Agent 体系（决策/执行/监督）                       | `Producer`、`ScriptAgent`、`AssetDirectorAgent`、`ProductionAgent`、`ContinuityReviewerAgent` |
| FR-SDMA-02  | 落地六阶段可挂起恢复短剧 Mastra Workflow                             | 覆盖事件图谱、剧本审校、三视图审批、2x2 宫格审批、I2V/声音审批、时间线装配 |
| FR-SDMA-03  | 支持双模式协作（Workflow 阶段推进 + 无限画布圈选节点副驾驶）         | 同一 `agent/` 混合编排内核同时承接两类入口                               |
| FR-SDMA-04  | 支持双层视觉一致性锁定与单镜独立重抽                                 | 主体三视图 `subject_id` 强制绑定 + 2x2 宫格切图放大 + 画布单镜重抽       |
| FR-SDMA-05  | 支持分级 I2V、角色 `voice_id` 绑定、特写按需 LipSync 与显式 Take 采用 | 仅已采用（adopted）镜头进入时间线导出                                    |
| FR-SDMA-06  | 落地 6 套短剧声明式 `SKILL.md` 与短剧专项离线 Scorers 评测           | 校验主体绑定率、未审批零收费红线与监督层打回上限（≤2 轮）                |
| FR-SDMA-07  | Go 内部 MCP Server 暴露 5 组短剧原子工具并强制乐观锁与审批凭证校验   | `script_*`、`bible_subject_*`、`canvas_*`、`media_*`、`timeline_*`       |
